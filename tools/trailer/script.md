# 《墨途》宣传片 · 分镜与字幕稿（v0）

> 实机演示：画面全部来自游戏实时运行（Playwright 驱动 Chromium + GPU，真实键鼠事件），调试接口只用来布置场景（刷怪、给物品、改境界、跳天时、主角无敌），画面里不出现调试界面。
> 成片：`work/video/墨途_宣传_v1.mp4`（1920×1080 / 30fps / H.264 + AAC），短版 `work/video/墨途_宣传_15s.mp4`，联系表 `work/video/contact_sheet.png`。
> 每次构建都会把实际时间线写到 `work/video/build/<成片名>/timeline.json`，下面的时间码以它为准（重录后会小幅变化）。

## 一、制作规则（用户 / 主管要求，全部流水线都按这个来）

1. **不配音**：不用 TTS 旁白，只有字幕 + 背景音乐（+ 少量合成音效）。音乐不做旁白压低（ducking）。
2. **字幕停留**：每条 ≥ `1.0 + 字数 × 0.25` 秒，最短 2.5 秒；相邻两条至少隔 0.3 秒；一屏最多两行、每行 ≤ 16 字（尽量单行）；大字卡 ≥ 1.8 秒。
   画面节奏跟着字幕走——字幕没读完不切到下一个关键镜头（构建时自动检查，违例会打印 `⚠`）。字卡与字幕错开，不同屏。
3. **字幕位置（宣纸画框）**：实机画面等比缩到 1728×972，放在上方居中（左右各留 96px、上留 16px 宣纸边，带纸纹和一道淡墨框）；底部约 92px 是宣纸字幕带，字幕只出现在这条带里，不压任何 HUD（技能栏、气血、天时条、铜镜、拾取列表、储物袋纸笺都不挡）。
   字幕：马善政楷书，墨色，单行 46px（1080p），两行缩到 40px，左右各一笔淡墨点缀。
   例外：开场标题、落版、大字卡可以压在画面上；大字卡放在实机画面上半部的中央，不与技能栏同位置。
4. **UI 段要等进场动画结束**：结算手卷、天机镜、炼器结果、境界页、储物袋、地图这类有进场动画的界面，要等动画全部播完、数据填好（≥ 1.5 秒，并检测界面里的有限时长动画都结束）再开始取这一段。录制脚本用 `settle()` 检测并打 `*Ready` 标记，剪辑表从这些标记取。
5. **按键**：蓄势斩 = 鼠标右键主动释放（气势 ≥ 50 可放，满势有完整演出）；法宝 = V（预览后左键确认）。录制脚本自动识别新旧方案（`tools/trailer/controls.json`，`detect`）。
6. **帧率稳定**：虚拟时钟逐帧推进（`tools/trailer/vt.js`），每帧严格 1/30 秒游戏时间，截图慢也不掉帧；慢动作 = 每帧推进更短的游戏时间（游戏本身逐帧渲染，不是后期插帧）。画质设置固定"高"。

## 三、配乐与音效（全部代码合成，无版权素材）

`tools/trailer/music.py`：B 羽调式五声（B D E F# A）。
- 开场：低音长音 + 标题处古琴泛音、吟猱；连招处板鼓。
- 世界段：古筝分解和弦 + 洞箫旋律 + 轻太鼓。
- 洞府段：古琴慢句（滑音、揉弦）+ pad + 高音点缀，无鼓。
- 战斗段：太鼓节奏型 + 古筝轮指 + 低音持续，锣声起。
- Boss 段：更重的鼓、洞箫长音，最后一击前留白，重鼓落下。
- 落版：一声磬（非谐泛音长余韵）+ 古琴泛音收尾。
音效（同一脚本合成）：挥剑、蓄势斩、破盾、盖印（每张字卡盖印时一声）、重击。段落起点由剪辑表算出，重剪后自动对齐。

## 四、一键重做

```
node tools/trailer/build.mjs                       # 全流程：重录全部镜头 → 字幕 / 字卡 → 配乐 → 混音 → 成片 + 15s 短版 + 联系表（约 15 分钟）
node tools/trailer/build.mjs --no-record           # 只重做后期（用 work/video/clips 现有片段，约 3 分钟）
node tools/trailer/build.mjs --record=s05_loot,s18_boss   # 只重录指定镜头再出片
node tools/trailer/record.mjs s13_forge            # 只录某个镜头（输出 work/video/clips/s13_forge.mp4/.json）
node tools/trailer/peek.mjs <视频> <out.png> [间隔秒]  # 抽帧检查
```
依赖：项目 node_modules（vite、playwright-core）、Playwright Chromium（%LOCALAPPDATA%/ms-playwright/chromium-1243）、Python 3 + numpy + scipy；ffmpeg 用 `pip install --target work/video/bin/pydeps imageio-ffmpeg` 自带的静态版（build.mjs 缺了会自动装）。字体：`assets/fonts/` 下的马善政楷书 / 志莽行书完整版（SIL OFL），没有时回退到游戏子集 + 系统楷体。

## 五、文件

| 文件 | 作用 |
|---|---|
| `tools/trailer/record.mjs` | 录制入口：逐镜头开独立浏览器上下文、看门狗超时重试，输出片段 + 标记 |
| `tools/trailer/shots.mjs` | 镜头表（每个镜头的布置与操作），按键方案识别、界面稳定检测 |
| `tools/trailer/lib.mjs` | Vite 服务器 + Chromium（GPU）、逐帧截图管道编码、键鼠输入工具 |
| `tools/trailer/vt.js` | 虚拟时钟（initScript）：rAF / 定时器 / CSS 动画全部按虚拟时间逐帧推进 |
| `tools/trailer/controls.json` | 按键方案（蓄势斩 / 法宝），默认自动识别 |
| `tools/trailer/edit.mjs` | 剪辑表：分镜、字幕、字卡、音效、配乐段落（完整版 + 15s 版） |
| `tools/trailer/overlay.html` | 宣纸画框、字幕、字卡、落版（用游戏 src/ui/ink 的水墨套件渲染） |
| `tools/trailer/music.py` / `mix.py` | 配乐与音效合成 / 混音 |
| `tools/trailer/build.mjs` | 一键构建 |
