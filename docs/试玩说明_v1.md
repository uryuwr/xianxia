# 墨途 · 第一版试玩说明

## 启动
- 开发服务器：`npx vite`（端口 5199，局域网可用本机 IP 访问）。浏览器打开 `http://localhost:5199/` 进入开始界面。
- 直达参数：`?scene=cave&slot=1`（载入 / 新建第 1 卷并进洞府）、`?scene=run&region=r1|r2|tutorial`、`?scene=sandbox`（旧战斗沙盒）。

## 操作
| 键 | 作用 |
|---|---|
| WASD | 移动 |
| 鼠标左键 | 普攻（按住连段，三段循环，命中积攒气势）；瞄准时为确认 |
| 鼠标右键 | 蓄势斩：气势 ≥ 50 可放（按气势比例），满 100 = 势成；满势一刀约等于同境界剑气斩三道全中的 1.8 倍，**剑意破盾**（不看五行，削护盾上限 35%，首领每段 20%）、击倒小怪 / 打断精英与首领、3 秒墨痕持续伤害；放出后清零。**气势不随时间流失**（出局清零），可在小怪身上攒好带去打精英。气势不足时提示"势未成"。瞄准中右键 = 取消瞄准；储物袋 / 搜取 / 天机镜打开时右键归界面 |
| Space | 闪身（开局 1 次、冷却 2.75 秒，练气六层起 2 次；完美闪避返还 60% 冷却）；站在断涧 / 石台跃点朝对岸按下 = 跃涧（练气五层二段跳）；**筑基后**在深水 / 崖边朝对岸按下 = 御剑掠过（≤ 12 米），筑基前深水边会提示"水深难渡，需御剑（筑基）" |
| Q / E / R | 法术：先出预览（射程、轨迹、范围），左键或再按一次确认；右键 / Esc 取消 |
| V | 法宝（练气七层）：先出预览，左键或再按 V 确认 |
| T | 阵盘（练气七层） |
| F | 交互：拾取、采集、开箱、撤离、奇遇、洞府设施 |
| 1 / 2 | 丹药栏 |
| 3 / 4 | 五行符：使用 / 切换 |
| G | 遁地符（原地读条遁回洞府，受击打断） |
| Tab | 储物袋 |
| M | 天机镜（地图） |
| C | 境界（洞府） |
| Esc | 暂停菜单：继续 / 设置 / 回到主页（按身陨结算，首次豁免）；序章中可跳过序章 |
| F8 | 调试面板：跳场景、发物品、立即撤离 / 身陨、入夜、改境界 |
| 设置 | "快速施法"：按键直接在鼠标处释放 |

- 真气不自动回复（击杀、拾取也不回）：靠回气丹、紫金葫芦、聚灵阵。

## 一轮闭环
开始界面 → 新卷 → 开场 → 教学局（沿河拾剑、斩狼、到破洞府）→ 洞府（灵泉 / 丹器房 / 仓库 / 出行台）→ 出行准备（选区域、委托、丹药符箓、贴身锦囊）→ 出行局（随天时灵潮倍率上涨，入夜妖潮）→ 撤离结算（当场鉴定）→ 洞府炼化修为、突破。
- 区域一身陨：储物袋保留一半；区域二身陨：保留 25%，其余与 1 件装备遗落，下一局可取回。关键物品永不丢。
- 练气五层可去区域二（竹海·溪谷）；练气八层可挑战碧鳞；练气九层 + 筑基丹 → 心魔劫 → 筑基一层。

## 分享包
`node tools/pack.mjs` → `release/墨途_v1.html`（单文件，双击离线可玩，存档在浏览器本地）；另有目录版 `release/墨途_v1_web/` 可放静态服务器。`node tools/check_pack.mjs` 用 file:// 验证。

## 回归测试
`bash tools/regress.sh`：全部场景两两并行跑，汇总通过 / 失败（日志在 `work/regress/`）。单个场景：`node tools/run.mjs <场景> [query]`。

## 已知限制
- 白鹭跑步时裙摆会被腿顶穿；药园页偏空；心魔出招较简单。
- 区域二全清约 12–17 分钟，超出 9–13 分钟目标（有意留作"留还是走"的取舍）。
- 硬崖只作用于碰撞，崖边约 0.7 米内脚底与画面可能有 0.5 米偏差。
- 数值基于模拟，单局时长 / 每分钟击杀 / 每局精英数等实测后需回填重跑（`docs/review/numeric/sim/run_all.py`）。
