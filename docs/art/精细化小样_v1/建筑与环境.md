> 角色 / 怪物（林墨、青牙）由 art-char 交付，见同目录 `assets/` 与其说明；本文只写建筑、环境、页面与代价。

## 1. 结论先说

- **纯程序能做到的程度**：一座单檐歇山的山神庙（举折曲面 + 出翘 / 起翘、实例化板瓦 / 筒瓦 3474 片、瓦当滴水 300 个、正脊 + 吻兽、垂脊 / 戗脊 / 博脊 + 垂兽 / 走兽 / 仙人、博风悬鱼、山花、连檐 + 飞椽 / 檐椽、26 攒斗拱、彩画额枋、朱漆柱、格扇门窗棂格、匾额、须弥台基 + 踏跺垂带、室内神像），加 30×30 米的场地（黄土 / 碎石 / 草地过渡 + 接触 AO、不规则石板路、劈理面山石、几何草丛、带竹节的竹丛、虬松、杂树、石灯），全部几何和贴图在页面里现算，**没有一张外部图片、没有 Blender**。
- **45° 游戏镜头下最显著的提升是屋顶**（瓦垄、檐口曲线、翼角、屋脊兽件在 30 米外都读得出），其次是地面的层次和山石的块面。斗拱、棂格、匾额这些在游戏镜头里基本被檐口挡住，只在近景有用（见"精度：游戏预算"开关）。
- **代价**（详见 §5）：RTX 3070 上全部加起来 ≤ 2.5 ms/帧（1080p × 1.5 像素比），对 3070 不是问题；**普通集显才是约束**——UHD 630（游戏"中"档像素口径 1536×864）上现状 14.7 ms → A 20.3 → B 28.3 → C 31.1 ms。分项消融后已把 B 压到 26.5 ms，落地还要按 §6 做 LOD 才能进集显 60 帧预算。
- **三种着色的观感**（同一套几何与贴图，§3）：
  - A 现行 toon：最接近游戏现在的平涂水墨感，新几何本身已经带来大部分提升；暗部是一块平色。
  - B 水墨写意：法线让 3 阶色阶沿瓦缝 / 石纹断开，像皴擦；AO 压住接缝与接地；暗部叠披麻皴。**最"像画"，也是我推荐的方向**，代价比 A 高约 40%（集显）。
  - C 写实 PBR：体积和材质感最强，但过完水墨后期整体偏亮、阴影偏弱，平涂的"画意"最少，片元成本最高。

## 3. 方法

### 3.1 与游戏一致的渲染设置
- 画布无抗锯齿 + `InkPipeline`（4×MSAA 半浮点 RT + 深度）→ 水墨后期；PCFSoft 阴影 4096、阴影相机 ±38 米、日光 (-26, 40, -14) 强度 2.0、半球光 0xf2efe6 / 0x5a5d5a 0.85、宣纸底色 0xece6d6，全部抄 `src/main.js` / `level.js`。
- 直接 import 游戏的 `src/render/materials.js`（toon、toonGradient、outlineMaterial、TEX）、`bake.js`（bakeAll 皴法 / 点苔）、`ink.js`、`markers.js temple()`、`props.js lantern()`、`vegetation.js rockGeo()`，现状版就是游戏代码本身，不是仿制。
- C 模式：在 ink 后期取色前插一个 `uTone`（曝光 + ACES 拟合），`uTone = 0` 时走原分支，A / B 与游戏后期逐像素一致；C 时半球光降到 0.3、由程序化天穹 PMREM 承担天光（不降会双重补光、暗部发白）。

### 3.2 GPU 程序化贴图（`tools/art_refine_v1/src/texbake.js`、`recipes.js`）
- 配方 = 可平铺的场函数 `field(uv) → (高度[米], m1, m2, m3)` + 着色函数（albedo / rough / inkLine / AO）。第 1 遍场函数写半浮点 RT；第 2 遍一个收尾着色器画三次：
  - **albedo**（sRGB RT，硬件编码）：配方着色 + **缝隙积灰**（与一圈均值比较的凹度压暗）+ **凸棱磨亮** + 地平线 AO 压暗；
  - **normal**：高度场 Sobel，按"米 / 像素"物理缩放；
  - **orm**：R = 地平线 AO（两圈 8 方向）、G = 粗糙度、B = **墨线遮罩**（B 模式拿它勾缝隙 / 裂纹的淡墨）。
- 12 个配方：瓦（陶土颗粒 + 地衣斑）、朱漆（木纹 + 冰裂断纹 + 磨损露木）、旧木（顺纹 / 年轮 / 干裂 / 灰化）、赭红抹灰（斑驳 + 局部剥落露青砖）、青砖（错缝 + 崩角）、条石（斧剁纹 + 崩口 + 地衣）、方砖墁地、山石（层理 + 节理 + 风化坑）、地面（黄土 + 碎石团簇）、树皮（纵裂）、竹竿、彩画（青绿旋子 + 剥落）。另有 1 张世界空间噪声（苔 / 雨痕 / 泥溅用）和 5 张 Canvas 贴图（棂格、匾额、松针、杂树叶）。
- 几何体 UV 一律"米"制（按面法线盒投影 / 圆柱展开），贴图 repeat = 1 / 配方米数 → 全场纹理密度一致，没有手工展 UV。山石用**三向投影**（世界空间、whiteout 法线混合），侧面的 v 就是世界竖直，层理自然水平。
- 思路参考听雨园 `src/materials/baker.js`（MIT © 2026 Wode44398）的"配方 → 高度场 → 法线 / 地平线 AO / 缝隙"两段式；代码为本项目重写（WebGL2 + three r180 ShaderMaterial，不用 MRT / 整数打包）。

### 3.3 三种着色 = 一个材质工厂（`shading.js`）
- `Looks.use(mesh, look)` 登记网格；`look × 模式` 的材质在第一次用到时建好并缓存，切换只换 `mesh.material`（不 new、不 dispose）；进场时三种模式各真画一帧预热（加载层盖着），之后切换 0 编译。
- 共享注入（onBeforeCompile，一份 GLSL）：世界坐标 / 法线（含实例化）、风动（与游戏 JX_WIND 同公式）、实例 UV 偏移（每片瓦取不同的贴图区域）、三向投影、地面配比、风化：
  - **苔**：朝上的面 × 世界噪声成片；**雨痕**：竖直面上竖向拉长的噪声；**泥溅**：贴地 0.7 米内。
  - **接触 AO**：顶点属性 aAO（台基 / 墙脚 / 柱脚 / 檐下 / 石与地面接触处），B / C 模式乘到间接光、直射光乘一半（水墨里接地处要"压得住"）。
- B 的暗部皴笔：按"出射光 / 固有色亮度"估受光程度，暗部叠游戏的 `TEX.cunfa` 披麻皴（三向投影；地面用单次俯投影省 2 次采样）；缝隙勾墨 = orm.b × 0.3–0.45。

### 3.4 建筑（`temple.js`）——屋顶优先
- **屋面是平面高度场**：前后坡 `H = f(zE(x) − |z|) + rise(x, z)`，两山 `H = f(xE(z) − |x|) + rise`；
  - 举折 `f(d) = 檐口高 + 0.32 d + 0.036 d^2.4`（檐口约 18°、脊下约 47°，越往上越陡）；
  - 出翘：檐口在平面上向四角外撇 `zE(x) = 4.7 + 0.45 · sx^2.2`；起翘：`rise = 0.55 · (sx · sz)^1.5`（sx、sz 是到角部的归一距离）；
  - 歇山的"收山"：前后坡越过山花挑到博风（XB），两山只铺到山花面（XG），山花是两坡之间的竖直墙；
  - 戗脊线 = 两个坡面 d 相等处，二分法求解；所有构件（瓦垄、戗脊、博风、山花、椽子）都从同一套函数取点，天然贴合。
- **瓦**：板瓦（凹壳 24 面）/ 筒瓦（半圆壳 32 面）带厚度，按垄距 0.30 米沿等 x（前后坡）/ 等 z（两山）铺，沿坡按弧长每路 0.27 米（压七露三），每片下端抬 2.2 厘米形成叠压台阶，随机微转 / 缺 1% 筒瓦；到戗脊处截断由戗脊盖住。檐口第一路换成瓦当（带外沿凸棱和乳钉）/ 滴水（如意形舌片）。全部 InstancedMesh，**每类 1 个 draw call**；瓦片不投影（屋面整体的影子由瓦下垫层投出，集显上瓦片投影约占阴影 pass 一半）。
- **屋脊**：同一个多层截面（当沟 / 压当条 / 脊身 / 盖瓦）沿路径扫掠；正脊两端略升（生起），戗脊翼角外挑 0.45 米并上翘；正吻 = 头块 + 上卷身躯与卷尾（变截面扫掠）+ 背鳍 + 剑把；垂兽 / 走兽 / 仙人是小方块组合。
- **檐下**：连檐板、飞椽（方）/ 檐椽（圆）各一圈实例；26 攒斗拱（大斗、瓜拱 / 万拱 / 厢拱用带卷杀的拉伸截面、翘、昂、升、耍头）实例化；额枋 / 平板枋上彩画贴图，挑檐檩、正心枋。
- **墙与门窗**：下碱青砖 + 上身赭红抹灰；明间四扇格扇门（中间两扇半开，能看见暗室和神像）、次间槛窗、横披窗；格心是 0.3 米一格的步步锦透明贴图 + 后面一层窗纸。
- **台基**：土衬 / 陡板 / 阶条石按不等长石块沿边铺（每块倒角、微倾、独立贴图偏移）、角柱石、方砖墁地、四级踏跺 + 垂带 + 象眼。
- **风化**：贴图层（缝隙积灰、磨损、断纹、地衣、剥落）+ 材质层（苔 / 雨痕 / 泥溅）+ 几何层（瓦片微乱、缺瓦、石块微倾）+ 83 丛瓦松杂草（屋脊根、瓦垄间、台基缝）。
- 整体缩放 0.8：游戏镜头下主角站在踏跺前时，正脊与吻兽刚好入画（屋顶太高会被画面上沿切掉）。

### 3.5 环境（`env.js`）
- **地面**：64 米见方的不等距网格（中心 30 米内 0.25 米一格，向外渐疏到 2 米），顶点属性 `aSplat`（碎石 / 草 / 湿痕）+ `aAO`：庙基一圈碎石散水、檐口正下方一圈滴水湿痕、路面踩实、草地按噪声成片；接触 AO 来自台基、檐下、山石 / 树 / 石灯 / 竹丛的解析遮挡（指数衰减）。
- **石径**：4 种不规则多边形石板（拉伸 + 倒角）实例化，单列 / 双列交替。
- **山石**：二十面体 4 级细分 → 8–11 个随机"劈理面"把圆团切成大块面（斧劈皴的面）→ 轻微层理台阶 → 按 32° 折痕角分硬棱 / 软面；三向投影的层理 + 节理贴图提供皴笔"笔路"；顶点 AO = 凹度 × 贴地。
- **草**：几何草叶团（每丛 7–14 片 3 段渐窄叶，顶点色根深梢浅，法线偏上），1770 丛、3 种变体实例化、风动；石脚加一圈密草。
- **竹**：竹竿带竹节外凸（每 0.42 米一节）、竹枝、"个 / 介"字三到五片的披针叶；**松**：虬曲主干 + 平展层枝 + 云片状针叶团（每团 3 层卡片）；**杂树**：三级分叉 + 枝端叶团卡片；**石灯**：须弥座、八角柱、灯室开光、攒尖顶、宝珠（车削 + 倒角方块）。

## 5. 实测（本机：RTX 3070 / Intel UHD 630；GPU 基准 = 背靠背 40 帧中位数，3 轮取最小）

测于 hero_v2 交付前（主角为现状模型），4×MSAA、4096 阴影（页面固定用游戏"高"档的设置）。

| 状态 | 720p × 1 | 1080p × 1.5（2880×1620） | draw call | 主 pass 三角面 |
|---|---|---|---|---|
| 现状 | 0.56 ms | 1.43 ms | 93 | 60k |
| A | 0.73 | 1.98 | 124 | 487k |
| B | 1.27 | 2.43 | 124 | 487k |
| C | 1.01 | 2.37 | 124 | 487k |

（Iris Xe 按快 2–2.5 倍估：B 约 11–14 ms。）

## 6. 在游戏里同屏的代价估算与落地建议

**估算口径**：游戏出行局集显"中"档（2×MSAA、2048 阴影）现在约 14 ms/帧（性能优化_v1）。一座精细庙宇是地标（同屏 1 座），地面 / 草 / 石是全图的。

| 方案 | 集显增量（估） | 3070 增量 | 观感 |
|---|---|---|---|
| 只换建筑（A 着色） | +2–3 ms | < 0.3 ms | 屋顶提升最大、风险最小，**建议先落地** |
| 建筑 + 场景件 B，地面仍 A | +4–6 ms | < 0.6 ms | 推荐终态 |
| 全部 B（含地面、几何草） | +10–12 ms | ≈ 1 ms | 中档会掉到 40 帧左右，必须靠档位 |
| C | 比 B 再 +2–3 ms | ≈ 同 B | 不推荐（画意最少） |

**LOD / 档位**（挂到 `src/render/quality.js` TIERS）：
1. 瓦：30 米外或"低"档换成"垫层 + 瓦垄法线贴图"（用同一个瓦模板烘一张瓦垄高度场），省约 4 ms（集显）。
2. 地面：皴笔 / 法线只在"高"档开；"中 / 低"档地面用 A + 顶点配比 + 接触 AO（几乎无额外成本），省 5 ms。
3. 草：几何草叶团只在 20 米内，外面退回游戏现有的插片草；按现有 `userData.thin` 机制抽稀。
4. 阴影：瓦、草、碎石、檐下细节件不投影（已做）；竹叶在"中"档不投影。
5. 斗拱 / 椽望 / 室内 / 棂格：只在近景演出镜头（处决、入场）显示。
6. 贴图：地面 / 山石 1024 → 512（三向投影在 45° 下看不出差别）、normal + orm 合成一张（RG = 法线 xy、B = AO、A = 粗糙度）→ 约 71 MB 降到 25 MB 左右。

## 7. 局限与不满意的地方（如实）

1. **翼角瓦垄没有做"摔网"放射**：瓦垄一律平行铺到戗脊截断，近看翼角处瓦的方向不对（真实建筑在翼角是扇形转过去的）。45° 远景看不出。
2. **斗拱在游戏镜头里看不见**，近景低机位也因为背光基本是一片暗；彩画额枋近看偏"花"。
3. **屋脊是统一截面**，没有花脊纹饰；吻兽、走兽是简化方块组合，近景能看出程序感。
4. **棂格是透明贴图**，近看是平的；窗纸没有透光。
5. **地面贴图 4 米重复**，近景低机位能看出碎石的团簇规律；石板路的形状变化只有 4 种。
6. **杂树造型普通**（叶团卡片），松针团近看是卡片；竹叶在 45° 下偏碎。
7. **C 模式偏亮、阴影弱**：ACES + 水墨后期的色阶把中间调推向纸白，调了曝光仍不理想；没有做 GTAO / 软阴影这类屏幕空间效果（听雨园有），因为按性能规范不加新的全屏 pass。
8. **没有远景**：近景环绕时能看到 64 米地面的边缘和空白天空。
9. **贴图显存偏大**（约 71 MB），合并 normal / orm、降地面山石分辨率之前不适合直接进游戏。
10. **集显代价**：B 全量在 UHD 630 上 26.5 ms，没有 LOD 不能直接用。
11. 页面 10.3 MB（角色图集与 glb 以 base64 内联），本地打开约 1–2 秒。
