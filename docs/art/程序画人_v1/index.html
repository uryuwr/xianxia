程序画人 · 试验 v1

整张图是一个 HTML 文件里的 SVG：没有任何图片、贴图或模型。每一笔都是代码算出来的——笔锋的提按与收尖、头发逐缕生成、宣纸纤维与水彩晕染是 SVG 滤镜。

用到的程序手法

  • 笔锋：中线（Catmull-Rom 样条）+ 宽度曲线（起笔按下、行笔、收笔出锋）→ 轮廓多边形，再用置换滤镜做毛边
  • 头发：沿发际线均匀分布约 90 缕，每缕各自的弯度、粗细、浓淡随机；鬓边垂发单独生成
  • 五官：眼 = 上睑粗笔 + 下睑淡笔 + 渐变虹膜 + 瞳孔 + 两点高光 + 睫毛；眉 = 头重尾轻的笔锋
  • 皮肤：径向渐变 + 模糊的阴影 / 腮红块；衣袍：淡墨晕染块 + 粗细变化的衣纹线

说明

这是 2D 画法的上限试探，不是游戏模型。游戏是 3D、45° 俯视、要做动画，同样的精细度搬到 3D 上难得多（上一轮林墨 v2 就是证明）。这张图用来回答"程序到底能画多细"。
