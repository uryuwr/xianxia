# 写意留白 v1 · 林墨"不画脸"样张（美术管线 art-char，2026-11-18）

**打开**：双击 `docs/art/写意留白_v1/index.html`（资源全部内联，file:// 可开，约 3.5 MB）。
**打包**：`node tools/xieyi_v1/build.mjs`；**截图**：`node docs/art/写意留白_v1/shoot.mjs [V1 …]` → `png/`（一个浏览器实例，跑完即关）。
**没有跑 Blender**：身体、衣服、动作都是现有 `hero_v2.glb`，只在页面里换脸 / 衣袍材质，并加一顶程序化斗笠。场景和渲染设置沿用总小样的山神庙 B 水墨场景（游戏镜头参数相同）。

## 写意留白是什么
减笔人物画：**形不全而神全**。不把五官画精细，只留最少的笔，甚至一笔不画；靠剪影、衣纹、姿态和一两处朱色来传神，例如梁楷《泼墨仙人图》一路。游戏 45° 镜头下脸只有十几像素，本来就是看形不看脸。

## 如实的观感判断
- **面具感（V1 / V2 近景）**：一整块平涂、不受光的纸白脸，配上立体的头发、耳朵和衣服，近看像戴了一张白面具，V2 尤其明显。画里的留白之所以成立，是因为整幅画都是平面的，四周也是留白；3D 人物身上只有脸是平的，反而显眼。游戏 45° 镜头下（`*_game.png`）这个问题基本看不出来。
- **V3 不够"泼墨"**：晕染是按位置计算的噪声，浓淡和飞白都偏均匀，更像灰袍上的污渍，没有画家下笔的大块墨和明确的留白。要接近《泼墨仙人图》，需要按身体结构人为指定墨块（肩、背、袖成几大笔），而不是靠噪声。
- **V4 最"干净"**：遮住了脸，不存在五官难题，剪影也有特点；代价是人设变成戴斗笠的江湖客。
- **残留问题**：V1 / V2 / V4 的水墨后期会在口缝处描出一笔很细的横线（hero_v2 低模口缝处的折角，后期按深度折角描边）。页面里压平、补片都没去干净，要回 Blender 把口缝补平（重建 hero_v2 约 7 分钟），这次没做。

## 实现位置
- `tools/xieyi_v1/src/xieyi.js`：
  - 脸部笔触贴图：用 `tools/icons/inkicons.js` 的毛笔模板，画在正面投影贴图上；
  - 脸面抹平：在页面里按最小二乘拟合脸面曲面，把眼窝、鼻、唇的顶点拉上去，法线一并改；
  - 黑瞳面改成脸色；
  - 泼墨衣袍着色器、留白白袍材质、斗笠幂篱（挂在 head 骨上）。
- `tools/xieyi_v1/src/main.js`：场景、镜头、动作、界面。`tools/xieyi_v1/page.html` 是页面模板，`tools/xieyi_v1/build.mjs` 负责打包。

## 能否进游戏
- V1 / V2 / V4 只是材质加道具，进游戏的成本很低：
  - 脸用一个不受光的材质；
  - 发型网格需要去掉画上去的黑瞳；
  - 斗笠是 1 个网格 + 1 张 512 贴图；
  - 口缝要在 Blender 里补平一次。
- V3 需要一个新的着色器程序，要加进预热；毛边用的是 discard，阴影里看不出毛边。
