## 0. 一页结论

| 问题 | 本方案 |
|---|---|
| 有几个流派 | **5 个**：剑势（攒势 → 斩）、五行（叠状态 → 相生引爆 → 克盾回气）、身法（读招 → 闪 / 化 → 反打）、雷暴（暴击 → 叠雷痕 → 引雷）、守御（扛 → 蓄震 → 反震）。区分它们的不是数值，而是**资源放在哪**：自身气势 / 真气与敌身五行状态 / 敌人出招的那一刻 / 敌身雷痕 / 吸收掉的伤害 |
| 怎么避免死板职业 | 21 个**交叉件**（两个以上流派都能用，§2.2）；法术三重变体把同一门法术挂到不同流派；心法栏 2 格（练二 / 练八）天然鼓励"主流派 + 副流派" |
| 每个流派成型要什么 | **★三件**：1 本入门心法 + 1 门核心法术 + 1 件法宝或阵法。v1 五个流派都齐（§8.1）。★法术由**练四突破·玄机子传功**直接给完本（数值策划提议，战斗同意：剑势 凝锋诀 / 五行 落石诀 / 身法 止水诀 / 雷暴 掌心雷 / 守御 土遁护体），五派★三件 p50 练七、p90 练八 |
| 法术流的真气 | 遵守"不自动回复、击杀不回复"，5 条明确的构筑手段：回气丹（通用）、《凝神》克盾返还、《轮转》相生减耗、紫金葫芦**吸取**（去掉被动回蓝）、聚灵阵改"灵池"（每阵总量封顶）。目标：五行流一局可放法术 ≈ 其他流派的 1.6–2 倍，不是无限 |
| 新增 / 改动的部件 | v1：心法新 5 本（凝神、轮转、凌波、拂柳、不动）+ 改 3 本（灵根·火 → 灵根、锋锐加雷痕、雷引）；法宝新 1 件（**定风珠**，身法）+ 改 1 件（紫金葫芦）；阵法改 1 个（聚灵阵）；新敌人状态"雷痕"；新词条"暴伤"。第二期：五雷令（雷暴法宝）、八门阵（身法阵法）、标签词条、另 6 门法术变体 |
| 成长轴的手感 | **法术**：二重 = 数，三重 = **变体二选一**（改形不改动词；v1 先做 6 门）。**法宝**：一 / 二 / 四重 = 数，三 / 五重各改一次手感（只狼义手式升级）。**阵法**：二重 = 数，三重 = 改形（剑阵随身、火阵火墙、聚灵阵无前摇） |
| 不能只有剑势能打 | 剑势不加新件，只修获取；其余四派补齐法宝 / 阵 / 心法。平衡目标：同档位五个流派打青牙 / 碧鳞的用时与中位数差 ≤ 20%（守御允许慢到 +35%，换更低的掉血） |
| 首领检验不被绕开 | ①剑意对首领每段护盾**累计最多削 60%**；②所有新伤害件都有五行、照 `SHIELD_TUNE` 打盾，没有新的"无视护盾"；③《拂柳》的反打斩不带剑意；④结构检查：除五行流外，没有流派能只靠自己的件克全部五种护盾（§8.2） |
| 请用户选 | 4 题（§10）：守御是否独立成派；《凝神》克盾返还算不算合规回蓝；三重做变体还是保留冷却；心魔是否改成"照见你的流派" |

## 3. 设计原则

1. **一个流派 = 一个资源循环**（方法论 §5：核心资源或行为 + 3–5 个修饰：攒 / 花 / 触发 / 转化 / 叠层）。五个流派的资源放在五个不同的地方，所以手上在做的事不同，不是换皮：

| 流派 | 资源在哪 | 玩家在做什么 | 怎么"花" |
|---|---|---|---|
| 剑势 | 自身气势（可携带，不流失） | 贴身连砍、挑时机 | 右键蓄势斩 |
| 五行 | 真气 + 敌人身上的五行状态 | 排法术顺序（相生），看护盾换手 | 相生反应、克盾 |
| 身法 | 敌人出招的那一刻 + 闪身充能 | 读预警、贴着招闪 / 化 | 反打窗口（完美闪身、止水、拂柳斩） |
| 雷暴 | 敌人身上的雷痕 | 多段命中钓暴击、盯一个目标 | 叠满自落天雷 / 引爆 |
| 守御 | 吸收掉的伤害 | 站住、选什么时候吃招 | 护体破碎时反震 |

2. **交叉件**：每个流派的核心之外，至少一半的增强件也能被另一个流派用（Dead Cells 双色武器）。同名效果只算一次（现有规则）。
3. **动词不重复**：新部件先查"这个动词有没有载体"（功法 v2 §1 第 2 条）。
4. **防御型给进攻收益链**（Hades 复仇祝福的教训）：守御的吸收 → 反震，身法的闪 / 化 → 反打。
5. **首领检验是共同的考题**：每个流派都要"换手"，只是换的方式不同（带克制法术 / 附灵剑 / 剑意 + 撞柱）。新件不准绕开护盾。
6. **入门即有身份**：练二的入门心法本身就要改变手感（不能只是 +15% 某属性），因为练二时只有 1 个法术栏。

## 4. 五个流派

> 部件后面的标记：**★** = 成型必需的三件；（新）（改）= 本方案新增 / 改动；〔二期〕= 第二期内容。

### 4.1 剑势（剑修）——"攒势 → 斩"

- **核心循环**：普攻命中攒气势 → 小怪群 50 势就放、精英攒满势成 → 满势蓄势斩剑意削盾 / 打断 / 墨痕 → 破盾的气势留给下一刀。
- **★三件**：《蓄势》（入门）+ 凝锋诀 + 青冥飞剑（或剑阵）。
- **增强件**：《连环》《满势》《余波》《回锋》；词条 气势获取 / 蓄势斩伤害 / 攻速；剑气斩三重「凝」、凝锋诀三重「锋」；交叉 定风珠（窗口 = 满势斩出手机会）、《拂柳》。
- **关键协同**：凝锋诀 + 一套三连 ≈ 势成；《回锋》（斩中返还闪身）→ 闪身穿过 → 落地右键；飞剑五重"满势斩时诸剑齐出"。
- **弱点 / 被什么克制**：要贴身——飞行的蝠妖、站高处的远程、会跑的敌人拖慢攒势；首领护盾段大部分时间只能靠剑意（有 60% 封顶）+ 撞柱；满势斩起手 0.36 秒，大招预警中贪刀会被打。
- **首领**：
  - 青牙：一段木盾 剑气斩（练一必有）+ 剑意；满势斩一刀 = 1.0 打断值，断召狼长嚎；二段土盾 剑意 3 刀（60% 封顶）+ 引它撞柱（−35%）；威折窗口里蓄势斩 ×1.4 是主力。小心回首咬守背。
  - 碧鳞：火 / 土盾靠五行坛附灵（坛附灵优先于剑附灵，普攻和蓄势斩都带该五行）；潜水突袭 1.7 秒预警 → 闪开，破水而出的后摇里放满势斩。
  - 心魔：没有护盾，纯粹的攒势与读招；它的三连是你的三连，闪过第三段再右键。

### 4.2 五行（法修）——"叠状态 → 相生引爆 → 克盾回气"

- **核心循环**：按相生顺序排法术（木 → 火 → 土 → 金 → 水 → 木），前一门上状态、后一门引爆反应（爆燃 / 熔岩 / 碎甲 / 冰裂 / 藤蔓）；看到护盾换克制法术，《凝神》返还真气。
- **★三件**：《凝神》（新，入门）+ 两门相生法术（区域一：**落石诀 → 剑气斩 = 碎甲**；区域二：缠藤 → 火符 = 爆燃、剑气斩 → 寒冰锥 = 冰裂）+ 紫金葫芦或聚灵阵。
- **增强件**：《轮转》（新）、《灵根》（改）；火阵、火鸦；词条 法力% / 五行亲和 / 冷却 / 真气上限；回气丹；落石诀三重「熔」、剑气斩三重「散」、掌心雷三重「落」。
- **关键协同**：缠藤 + 火阵（站在火阵里的缠绕目标反复爆燃）；葫芦把怪吸进火阵；凝锋诀三重「承」让放法术也攒势（交叉剑势）。
- **弱点 / 被什么克制**：真气预算——一场战斗扔完就只剩普攻；施法前摇 0.1–0.2 秒、寒冰锥 / 火符要瞄准，被快攻打断节奏；分散的小怪群让单体反应不划算；首领吃控折算狼威（ccMode poise），控制型法术对首领打折。
- **首领**：
  - 青牙：木盾 剑气斩 / 掌心雷（《凝神》每发返还 40%）；落石诀 1.2 打断值一发断长嚎；二段土盾缠藤诀（首领缠绕时长减半）；火鸦 / 火符烧图腾（火伤 ×2）。召来的狼正好是葫芦的回气来源——**断不断长嚎变成真气上的取舍**。
  - 碧鳞：教科书打法：寒冰锥 / 止水（火盾）→ 缠藤（土盾）→ 剑气斩 / 掌心雷（木盾）；本体水抗 0.4、土抗 −0.15，破盾后用土 / 熔岩打本体；聚灵阵布在五行坛边。
  - 心魔：没有护盾，真气只够 6–8 发——用反应打短窗口，别空放。

### 4.3 身法（游身）——"读招 → 闪 / 化 → 反打"

- **核心循环**：看预警，贴着出手的那一刻闪身（完美闪身返还冷却 + 25 气势 + 下一击 +50%）或止水化掉一击 → 在反打窗口里出伤（拂柳斩、背击）。
- **★三件**：《流云》（入门）+ 止水诀 + **定风珠**（新）。
- **增强件**：《凌波》《拂柳》（新）、《剑影》、《回锋》；藤引、地行术；词条 闪身冷却；止水诀三重「流」、土遁三重「遁」；八门阵〔二期〕。
- **关键协同**：定风场里敌人前摇、后摇都变慢 → 完美闪身更好抓、反打窗口更长；《凌波》穿过敌人到背后 → 首领背击 ×1.35（青牙月下 ×1.6）；止水三重「流」：反击成立后 2 秒闪身不耗充能。
- **弱点 / 被什么克制**：伤害靠窗口，**不出招的敌人**（远程放风筝、会跑的、读条召唤物）最难受；群怪同时出手时窗口互相覆盖；护盾段几乎只能靠借来的克制法术。
- **首领**：
  - 青牙：最适合身法——双噬第二口 / 回首咬 / 影袭现身都是"读招"（完美闪身狼威 20）；止水反击成立按读招给狼威 20；定风让它 ×0.85（12 秒一次）；地行术赶到月光里断影袭。护盾：木盾 剑气斩 / 《剑影》（金）、土盾 藤引。
  - 碧鳞：大招预警长（潜水 1.7 秒、水柱 1.3 秒）→ 完美闪身的乐园；火盾用止水（水）。
  - 心魔：心魔的招就是你的招，读得最熟。

### 4.4 雷暴（雷修）——"暴击 → 叠雷痕 → 引雷"

- **核心循环**：暴击给目标叠雷痕（新敌人状态，§5.3）→ 雷痕让它受金行伤害更痛 → 叠满 5 层自落天雷；多段命中（飞剑、剑阵、掌心雷跳跃、攻速）就是多次掷暴击的机会。
- **★三件**：《锋锐》（改，入门：暴击给雷痕）+ 掌心雷 + 剑阵（v1）/ 五雷令〔二期〕。
- **增强件**：《雷引》（改：天雷也叠雷痕；**法剑附灵时天雷随附灵五行**）；青冥飞剑（多段命中）；词条 暴击 / 暴伤（新）/ 攻速；掌心雷三重「连」、剑气斩三重「散」（破甲 → 碎甲 / 冰裂）。
- **关键协同**：剑阵（每 0.6 秒斩 2 目标、破甲）在原地替你掷暴击；飞剑自动斩近敌；《剑影》的剑影爆炸也是金伤。
- **弱点 / 被什么克制**：雷痕在**单个目标**上才滚得起来——群怪会把暴击分散掉；自身伤害件几乎都是金行，**只克木盾**，其他四种护盾都得借（附灵剑 + 《雷引》可以补一种）；暴击是概率，短窗口里方差大。
- **首领**：
  - 青牙：一段木盾是主场（掌心雷、剑气斩、飞剑都克）；二段土盾要借缠藤诀 / 藤引，或撞柱；破盾后的易伤 + 雷痕 5 层是最痛的爆发。先砍图腾（狼会把暴击分走）。
  - 碧鳞：火 / 土两段靠五行坛附灵——《雷引》天雷随附灵五行，这一场雷暴反而有解；木盾段是主场。
  - 心魔：单体、无盾，雷痕滚满的最佳对象。

### 4.5 守御（金刚）——"扛 → 蓄震 → 反震"

- **核心循环**：土遁护体 / 镇山印护体吸收伤害 → 吸收量攒成"震" → 护体破碎或到时反震（土行范围伤害 + 眩晕）。站得住，就能挑"吃哪一招"来换反震。
- **★三件**：《金刚体》（入门）+ 土遁护体（练三保底已有）+ 镇山印。
- **增强件**：《不动》（新）；火阵（站桩烧，敌人围上来正好吃火）；止水诀（化一击）；落石诀；词条 气血 / 防御；土遁三重「坚」、止水三重「长」、葫芦吸血（交叉五行）。
- **关键协同**：土遁 + 《不动》+ 火阵：站在火阵中心开护体，让围上来的敌人边烧边打你，护体一碎全吃反震；镇山印三重的"山影护体"也能攒震。
- **弱点 / 被什么克制**：**慢**，伤害多半要先挨打；不挨打的敌人（远程、潜行的影袭）让反震攒不起来；护盾：只克水 / 火 / 金盾，木 / 土盾都要借（剑气斩人人都有，木盾不难；土盾要借缠藤 / 藤引）；狼威获取少（不读招）。
- **首领**：
  - 青牙：土遁吃啸月冲击波（26 + 1.0 攻、范围 8 米）→ 大反震；火阵摆在图腾边烧图腾；二段土盾借缠藤诀。用时最长，但掉血最少——这是给"不想读招也能过"的人的路（技巧 / 力量 / 解法里的"力量"）。
  - 碧鳞：本体土抗 −0.15，镇山印 / 反震打本体很痛；火盾借止水诀（止水本身就是守御交叉件）。
  - 心魔：心魔 0.8 倍你的属性，你厚它也厚——拼的是反震时机。

## 5. 新增与改动的部件

> 每件写：**动词**、机制、与已有部件的差异、量级（交数值策划 03 复核）。

### 5.1 五行流的真气续航（遵守"不自动回复、击杀不回复"）

| 来源 | 类型 | 怎么回 | 代价 / 风险 | 量级（意图） |
|---|---|---|---|---|
| 回气丹 | 丹药（通用） | 吃 | 占丹药栏、要炼 | +40 / 枚（现状）；《凝神》+25% |
| 《凝神》（新） | 心法 · 入门 | 法术命中**被它克制**的护盾 → 返还该次耗蓝 40%（每次施放一次） | 要带对克制法术 | 精英战多 1–2 发（另带法术伤害，见下） |
| 《轮转》（新） | 心法 | 不回，**省**：按相生顺序施法耗蓝 −25% | 法术顺序被锁 | 平均耗蓝约 −15~20% |
| 紫金葫芦（改） | 法宝 | V 吸取：伤害 ×0.3 转真气 | 要把敌人**吸到身边** | **每次吸取回气封顶 15 + 3 ×(重 − 1)**，首领再 ×0.5（数值实测：不封顶时一群小怪一次可回 100–180） |
| 聚灵阵（改：灵池） | 阵法 | 阵内每秒 +6，**每阵总量封顶 36**（二重 47） | 要站在 3.5 米圈里约 6 秒 | 一阵 ≈ 1.5 门法术 |

**《凝神》**（心法 · 五行入门，新）
- 动词：**克**——奖励"换手破盾"本身。
- 机制：真气上限 +25%；回气丹效果 +25%；法术伤害 +25%、法力 +15%；克制法术打护盾再 ×1.25；法术命中被它克制的五行护盾时，返还该次施放耗蓝的 40%（每次施放只返一次；打在非克制护盾、本体上不返）。
- 数值策划实测（03 §4）：入门心法里《锋锐》《连环》是伤害乘区，《凝神》原稿不是，五行流因此慢于中位 6–12%；补「法术伤害 / 法力 / 克制打盾」三项后进带内。
- 差异：现有部件里没有"按克制关系返还"的；它把用户最在意的首领检验（五行护盾换手）变成五行流的资源来源——**强化考题，而不是绕开考题**。练二只有剑气斩时，打狼妖头目的木盾就能感到"法修"。
- 合规性：不随时间、不靠击杀，只在"带对了法术并打中护盾"时返还 → 属明确构筑手段（是否接受请用户确认，§10 第 2 题）。

**《轮转》**（心法，新）
- 动词：**循**——排法术顺序。
- 机制：所施法术的五行 = 上一门法术五行的"所生"（木 → 火 → 土 → 金 → 水 → 木）时：该次耗蓝 −25%（原稿 −40%，数值策划：否则★配置一局法术次数超过非五行流 2 倍）、所附状态强度 +30%。"上一门"只记最近 6 秒内的。
- 差异：反应系统已经奖励"先 A 后 B"的伤害；《轮转》奖励的是真气和状态强度，让相生排序也成为经济决策。三个法术栏正好排成一段相生链（如 缠藤 → 火符 → 落石）。

**《灵根》**（心法，改：替换只有数据、没有掉落的《灵根·火》）
- 动词：**专**——押一行。
- 机制：参悟时择一行（之后要改走散功）：该行五行强度 +40（状态强度 +40%）、该行法术伤害 +12%。
- 差异：《轮转》是"雨露均沾"，《灵根》是"一行打穿"——五行流内部的两条小路。旧档里的《灵根·火》按"火"迁移。

**紫金葫芦**（法宝，改）
- 动词：**吸**（不变）。
- 改动：去掉被动 `mpRegen +1×祭炼`，被动改为"真气上限 +20×祭炼、法力 +8×祭炼"；主动伤害 ×2.5（数值实测：葫芦原来只占五行流输出 1–4%，★件不带输出会拖慢整个流派）；回气只来自 V 吸取（`mpRate 0.3`、`healRate 0.5`、cd 10），**每次吸取回气封顶 15 + 3 ×(重 − 1)**，首领再 ×0.5。首领不被拉动（现状）。
- 祭炼手感：见 §7.2。
- 差异：与聚灵阵分工——葫芦是"冲进怪堆、主动拿"，聚灵阵是"找个地方站住"。

**聚灵阵**（阵法，改：灵池）
- 动词：**聚**——站桩回气。
- 机制：耗蓝 0、冷却 24、持续 10 秒、半径 3.5；主角在阵内每秒 +6 真气，**每个阵总共最多给 36**（≈1.5 门法术；二重 47，数值策划建议）；阵内法术冷却 ×1.5 速（保留 `cdSpeed 0.5`），**去掉 `cdr +20%`**（与冷却加速重复）。
- 差异：现版 12 秒可回 180 真气，相当于一局法术预算的一半以上；封顶让数值策划能算清"一局多几发"，也让"去哪布阵"成为决定（布在五行坛边 / 布在图腾旁）。

### 5.2 身法流

**定风珠**（法宝，木，新，**v1**）
- 动词：**缓**——把敌人的动作放慢，让窗口变大（魔女时间的思路，但由玩家主动放）。
- 机制：V：以自身为心 4.5 米"定风"2.5 秒，场内敌人**动作**（含预警、出招、后摇）×0.6、投射物 ×0.4；首领 ×0.85，同一首领 12 秒一次。耗蓝 15 / 冷却 14。场内敌人受到的伤害 +8%（数值策划：身法★件原来不带输出）。被动：完美闪身返还冷却 60% → 75%；闪身冷却 −3% × 祭炼重数。
- 差异：寒冷是**移动**减速（状态、可叠到冻结），定风是**动作**放慢（招式时间轴整体变慢、预警变长、可以更从容地读）；它不打伤害、不破盾、不控首领——身法流的"放大器"，不是答案。
- 为什么 v1 就要：v1 里身法流没有任何对应的法宝或阵法（八门阵放第二期），没有它身法流永远差一格（玩法系统已采纳，01）。
- 表现：场内贴地一圈淡墨"风纹"（复用阵纹 / ring 着色器），场内敌人身上墨色拖影变长；不加后期 pass。

**《凌波》**（心法，新）
- 动词：**穿**——闪身穿过敌人。
- 机制：闪身路径压到敌人碰撞圈（穿身而过）也算完美闪身：返还冷却、+25 气势、下一击 +50%，**没有慢动作**；同一敌人 4 秒一次、首领 6 秒一次。
- 差异：完美闪身原来只奖励"被动等招"；《凌波》奖励"主动穿过去"，配合首领背击（青牙 ×1.35、月下 ×1.6）。《剑影》是"闪身留一把延迟爆炸的剑"，《凌波》是"闪身本身变成进攻的起点"。

**《拂柳》**（心法，新）
- 动词：**还**——反打。
- 机制：完美闪身或止水反击成立后 1.5 秒内，下一次普攻变"拂柳斩" = 半势蓄势斩（气势 50 档的伤害、范围与剑气），**不耗也不清气势**；对首领 12 秒一次（原稿 8 秒；数值实测身法流首领战蓄势斩类占比已 24–25%，《拂柳》还会 +约 5 个百分点，拉长冷却压回去）。伤害标签 `melee basic fuliu`：**不吃**蓄势斩伤害加成 / 《连环》，**不带剑意削盾、墨痕、控制**。
- 差异：身法流的伤害出口，不依赖攒势；它和剑势流是交叉（拂柳斩不清气势，剑势照样攒）。
- 注意：会推高首领战里"蓄势斩类"的伤害占比，请数值策划一起算（§8.3）。

**《流云》**（心法，改，身法入门）：闪身充能 +1、冷却 −10%（现状）+ **闪身后 1.5 秒内造成的伤害 +20%**（数值策划：入门心法要带伤害乘区，否则身法流整体偏慢；与完美闪身"下一击 +50%"叠加，但只算一次闪身的窗口）。

**八门阵**（阵法，〔二期〕）
- 动词：**破绽**。
- 机制：阵内敌人前摇 +20%、后摇 +30%（首领 +10% / +15%）；三重：阵内完美闪身 / 止水成立后该敌"门开"2 秒，受伤 +25%。
- 差异：定风是"随身、短、强"，八门阵是"定点、长、弱"；和剑势交叉（后摇长 = 满势斩能放出来）。

### 5.3 雷暴流

**雷痕**（新敌人状态，金）
- 动词：**标**——资源放在敌人身上。
- 机制：上限 5 层、持续 8 秒（再叠刷新）；每层令该目标受金行伤害 +3%；**叠满 5 层自动落一道天雷**（伤害 = 4 × 每层量，金行；数值实测雷暴过快，原稿 +4% / 5×）并清空。来源（只在身上有《锋锐》/《雷引》/ 五雷令时生效）：暴击（非 dot / 反应 / 雷）+1 层；《雷引》的天雷命中 +1 层；掌心雷每跳 +1 层。天雷、引爆的雷都不能再触发暴击类效果（RoR2 proc 系数的思路，现有《雷引》已排除 thunder 标签）。
- 差异：剑势的资源在自己身上（可携带），雷痕在敌人身上（换目标就重来）——所以雷暴是"盯一个打"的单体流，和剑势的"小怪攒、精英放"是两种节奏。破甲（金行状态）是"受到所有伤害 +"，雷痕只放大金行，并且会自爆。
- 表现：敌人头顶一圈小金墨点（实例化墨点池，层数 = 点数），不加 DOM。

**《锋锐》**（心法，改，雷暴入门）：暴击 +15%、暴伤 +30% → **+20%**（数值实测雷暴比中位快 33–43%，暴伤下调）+ **暴击给目标叠 1 层雷痕**。它同时是剑势的交叉件（暴击 +4 气势），雷痕对剑势无害。练四不再自动赠送（改进入门五选一，01）。

**《雷引》**（心法，改）：暴击引落天雷（现状）+ 天雷命中再叠 1 层雷痕 + **法剑附灵时天雷改为附灵五行**（没有附灵仍是金）。最后一条让雷暴有一条自己的护盾解：带一把对的附灵剑。

**五雷令**（法宝，金，〔二期〕）
- 动词：**引**——主动引爆。
- 机制：V：指定处 8 米内所有带雷痕的敌人各落一道雷，每层 12 + 0.5 × 法力金伤，清空雷痕；没有雷痕的敌人只吃 1 层的量。耗蓝 18 / 冷却 10。被动：暴伤 +5% × 祭炼重数。
- 差异：雷痕自爆是被动的"满 5 才响"；五雷令让你挑时机（破盾易伤、威折窗口里一次引爆）。v1 用剑阵 + 飞剑 + 雷痕自爆兜底，所以可以放第二期。

**暴伤词条**（新，法剑 / 玉佩，灵 / 宝 / 仙 10 / 15 / 25%）：现有词条池只有暴击率没有暴伤；新增会稀释池子（法剑池 9 → 10 条），数值策划定权重。

### 5.4 守御流

**《不动》**（心法，新）
- 动词：**震**——把挨的打还回去。
- 机制：土遁护体 / 镇山印"山影护体"（三重）吸收的伤害累计；护体破碎或到时，以 4 米震波返还（吸收量 × 1.5 + 0.8 × 法力，土行，眩晕 0.8 秒，首领折算狼威）；身上有护体时不被击退。
- 差异：土遁护体原来是纯守御（功法 v2 有意留的"纯保命"）；《不动》给它进攻收益链。和土遁三重「崩」不重复：「崩」是土遁自带的小震开（v1 不做，见 §7.1 改为「遁」），《不动》是按吸收量结算的大反震。
- 量级：挨满一盾（练七约 120 + 6 × 48 ≈ 410）→ 约 600 + 40 ≈ 1.5 发寒冰锥。

### 5.5 剑势流：不加新件，只修获取

- 剑势已经最完整（心法 5 本、词条 3 条、剑意、凝锋、飞剑、剑阵），**本方案不给它新增任何部件**；只把它的心法从 3–5% 罕见掉落提到常见、按"身上心法流派"偏置（01 §4.2、03）。
- **剑意封顶**：首领每段护盾，剑意累计最多削 60%（现在 20% / 刀，5 刀可削穿）；剩下 40% 必须靠克制五行 / 撞柱 / 普攻磨。精英不封顶（剑意本来就是"没带克制时的后备"）。

### 5.7 淘汰的候选（为什么不做）

| 候选 | 原因 |

## 7. 成长轴在战斗上的表现（手感，不只是数字）

统一计量"重"（玩法系统 01）：法术一–三重、阵法一–三重、法宝一–五重。规律：**数档和形档交替**（Hades 石榴 / 锤子）。

### 7.1 法术：二重 = 数，三重 = 变体二选一

- **二重**：伤害 +12% → **+15%，并加耗蓝 −15%**（数值策划 2026-11-18：只加 12% 伤害对一门占流派 10–25% 输出的法术，总 DPS 只多 1–3%，6 点悟性不值；加上耗蓝 −15%，真气紧的流派约多放 18% 次数。战斗同意）。
- **三重**：**变体二选一**，改"形"不改动词（定位查重不变）；解锁后在洞府功法匣免费切换，局内不切（01）。取代现有"冷却 −15%"（会把剑气斩压到 6.8 秒，越过 8–18 秒的线）。
- 每个变体挂一个流派，**同一门法术的两个变体通常挂不同流派**——这是交叉件的第二个来源。

| 守御 | 借（剑气斩） | 借 | 落石诀 / 《不动》/ 镇山印 | 止水诀 | 火阵 | 借 借 | ✓ 借 借 |

- **没有一个非五行流派能用自己的件克全部五种护盾** → 换手考题对四个流派都成立；五行流能全覆盖，但受 3 个法术栏 + 真气预算限制，仍要"出门前选对三门"——考题对它是"准备"而不是"临场"。
- 规则（落地时写进测试）：①剑意每段首领护盾累计 ≤ 60%；②新伤害件全部带五行、照 `SHIELD_TUNE`（克制 ×2、其他 0.2、无属性 0.25、附灵 0.35）结算：天雷 / 引爆 = 金（《雷引》附灵时随附灵），反震 = 土，葫芦 = 无属性；③定风、凌波、拂柳不影响护盾，拂柳斩不带剑意；④首领一阶段不能被一刀跳过（现有规则）。
- 雷暴打青牙二段 / 碧鳞前两段最吃亏，这是它"单体爆发最高"的代价；补救是附灵剑 + 《雷引》随附灵、碧鳞五行坛附灵。数值策划按 §8.3 的目标看它是否掉出带外，掉出就先加强"破盾后"的雷痕收益，**不给它无视护盾的手段**。

### 8.3 强度不能只有剑势能打（交数值策划 03 验证）

| 指标 | 目标 | 怎么测 |
|---|---|---|
| 同档位五个流派打青牙（练六七）/ 碧鳞（练八九）的用时 | 与中位数相差 ≤ 20%；守御允许 +35%，但掉血 / 用丹要明显更少 | `num_ttk curve=` 按流派配五套 curvePreset（★三件 + 该档常见增强件） |
| 首领战里"蓄势斩类"（蓄势斩 + 拂柳斩）的伤害占比 | 剑势流 ≤ 40%；其他流派 ≤ 20%（15–25% 是全体目标） | num_ttk 按伤害标签分账 |
| 一局可放法术次数 | 五行流 ≈ 其他流派的 1.6–2 倍（不是无限） | 数值策划的真气预算表 |
| 读条打断 | 每个流派都有 ≥ 1 种"一次或两次动作打满 1.0 / 1.5"的办法，但不能是零成本 | boss_qingya 打断值断言 |

**数值策划实测（2026-11-18，03 §4；`num_ttk bcurve=1`，主角无敌、本体 DPS + 木 / 土 / 火破盾秒数换算）**，按原稿数值：

| 流派 | 练六打青牙（相对中位） | 练九打碧鳞（相对中位） | 首领战蓄势斩类占比 |
|---|---|---|---|
| 剑势 | −26% | −41%（35 秒） | 28–32% ✓ |
| 雷暴 | −33% | −43%（34 秒） | 18–20% |
| 五行 | +12% | +6%（62 秒） | 19–31% |
| 身法 | +6% | +5%（62 秒） | 24–25% |
| 守御 | 0% | 0%（59 秒） | 26–35% |

- 原因：**★件本身带不带输出**——飞剑占剑势 / 雷暴伤害 15–26%，葫芦 / 镇山印只占 1–4%；《锋锐》《连环》是伤害乘区，《凝神》《流云》《金刚体》原稿不是。教训写进本岗位 坑.md。
- 采纳的调整（已改进 §5 / §7）：葫芦主动 ×2.5 + 被动法力；《凝神》法术伤害 +25%、法力 +15%、克制打盾 ×1.25；定风场内受伤 +8%；《流云》闪身后 1.5 秒内伤害 +20%；镇山印主动 50 → 90；剑势《连环》每层 +4% → +3%、《蓄势》斩伤 +10% → +5%；雷暴《锋锐》暴伤 +30% → +20%、雷痕每层 +4% → +3%、自爆 5× → 4×；剑意封顶 60%。数值策划估算调整后五派都在 ±20% 内。
- 关于"剑势不动"：剑势**不加新部件**这一条不变；数值实测说明它快的原因之一是★法宝自带输出，所以接受对它两本心法的**小幅下调**（不动用户 v1.3 拍板的蓄势斩单刀伤害、不动剑意本身）。战斗这边不再把它列为分歧；若用户坚持剑势一点不动，备选是只加强其他四派（03 §8 第 3 题）。
- 蓄势斩类占比：身法 / 守御超 20% 是因为分母（总输出）低，加强后回落到约 20%；《拂柳》对首领冷却已拉到 12 秒。落地后用 `node tools/run.mjs num_ttk "scene=run&region=r2&bcurve=1&build=jian,fa,bao,shen,shou&levels=6,9&sec=30&els=wood,earth,fire"` + `tools/build_growth/balance.py` 复测。
