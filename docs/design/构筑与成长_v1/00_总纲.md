| 守御 | 《不动》反震；镇山印主动 50 → 90 | +7% / +12%（允许 +35%，EHP 为其他派 1.7 倍） |
| 剑势 | 《连环》每层 4% → 3%、《蓄势》斩伤 10% → 5%、剑意每段封顶 60%（不加不减部件） | 0% / −18% |

调整后青牙练六真人约 120 秒、碧鳞练九约 85 秒，与青牙 v2 口径接近，**首领气血不用改**。落地后用 `num_ttk bcurve=1` 复测，标准：±20%（守御 +35%）、蓄势斩类占比 剑势 ≤ 40% / 其他 ≤ 20%。

**青牙实测**（`05_青牙实测.md`，真青牙 × 练四–七 × 五派 + 现状通用 × 莽 / 闪 / 熟三种机器人，每格 10–12 次）：
- "练四就能杀青牙"属实，但**不是构筑提前造成的**：现状通用配装练四闪 67%、练五 100%（青牙 v2 的 T2 标准是 10–30%）；流派配装练四闪 42–58%，只有守御 92%。→ 练四传功不用挪。
- 练六给法宝只在"青冥飞剑 + 莽打"上出界（飞剑自动清召来的狼，0% → 80%）。→ 法宝栏练六不用改回练七。
- 建议青牙**方案 C**（不动气血）：威折处决 12% → 6% 最大气血、狼威阈值 100 → 130、攻击 40 → 52。实测练四闪回到 10–30%、练五 40–70%，剑势练六莽 80% → 30%，练六–七闪 / 熟仍 ≥ 90%。
- 守御：《金刚体》气血 +25% → +15%、防御 20 → 12 后，练四–五仍偏安全（闪 30% / 90%），建议作为"新手的安全选择"接受。

**真气**（03 §4.5）：首领战里真气不卡任何流派，卡的是冷却。一局可放法术：非五行约 15 次（练九），五行★（凝神 + 葫芦 / 灵池）约 1.6–1.9 倍，满配（凝神 + 轮转 + 葫芦 + 灵池 + 二重）约 3 倍、约为冷却上限的一半——不是无限。为此：**葫芦每次吸取回气封顶 15 + 3 ×（重 − 1）**（不封顶时一群小怪一次可回 100–180），首领再 ×0.5；灵池每阵 36（二重 47）；《轮转》相生耗蓝 −25%；《凝神》回气丹 +25%。全部符合"不自动回复、击杀不回复"。
