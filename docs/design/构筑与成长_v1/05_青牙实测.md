# 墨途 · 构筑与成长 v1 · 05 青牙实测

> 岗位：数值策划。任务：主管（用户已同意）——用**真青牙**实测"构筑提前后，练四 / 五 / 六打青牙是否太容易"。
> **只测不落地**：没改 `src/` 的任何代码和数据，没做 git；测试改动只在 `tools/scenarios/`、`tools/build_growth/`、`work/`。
> 背景：03 §4 的青牙数字来自假人（青牙 v2 的"入睡 → 入场演出"让旧 `curve=qingya` 刷出的青牙不进战斗），没算狼威、撞柱、处决、打断，也没测练四–五；而 00 总纲把入门心法提到练二、★法术提到练四（传功）、★法宝提到练六。

（结论与表格见下方各节，文末有原始数据路径与脚本用法。）

## 1. 方法

### 1.1 打的是真青牙

- 底座是前任数值策划的 `tools/scenarios/num_qingya.mjs`（青牙 v2 控制器、5 根狼牙石柱、3 个图腾与召狼、月光、读条、狼威 / 威折 / 处决、二阶段全部按 `src/data/bosses/qingya.js` 现行规则结算）。新建 `tools/scenarios/num_qingya_build.mjs`，只加了三件事：
  1. **流派配装**（`qyPreset`）和**数值套**（`set`）：`cur` = 现行数据；`orig` = 03 原稿（02 草案：凝神真气 +25%、葫芦去被动回气、灵池 36）；`bal` = 03 §4.4 平衡后（在 orig 上：葫芦主动 ×2.5、被动法力 +8×重；凝神法术伤害 +25%、法力 +15%；镇山印主动 50→90；连环每层 +3%；蓄势斩伤 +5%；锋锐暴伤 +20%；二重伤害 +15%、耗蓝 −15%）。全部只改页面内存。
  2. **同一页面连打**：每次结束移除青牙、把撞碎的石柱 / 砍倒的图腾放回（碰撞体加回）、复位 `run.bossSpawned`，主角走回谷口让关卡重新生成青牙（非首次挑战，短版入场 1.2 秒）。
  3. **加速**：关 3D 渲染，每 16 毫秒额外推进 8 步玩法时间；同时把 `performance.now` 换成随玩法时间走的虚拟时钟（受击无敌、完美闪身、慢动作、处决演出都按真实时间计时，不换的话 8 倍加速时受击无敌变成 3.2 秒，莽机器人练四胜率从 0% 变成 92%——已和不加速对过：莽练四 剩血 82–83%、用时 58 秒，两者一致）。
- 每次试验：主角不无敌（致命一击记"阵亡"并停止），带回春丹 3、回气丹 3，开场满势；超时 240 秒（玩法时间）。

## 2. 结论先行

1. **"练气四层就能杀青牙"是真的，但不是构筑提前造成的**：现行游戏的通用配装（剑气斩 + 缠藤诀 + 练四送的《锋锐》）在练四就已经 闪 67% / 熟 83% 胜，练五 闪 / 熟 100%，远超 T2 的 10–30% / 40–60%。00 总纲的流派配装（入门心法 + 传功★法术）在练四–五**和现状差不多甚至更低**（闪 42–58% vs 67%）——唯一更高的是**守御**（练四 闪 92%、熟 100%）。
2. **构筑提前真正改变的是 T3 的"莽"**：练六给★法宝后，带**青冥飞剑**的剑势 / 雷暴，莽机器人练六胜率从 0% 跳到 **80–90%**（标准 20–40%）；没飞剑的五行 / 身法仍是 0–10%，守御 40%。原因不是飞剑的伤害（伤害 ×0.6 后仍 90–100%），而是**环身飞剑自动清掉青牙召来的狼**——莽机器人原本死在"狼 + 青牙"的夹击里。闪 / 熟在练六–七全部 ≥ 90%（在带内），但剑势 / 雷暴的掉血只有 27–48%，比"掉血 50–80%"更轻松。
3. **练四→练五是一道悬崖**：同一配装，闪的胜率从 40–67% 跳到 83–100%（多一块玉佩、一层境界、★法术二重）。T2 用"练四–五"一个档写目标，实测两层差得很远——下面的建议按"练四偏低、练五偏高、平均落在带内"来定。
4. **最危险的组合**：守御 练四（闪 92% / 熟 100%）；剑势 / 雷暴 练六带飞剑（莽 80–90%、闪掉血 < 50%）；任何流派 练五（闪 83–100%）。
5. **建议**（§5）：T2 的问题在青牙本身，用不动气血的三个旋钮——**威折处决 12% → 6% 最大气血、狼威阈值 100 → 130、攻击 40 → 52**（方案 C）。实测在五个流派上：练四 闪 10–30%（进带）、练五 闪 40–70%，两层平均 25–45%；练六–七闪 / 熟仍 ≥ 90%；**剑势练六带飞剑的莽从 80% 降到 30%（进带）**，飞剑掉血也回到 54%。守御另需《金刚体》气血 +25% → +15%（防御 20 → 12），即便如此练四–五仍偏安全（闪 30% / 90%），列为请用户选的题。**不建议把传功挪到练五**——练四–五的胜率主要由境界、玉佩和《锋锐》级的通用件决定，★法术不是主因（现状配装没有任何★件，练四闪就有 67%）。

## 4. 原因（输出、破盾、打断、狼威哪一项）

| 出界 | 主要原因 | 依据 |
|---|---|---|
| T2 闪 / 熟 偏高（所有配装） | **狼威 → 威折处决给得太多** + 闪避机器人几乎不吃伤害 | 每场 3–4 次威折、1–2 次处决，处决约占伤害 20%；把处决 12% → 6%、阈值 100 → 130 后，练四闪 67% → 22%（方案 A）。完美闪身每次 +12 狼威，会闪的人威折更快 |
| T2 练四→练五悬崖 | 境界 + 玉佩 + 二重叠加，正好跨过"活得过二阶段"的线 | 同一配装胜率 +40 个百分点；首领侧的旋钮对练四压得多、对练五压得少（§5.1） |
| 守御 T2 偏高 | 生存：《金刚体》气血 +25%、防御 +20 + 土遁护体 | 闪掉血练五只有 74%（其他流派 130–150%）；金刚体降到 +15% 后练四闪 92% → 60%、熟 100% → 80% |
| T3 莽 剑势 / 雷暴偏高 | **飞剑自动清狼**（不是伤害） | 无法宝 0%、有飞剑 80–90%；飞剑环身伤害 ×0.6 后仍 90–100%；现状练七（飞剑在练七给）莽同样 100% |
| T3 莽 五行 / 身法 偏低（练六 0–10%） | 没有自动清狼 / 自动输出的件，莽机器人不闪不打断 | 练七加第三法术 + 阵法后 50–60% |
| T3 闪掉血偏低（剑势 / 雷暴 24–48%） | 飞剑让输出窗口外也在掉血，战斗缩短到 45–64 秒 | 胜者用时 vs 其他流派 88–102 秒 |

## 5. 调整建议与调整后的实测

### 5.1 首领侧敏感度（现状通用配装，每格 10 次；只改页面内存）

| 方案 | 改动 | 练四 闪 / 熟 | 练五 闪 / 熟 | 练六 莽 / 闪 / 熟 | 练七 莽 / 闪 / 熟 |
|---|---|---|---|---|---|
| 现状 | — | 67% / 83% | 100% / 100% | 0% / 100% / 100% | 100% / 100% / 100% |
| A | 处决 12% → 6%、狼威阈值 100 → 130 | 22% / 60% | 90% / 90% | 0% / 100% / 100% | 100% / 100% / 100% |
| B | 攻击 40 → 52 | 30% / 40% | 80% / 100% | 0% / 80% / 90% | 100% / 100% / 100% |
| **C** | **A + B** | **0% / 0%** | **70% / 80%** | 0% / 100% / 100% | 100% / 90% / 100% |
| C-lite | 处决 8%、阈值 120、攻击 48 | 50% / 30% | 80% / 90% | — | — |
| D（参照） | 气血 15000 → 20000 | 20% / 40% | 50% / 90% | 0% / 100% / 100% | 90% / 100% / 100% |

- 处决与狼威（A）对**会闪的人**最有效：完美闪身每次 +12 狼威，闪机器人威折更快、处决更多。攻击（B）对**所有人**加压。两者叠加（C）在练四压得最狠、练五仍放行，练六–七几乎不动（第二次闪身 + 法宝 / 寒冰锥跨过了门槛）。
- 气血 +33%（D）效果和 C 接近，但用户 / 战斗设计倾向不动气血，所以推荐 C。

### 5.2 方案 C 在各流派上的复核（平衡后数值；守御另加《金刚体》+15%；每格 10 次）

| 流派 | 练四 闪 / 熟 | 练五 闪 / 熟 | 两层平均 闪 / 熟 | 练六 莽 / 闪（有法宝） |
|---|---|---|---|---|
| 现状通用 | 0% / 0% | 70% / 80% | 35% / 40% | 0% / 100% |
| 剑势 | 10% / 30% | 60% / 40% | **35% / 35%** | **30% / 90%（掉血 54%）** |
| 五行 | 20% / 30% | 70% / 70% | 45% / 50% | — |
| 身法 | 10% / 10% | 40% / 90% | 25% / 50% | — |
| 雷暴 | 20% / 10% | 60% / 70% | 40% / 40% | 90% / 100%（飞剑代五雷令） |
| 守御 | 30% / 80% | 90% / 80% | **60% / 80%** | — |
| 标准 | 10–30% / 40–60%（T2） | | | 20–40% / ≥ 60%（T3） |

读法：
- 方案 C 下，**闪在练四全部进带（10–30%）**，练五仍偏高（40–70%）；按"练四–五"两层平均，剑势 / 五行 / 身法 / 雷暴 闪 25–45%、熟 35–50%，接近 T2 标准。练四就碰青牙会被教育，练五开始有一半机会。
- 熟在练四只有 10–30%，比标准 40–60% 低：熟机器人的"读招"只有九成闪 + 打断 + 撞柱，比真高手笨（例如不会留回春丹、不会退出谷重来）。真人高手预计会高 10–20 个百分点，落回带里。
- **剑势练六带飞剑**：莽 80% → **30%**、闪掉血 41% → 54%，两项都回到 T3 标准内。**雷暴练六**的数据用飞剑代五雷令（五雷令第二期，不带自动清狼），所以 90% 不代表真实雷暴；按 v1 的件（雷暴本命应选五雷令或镇山印），预计接近五行 / 身法（练六莽 0–10%）。
- **守御**仍是最安全的：练四闪 30%、熟 80%，练五闪 90%。《金刚体》再降意义不大（生存来自土遁护体的护盾 + 金刚体 + 镇山印叠加）。两种处理放进用户题：接受"守御 = 新手的安全选择，T2 允许 +20 个百分点"，或者土遁护体一重吸收 120 + 6×法力 → 80 + 4×法力（未测，估计练四闪再降 15–25 个百分点）。

### 5.3 按问题给的结论

| 问题 | 结论 |
|---|---|
| 构筑提前会不会让练四–五打青牙太容易？ | **不会比现状更容易**（守御除外）。现状本身就太容易：练四闪 67%、练五 100%。要修的是青牙，不是构筑节奏 |

## 7. 局限

- 每格 10–12 次，胜率的 95% 区间约 ±25 个百分点；判"出界"只用区间也在带外的格。落地后用 `trials=30` 复测方案 C 的关键格（练四 / 练五 闪熟、练六 莽）。
- 定风珠、五雷令、雷痕、凌波、拂柳、不动、轮转、凝神克盾返还都没实现，用代用件或缺省；按 03 §4 的解析，身法 / 雷暴 / 守御还会再强 5–8%。
- "熟"机器人比真高手笨（不会拉开回血、不会撤出重来、不会刻意等月光），"闪"机器人七成闪避接近一般玩家；真人的手感以试玩为准。
- 青牙每次都从短版入场开始（非首次挑战），开场满势、带 3 枚回春丹 / 3 枚回气丹；首次挑战的完整入场 4 秒不影响胜负。
