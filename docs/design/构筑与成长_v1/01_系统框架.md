## 0. 一页结论

| 问题 | 本框架的回答 |
|---|---|
| 成长轴太多会不会过载 | 收成**三条局外大轴 + 一层局内赌注**：**境界**（修为 → 灵泉）、**功法**（悟性 → 参悟 / 法术加重）、**法器**（材料 → 炼器 / 祭炼法宝与阵盘），外加"装备与局内拾取"这一层赌注。三条轴各对应一种资源、一个洞府站点；"几重"这一个计量单位通用于法术、阵法、法宝。**不新增货币、不新增局内成长系统** |
| 投入了会不会被搜打撤吞掉 | 一条总原则：**投入越深越安全**。"重"（法术 / 阵法）和祭炼都绑在已学功法、已拥有法宝上，永不丢；装备是赌注层（区域二可遗落、可取回、可认主）；首杀和选择点的奖励进护身格 |
| 什么时候做构筑选择 | 前半程补选择点：**练二 入门心法五选一**（剑势 / 五行 / 身法 / 雷暴 / 守御，定方向）→ **练三 第二法术**（收集带来的取舍）→ **练四 玄机子传功**（送本流派★法术完本，数值模拟证明随机掉落赶不上节奏）→ 第一次加重 → **练六 第一个"法宝匣"三选一 = 本命**；后半程 **剑修遗府 阵盘三选一**、法术三重**变体二选一**、练八第二心法、筑基一次免费重修。第 2–7 局**每局至少一个构筑决定**（现状：前 4 局几乎为 0） |
| 选错了怎么办 | 三选一选的是**先后，不是有无**：没选的件之后在重探 / 重战 / 夜明宝箱里还能拿到，变成之后出行的目标。装配与已解锁的变体随时免费换；"重"与祭炼在内观阁**散功**按比例返还；**筑基突破时一次全额重修** |
| 栏位节奏 | 心法栏 1 从练四提前到**练二**；法宝栏从练七提前到**练六**（青牙宜斩的境界）；其余不变。练七前就有心法 + 2 法术 + 法宝三类部件可拼 |
| 法宝匣（顺序无关） | 三个来源：**练六突破保底（玄机子）/ 青牙首杀 / 剑修遗府首通**，都是 `key` 物品进护身格、回洞府打开。**谁先打开谁是三选一并成为本命**，第二个二选一，第三个直接得最后一件——栏不会空，也不必送凡品基础款，三个来源都不浪费（青牙 v2 不是硬门，玩家顺序各不相同） |
| 法术流的真气 | 三件分属三个栏位：心法《凝神》（真气上限 / 回气丹药效，**不回蓝**）、法宝紫金葫芦（**吸取**回气）、阵法聚灵阵（**阵内**回气）。都是"明确的构筑手段"，不违反"真气不自动回复、击杀不回复" |
| 与主管三方向的关系 | 采纳**方向一（补缺口）全部 + 方向三的入门定向 + 方向二的本命三选一**，但做了三处减法：①偏向掉落**跟着你身上装的心法走**，不另立"道途"存档概念；②阵盘三选一放在剑修遗府、不再加"二选一"界面；③改选不用专门的"静室改选"系统，统一走散功 / 重修（§3.4） |

## 3. 成长轴全景

### 3.1 轴表

| 轴 | 局外 / 局内 | 玩家看到的"量" | 资源 | 在哪做 | 身陨会丢吗 | 上限（v1） | 解决什么 |
|---|---|---|---|---|---|---|---|
| **境界** | 局外永久 | 练气一层 → 筑基一层 | 修为（感悟 + 炼化 + 聚气丹） | 灵泉 | 不丢（感悟已入体） | 筑基一层 | 基础属性、**开栏**、身法钥匙（二段跳 / 御剑） |
| **功法 · 收** | 局外永久 | 已学的法术 / 心法 / 阵法 | 残页、完本、遗府首通、首杀、选择点 | 仓库（参悟） | 已学的不丢；**未带回的残页**按储物袋规则 | 12 法术 / ~14 心法 / 3 阵法 | 广度：能拼出哪些流派 |
| **功法 · 重** | 局外永久 | 法术 一–三重（二重 = 伤害 +15%、耗蓝 −15%；**三重 = 变体二选一**，解锁后随时免费切换）） | **悟性**（重复残页 / 完本化来；补页也用它；数值建议新增 拓碑 +1、遗府首通 +4、青牙 / 碧鳞首杀 +6 / +10） | 内观阁（功法匣） | 不丢 | 三重 | 深度：主力法术越用越强，旧技能不过时；变体把同一门法术挂到不同流派（设计文档 §4.1 "强化代替新增 / 三选一变体"） |
| **法器 · 祭炼** | 局外永久（绑在那件法宝 / 那个阵法上） | 法宝 一–五重；**阵法 一–三重**（新；二重 = 数，三重 = 改手感；用**阵纹**——阵台首探后可重复刷的材料，关卡定点——加灵石，数值定量） | 灵石为主（本命 2 重 120 / 3 重 300 / 4 重 700 / 5 重 1500，4–5 重筑基后）+ 铁精、妖丹碎片、灵玉、首领材料（**不用精英妖丹**——聚气丹已卡在它上面；不新增货币） | 丹器房 · 炼器鼎（新增"祭炼"分类） | 法宝栏不参与装备遗落；未带回的法宝按储物袋规则 | 五重（非本命三重，§3.3） | 深度：本命法宝成为流派核心 |
| **法器 · 装备** | 局外持有、**有风险** | 法剑 / 法衣 / 玉佩 品级 + 随机词条 | 掉落、炼器、重铸、注灵、附灵 | 丹器房 · 炼器鼎 | 区域二随机 1 件未保护装备进遗落袋（可取回）；认主 / 护器符保护 | 仙品 + 特殊词条 | 调数值方向（暴击 / 气势 / 法力 / 闪身…）、给流派补件 |
| **局内** | 只在这一局 | 捡到的装备当场换、符丹、炼化增益（出发前） | 局内拾取 | 储物袋 | 撤回才算 | — | 局内应变；**不新增局内成长系统** |

> 洞府里其余成长（储物袋 / 锦囊 / 丹药囊 / 设施等级）属于"搜打撤能力"，不算构筑，本方案不动。

### 3.2 各轴之间的关系（一句话版）

```
          修为 ──► 境界 ──► 开栏（几格）、属性、身法钥匙
                              │
  残页/完本/首杀/选择 ──► 功法·收（能装什么）──重复残页──► 悟性 ──► 功法·重（法术 / 阵法 几重）
                              │
  首领 / 精英材料 + 灵石 ──► 法器·祭炼（法宝 几重）        装备词条（往哪个方向堆数值）
                              │
                     出行准备 / 内观阁：把"能装的"装进"开了的格"＝构筑
```

- **境界只管"几格"和底子，不管"装什么"**：开栏的唯一来源是境界（`slotOpen` 单一来源，栏位与残页那次定的规则不变）。
- **功法管"有什么牌"，悟性管"牌多强"**：重复残页不浪费（化悟性），悟性在"补页学新的"和"给旧的加重"之间取舍——这是一个**持续的小决定**，而不是一次性的。
- **法器管"核心件"和"数值方向"**：法宝是流派核心（飞剑 = 剑势、葫芦 = 法术、镇山印 = 守御），装备词条决定往哪堆数值。
- **一个计量单位"重"**：法术几重、阵法几重、法宝几重。玩家只需记住"**法术用悟性加重；法宝和阵盘是器，用材料祭炼**"。阵法原先拟用悟性，2026-11-18 改为阵纹：悟性筑基前只有约 30 点，法术已经要取舍，阵法再分会更紧；阵盘本身是器物，归到炼器鼎也更顺；阵纹给了阵台一个重刷理由（关卡建议、战斗同意）。

### 3.3 概念预算（防过载）

| 新增给玩家的概念 | 首次出现 | 是新词吗 | 备注 |
|---|---|---|---|
| 入门心法五选一 | 练二（第 2 局后） | 否（心法已有） | 玄机子对话 + 五张卡（五个流派各一本：蓄势 / 凝神〔新〕/ 流云 / 锋锐 / 金刚体） |
| 法术加重 | 第一次有 6 悟性时（约第 3–4 局；数值建议新增悟性来源后第 4 局累计约 11） | 否（"重"已在功法 v2、调试面板里） | 只是把已有逻辑接上界面 |
| 法宝匣 · 本命三选一 | 练六（第 4 局回府） | 否（本命已有） | 本命的新含义：祭炼上限 5 重，非本命 3 重 |
| 祭炼 | 拿到第一件法宝后 | 否（法宝描述已写"可祭炼"） | 炼器鼎多一个分类 |
| 阵盘三选一 + 阵法祭炼 | 第一个阵盘匣（剑修遗府或断涧东阵台，第 4–5 局） | 否 | 与法宝祭炼同一页（炼器鼎） |
| 法术三重变体 | 第一门法术到三重时（约第 5–6 局） | 是（"变体"） | 二选一，解锁后随时免费切换 |
| 散功 / 筑基重修 | 需要时 | 是 | 内观阁里一个按钮 |

合计 **2 个新词**；玩法评审 P2 统计的前 3 局 33 个概念**不增加**（新的精进系统全部在第 4 局以后出现）。

**明确不做的**（防过载）：心法等级、局内临时祝福 / 顿悟、单独的"道途"存档值与界面、第二种精进货币、装备强化等级、变体的改选费用。

### 4.2 掉落偏置：跟着身上的构筑走（不另立"道途"）

- 主管方向三的"六成落在所选流派"会引入一个存档里的"道途"值和改道途的界面。本方案改为：**出发时按身上装的心法、法宝的流派标签计偏置**（心法、法宝、阵法在数据里带 `school` 标签，由战斗设计定）。偏置只作用于**心法、阵盘、法宝**的"抽哪一件"，不改变"掉不掉"（不动经济总量，同 `GEAR_SLOT_GATE` 的做法）。
- 好处：①不需要"改道途"——换个心法出门，偏置就跟着换（Hades 镜子"随时免费切换"的思路）；②玩家可读："身上装的是剑势心法，掉的剑势心法就多一些"；③入门五选一选错了也不会被锁死。
- **与关卡的"分区道途"并存**（`04_投放与地图.md`）：每个区域每个流派有一浅一深两个分区，分区里的亭 / 精英 / 灵光箱优先出这两个流派的心法。这是**地图属性**（不进存档、不用改选），回答的是"去哪刷"；身上偏置回答的是"刷到哪本"。两者相乘时由数值封顶（同流派合计不超过约 75%），保证别的流派仍掉得出来。
- 需要"单一流派"判断的地方（如关卡的道途碑必亮）一律读**心法栏第一格（入门心法）所属流派**，同样现算、不存档（战斗在 02 给每本心法标流派）。
- 比例（数值 03 §6 定，2026-11-18）：**替换式 b = 0.5**——掉到心法时以 50% 概率换成本流派池里还没有的一本；叠关卡分区道途 70% 后，自家分区约 71%、分区外约 53%，封顶 75%。我初稿的"同流派权重 ×2"在分区外只有 11%，等于没偏，已撤回。完本"优先未学"照旧。

### 4.3 选错了怎么办（代价阶梯）

| 想改的东西 | 代价 | 理由 |
|---|---|---|
| 装哪门法术 / 心法 / 阵法 / 哪件法宝 | **免费**，洞府或出行准备随时换（已有） | 装配是情境决定（看去处护盾），不应该收费 |
| 法术三重的变体 | **免费**切换，但只在洞府功法匣（及将来若做的石灯换功法）里切，局内战斗中不切；v1 先做 6 门：剑气斩、凝锋诀、落石诀、止水诀、掌心雷、土遁护体 | Hades 镜子红绿版随时切换；代价只在解锁三重那一下 |
| 入门心法选了不喜欢的 | **改入门**：内观阁付少量灵石（数值建议 30）换另一本入门心法（旧的收回）；练四传功只发一次，改入门后不重发 | 数值模拟显示随机心法在筑基前大多拿不到，"其余四本在掉落池"不够兜底，所以给一个便宜的改法；传功不重发防止花 30 灵石刷齐五门★法术 |
| 本命选了不喜欢的 | **换本命**：新本命必须已有；旧本命祭炼降到 3 重（非本命上限），超出部分的材料按散功比例返还 | 本命 = 深度承诺；换要付代价，但不归零 |
| 悟性加错了重（法术 / 阵法） | **散功**（内观阁）：按比例返还悟性（数值建议 80%） | Hades 退暗晶要付钥匙：小代价、可反悔 |
| 祭炼押错了法宝 | 同上，散功返还祭炼灵石与材料（数值建议 80%） | 同上 |
| 整体推倒重来 | **筑基突破时一次全额重修** | 大境界 = 天然的重新开始点（"筑基洗髓"的修仙语义） |

### 4.4 与搜打撤风险的关系

| 东西 | 撤离 | 身陨 · 区域一 | 身陨 · 区域二 | 保护手段 |
|---|---|---|---|---|
| 境界、已学功法、悟性、"重" | ✔ | ✔ | ✔ | 天然（局外） |
| 已有法宝的祭炼重数 | ✔ | ✔ | ✔ | 绑在法宝上；法宝栏不参与装备遗落（最小闭环 §5.2） |
| 首杀 / 选择点奖励（法宝匣、遗府阵盘匣、完本） | ✔ | ✔ | ✔ | 击杀 / 拾取即进护身格（沿用 `secureFirstKill`） |
| 本局捡到的残页、心法、阵盘、普通法宝 | ✔ 入库 | 保留 50% | 进遗落袋（60% 可取回） | 贴身锦囊（1 格物品可放） |
| 身上的法剑 / 法衣 / 玉佩 | ✔ | ✔ | 随机 1 件未保护的进遗落袋（100% 可取回） | **滴血认主**（1 件永久）、护器符（1 局） |

- **本命 ≠ 认主**：本命管**法宝的深度**（祭炼上限），认主管**装备的安全**（区域二不遗落）。两个词各管一件事，不再重叠（原 §5.3"本命永不掉落"在只有一个法宝栏时没有实际作用）。
- 构筑核心件（法宝、心法、主力法术）都在"不丢"那一层；**赌桌上的是装备词条和本局收获**——"穿着好装备去高区"仍然有压力，但不会因为一次身陨失去流派。
