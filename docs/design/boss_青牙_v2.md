## 0. 一页总览

**青牙不再是"3000 血 + 两层护盾的大号狼"，而是一场"读招 → 找破绽 → 用构筑和地形撼动它 → 处决"的对话。**

| 验收点 | 本方案的回答 |
|---|---|
| ① 专属环境 | 狼谷：狼王石（开场卧榻 / 转阶段跃上长啸）、5 根**狼牙石柱**（引它冲扑撞碎 → 撞晕、削盾）、3 根**狼骨图腾**（砍倒就断了那一窝的召狼）、**墨雾封门**（开战封谷，可读条穿雾撤出）、二阶段**墨云遮月 + 两片漂移的月光**（月下无影：它不能潜影偷袭，裂开的骨甲在月光下发亮） |
| ② 不是换血 | 4 个独特交互：**狼威失衡条**（闪、断、撞、破盾、背击都在攒）、**读条打断**（召狼长嚎 / 啸月）、**背部骨甲弱点**（二阶段，月光下更痛，但有"回首咬"看守）、**五行护盾与剑意**（克制法术是正解，蓄势斩剑意 + 撞柱是后备）。每个都挂钩法术 / 心法 / 法宝 / 词条，给出 5 套可通关构筑 |
| ③ 专属处决 | 二阶段**威折处决**（2.4 秒，跃上狼背、剑插骨甲裂缝、朱色"斩"，大伤害不致死）；**终结处决**（首次 4 秒 / 之后 2 秒：画面褪成留白、一笔横斩、"斩"字、朱印"青牙伏诛"、青牙沿笔痕化墨） |
| ④ 成长 | 青牙固定强度，曲线全靠林墨：练二三层初见被虐（看全一阶段、削 20–40%）→ 练四五层稳进二阶段 → 练六七层或构筑成型能斩 → 练九 / 筑基轻松斩（胜率 ≥ 95%、不用丹，还会看到它伏低畏缩）。现在的青牙实测太弱（练二 22 秒就斩），数值策划建议气血 3000 → 15000、护盾 2 × 10%。归因目标：数值 40% / 解锁与构筑 35% / 熟练 25%，用 num_ttk 三种机器人验证；天机镜记下每次挑战走到哪一步 |

## 2. 定位与基线

- **定位：守谷之王，一个会被反复挑战、最后被斩的门槛**。现状 `prep.js` 已允许"击败青牙 **或** 练气五层"进入区域二，所以青牙不是硬门：玩家可以先绕开，变强后回来斩它——这正是用户要的曲线（练二三层初见、六七层斩）。和《最小闭环》§10.3"第 4 局击杀"冲突，见 §12 问题 1。
- **强度固定**：首领按数据表等级（`levelFor` 对 boss 返回 def.level），现在气血 3000、攻击 40、防御 25，木 / 土两段护盾各 15%；实测太弱（练二 22 秒就斩），数值策划建议改为**气血 15000、护盾 2 × 10%、攻击不变**（§6.5）。曲线全由林墨的成长决定，可测、可解释。
- **不受天时加成**：现在 `run.buffEnemy` 会让首领在暮 / 夜 ×1.2 / ×1.35。建议青牙不吃天时属性（"狼王只认月相"），否则成长档位测不准、同一档位的体验差 35%。
- **不魂系的边界**：重击按境界约占气血 练二 25% → 练四 16% → 练七 13% → 筑基 6%；窗口 ≥ 1 套三连；任何时候都能读条穿雾撤出；身陨走区域一规则（储物袋保留一半）。

### 2.2 境界口径（2026-11-17 统一，关卡 / 敌人模块按此实现）

| 项 | 定为 | 理由 |
|---|---|---|
| **青牙境界** | **练气七层**（`realm: "1:7"`；现数据 `1:6`，敌人模块曾暂定九层，都改为七层） | 首斩档位是练六七层：练七时"同境界一战"最公平，练六是"越一层斩之"。九层会让中段玩家一直看不清、且与首斩档位脱节；区域分区基准 4 级是刷怪等级，不是首领境界（青牙强度按数据表固定，境界只是显示与叙事） |
| **关口提示**（`bossGate.text`） | **首领境界 + 宜斩境界**都写：`此去：狼王青牙 · {境界标签} · 宜练气六层以上`。`{境界标签}` 用与血条相同的 `realmLabel` 规则动态生成（看不清时就是"练气?"），不写死 | 用户要练二三层就去"初见被虐"，所以不写"推荐练气四层"这种会被理解成"到了四层就能打"的门槛；"宜练气六层以上"说的是"斩它"的境界，不拦人去试。第二行小字：`谷中可读条穿雾而退` |
| **横幅 / 题签 / 血条的问号** | **有意保留**。规则沿用现有神识判定：同大境界、层数更高且神识 < (差层 × 16) → "练气?" | 初见看不清对手是代入感，也是成长刻度：按现有神识（8 × (层 − 1)），练二至四层看到"练气?"，**练五层起看清"练气七层"**（正好是"稳进二阶段"那一档）；带《灵台》（神识 +30）练四就看清 |
| 斩过之后 | **首杀后永远显示准确境界**（`profile.flags.boss_qingya` 为真时跳过神识判定） | "斩过就看清了"；回来复仇 / 刷内丹时不再故弄玄虚 |
| 筑基后 | 显示"练气七层"（低于自己），配合入场畏缩演出 | 成长的情绪落点 |

- 统一后的三处文案：狼骨门 `此去：狼王青牙 · 练气? · 宜练气六层以上`（练五起 / 首杀后为"练气七层"）；登场横幅 `青牙 · 练气? 现身！`（同规则）；入场题签 `青牙 · 狼谷之主 · {境界标签}`。UI 草图里题签写的"练气六层"以此为准改为动态标签。

### 2.1 现成构件（战斗 v1.3，2026-11-17 交付）——青牙的交互直接建立在它们上面

| 构件 | 现状 | 在青牙战里的角色 |
|---|---|---|
| 右键蓄势斩：满势一刀 ≈ 剑气斩三道全中 × 1.8–1.9 | `CHARGE`（v1.3） | 不耗真气的"重手段"：打断读条（1.0 打断值）、狼威 +20、威折窗口里的主力伤害 |
| 剑意破盾：不看五行，首领每段护盾削 20% / 刀 | `CHARGE.shieldCut.boss` | 没带克制法术时的破盾后备（每段约 5 刀） |
| 满势命中打断首领预警 0.5 秒（同一首领 8 秒一次） | `CHARGE.stagger.boss / bossIcd` | 保留原规则，并把它接进狼威（§5.1）和读条打断（§5.2） |
| 墨痕持续伤害 25% / 3 秒 | `CHARGE.ink` | 威折倒地时满势斩 + 墨痕吃满易伤 |
| **气势不随时间流失**，可以带着满势进场 | `MOMENTUM`（v1.3） | 设计成"有准备的回报"：开场起身破绽（§5.6）；砍图腾、清召来的狼都在攒势 |
| **真气不自动回复**：一局约 8–15 次法术 | `mpRegen = 0` | 青牙战一场只有 练二约 6 次 / 练七约 7 次 / 筑基约 13 次法术（加回气丹）。所以**法术是"答案"不是"输出"**：用在破盾、打断啸月、冻结上；日常打断和破盾靠蓄势斩与地形（§5.2 的真气预算） |
| 筑基御剑：深水 / 高坡 12 米内掠过 | `PLAYER.swordFly` | 谷壁约 3 米高，筑基能御剑飞出狼谷。开战后谷沿一圈墨雾，**御剑落点不能在谷外**（提示"墨雾封谷"），撤出仍走墨雾门读条（§3.1） |

- 数值复核的旧结论（"青牙 24 秒"、"重击 13–16%"）出自修 bug 前的机器人（放不出蓄势斩，见战斗 v1 §3.8）；修正后的新实测见 §6.2：现在的青牙在每一档都太容易，且蓄势斩占首领伤害 37–56%。**本方案所有档位指标以数值策划的新实测为准**。

## 3. 专属环境：狼谷（与关卡设计共同定稿）

坐标单位米，x 向东、z 向南（关卡设计 2026-11-17 回复）。狼谷 pit 形状不变（x 28..68，z −37..−6，谷底 0.6 米，四周硬崖）。

### 5.2 读条打断

- 读条招（召狼长嚎 1.6 秒、啸月 2.2 秒）有"打断值"：期间累计到阈值（长嚎 1.0、啸月 1.5）就打断。地面墨圈向内收拢就是读条进度。
- 打断值：普攻 0.12 / 段；剑气斩 0.34 / 道（三道全中 1.02）；满势蓄势斩 1.0、半势 0.6；火符 1.0；寒冰锥（冻结）1.5；镇山印 1.5；剑阵每跳 0.15；飞剑主动齐发 0.5；五行符 0.5。
- 设计意图：**打断要"用一个重手段"**（黑神话的定身 / 识破同理）——练二只有剑气斩，三道全中刚好打断长嚎，是第一课；啸月要 1.5，逼玩家攒满势或带寒冰锥 / 火符，或者两种手段叠。
- **真气预算**（真气不自动回复）：一场下来长嚎约 3–4 次（冷却 20 秒）、啸月约 2 次。练二只有约 6 发剑气斩，全拿去打断就没得破盾——"这一发蓝是打断还是破盾"本身就是决策。不耗蓝的答案：满势蓄势斩（1.0，正好断长嚎）、先砍图腾（长嚎变空嚎，不用断）、撞柱。练七以后寒冰锥一发断啸月，是"变强回来"的手感。
- v1.3 满势斩的"首领打断 0.5 秒"在 `ccMode: "poise"` 下由控制器接管：非读条招 → 照旧打断预警（8 秒一次）；读条招 → 计 1.0 打断值（不受 8 秒限制，一次读条只断一次）。两条都另加狼威 20。破盾眩晕、撞柱眩晕是真眩晕（控制器放行，不折算）。
- 打断后：长嚎 → 踉跄 2.0 秒；啸月 → 倒地。

### 5.3 背部骨甲（二阶段弱点）

- 背后 120° 内命中：伤害 ×1.35、狼威 ×2；青牙身处月光时 ×1.6（裂缝发亮 = 看得见的弱点，Birkhead）。
- 看守：林墨在背后累计 1.2 秒 → 回首咬（尾巴竖起预警）。所以背击是"读招换伤害"，不是站桩。
- 绕背的手段：闪身穿过冲扑、撞柱后它朝着石柱、威折倒地时。伤害标签加 `"weak"`，飘字前加一个小"裂"字。

### 5.6 有准备的人先手：带满势进场、开场破绽

- 气势不流失（v1.3），所以"进谷前在狼群 / 图腾上攒满"是正当准备。入场仪式结束后，青牙从狼王石跃下、**落地起身 1.2 秒是固定破绽**（不出招、不吃硬直），势成进场的人可以先手一刀满势斩：剑意削木盾 20%、狼威 20 × 0.6、墨痕。只是一刀（攒满要约 3 套三连），不改变总时长（数值复核附录 A 的结论：开场一刀约占首领 4%）。
- 砍图腾、清召来的狼都给气势（普攻命中照常攒）。所以砍光图腾 = 少了狼，也少了"势的来源"——是取舍，不是白给。
- 首领沉睡时偷砍图腾：第一根倒下就惊醒它（提前开战、跳过入场仪式的起身破绽）。想要开场一刀还是想少一窝狼，由玩家选。

### 6.4 曲线靠什么实现（归因目标与验证法）

| 因素 | 目标占比 | 具体是什么 | 验证（数值策划） |
|---|---|---|---|
| 数值（境界属性 + 装备品质） | ~40% | 气血 ×1.65（练二 → 练七）、攻击 ×1.8、攻速 0.84 → 1.03、受到的扑咬 26% → 12%（练九 9%）；装备 灵 → 宝 | 同档位机器人，只换属性和装备，其余锁在 T1 工具箱 → TTK、胜率差 |

- 熟练度的"刻度"做成看得见的东西：天机镜战报记录每次挑战的境界、走到哪一阶段、首领剩血、用了几次处决（§10 玩法系统）。玩家自己能看见"第 1 次 41% → 第 4 次进二阶段 → 第 6 次斩"。

### 7.1 威折处决（二阶段威折倒地时，2.8 米内按 F）

总长 **2.4 秒**；伤害 = 12% 最大气血 + 4 × 攻击，**不致死**（最多打到 1 血；打到 1 血时直接进入气竭伏地 → 可以紧接终结处决）。处决同时清掉当前护盾。

### 10.1 事件与接口约定（2026-11-17 按落地实现更新）

- **控制器**：`src/game/enemies/bosses/qingya.js`（`QingyaCtrl`，由 `bosses/index.js` 运行时挂到 `ENEMY_TYPES.qingya.controller`），调参 `src/data/bosses/qingya.js`。`enemy.ctrl.view()` → `{ phase, mode, asleep, hp, hpMax, shield: { el, hp, max } | null, poise, poiseMax, poiseFalling, broken, down: "break" | "final" | null, downLeft, downDur, channel: { id, k, brk } | null, inMoon, weak }`（UI 每帧读，自己做变化检测）。
- **事件**（`ctx.world.events`，控制器发的都带 `{ id: "qingya", enemy, boss: enemy, src: ctrl }`）：
  - 入场：`boss:intro { boss, first, tries, best, cause }`（流程组 bossflow 发；无流程组时控制器发）→ 控制器开演并发 `boss:introStart { first, tries, best, last, dur, short, cause, cower }`
  - `boss:phase { phase: 2, dur: 3.6 }`（转阶段开头；不带横幅）、`boss:poise { v, max }`（≥ 1 点变化）、`boss:break { phase, dur }`、`boss:interrupt { attack, by }`、`boss:crash { pillar, cut, left }`、`boss:totem { totem, left }`、`boss:moonDenied {}`
  - 处决：`boss:execPrompt { kind, on, dur }`、`boss:execute { kind, dmg, dur, short }`、`boss:executeHit { kind, dmg }`（威折出伤帧）、`boss:execEnd { kind }`（`src/game/execution.js` 发）
  - 结束：`boss:retreat { phase, hpLeft, leash }`、`boss:defeated { executed, phase }`
- **伤害**：背击在 `onBeforeDamage` 里乘倍率（`info.qyWeak`，飘"裂"字）；处决标签 `"execute"`。
- **通用演出**：`src/game/execution.js`（时间轴 + 主角 `player.cinematic()` + 其他敌人定格 + `rig.cine(shot)` 镜头 + 结束还原；自己用 rAF 推进，首领死后仍能走完）。
