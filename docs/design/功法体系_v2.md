## 0. 一页总览

| 问题 | 本方案 |
|---|---|
| 只有 5 种法术 | **12 门**：五行各 2–3 门，**每门一个独立"动词"**（破防 / 对空 / 蓄势 / 群控 / 突进 / 爆发 / 反击 / 群伤 / 召唤 / 守御 / 打断 / 位移），没有数值变体。原先封存的落石诀、掌心雷改了定位后启用，新增凝锋诀、藤引、止水诀、火鸦、地行术 |
| 随境界解锁吗 | **栏位**随境界开（练一 1 栏 / 练三 2 栏 / 练七 3 栏，不变）；**法术本身**来自地点、敌人、容器、首领。境界只保底：开栏时没功法可装就赠一门（练三 土遁护体 / 练七 落石诀） |
| 野外掉功法、残页参悟 | 6 门靠**残页**（3–5 页）：按区域 / 敌人 / 容器分布 + 每局 1–2 块**功法残碑**（分区固定出哪门，必出 1 页）；异种 35% 掉**完本**，首领首杀必掉一本完本（优先未学）。回洞府仓库**参悟**（花少量灵石）；**重复残页化为悟性**，悟性可**补页**、给法术**升重** |
| 没有目标指引 | 来源全部**从掉落表推出**（表一改指引就跟着变）：功法匣里未领悟的法术直接写"竹海·溪谷 · 北脊断碑 · 残页 0/5"，悬停卡列出全部来源与概率档；`shieldGap` 把"去处的护盾分布"和"你缺的克制五行"连起来。更大的指引面板出了 3 个草图方向请用户选 |

## 2. 现状（2026-11-17 核实）

- `src/data/skills.js` 启用的只有 5 门：剑气斩（金·破防）、火符（火·群伤）、寒冰锥（水·单体爆发）、缠藤诀（木·群控）、土遁护体（土·保命）。落石诀、掌心雷在 `SPELL_ARCHIVE` 里封存。
- **五行缺口**：土行唯一的法术土遁护体不造成伤害，**水盾没有任何克制法术**（只有土符）。而区域二午时巡游的灰鬃头目 `shield: null`，会随机拿到 5 种护盾，水盾、金盾都会出现。
- 法术栏 `progression.js` spellSlots：练一 1、练三 2、练七 3。grants：练一 剑气斩、筑基 土遁护体。缠藤诀（山神庙）、寒冰锥（剑修遗府）是遗府首通固定奖励；《火符》残卷 ×3 在区域二宝箱。
- 参悟：`facilities.js` 的 studyList / study 已支持 `teaches + pages`，但完本和残页混放时按"件"计页，会算错；没有重复处理和代价。
- 功法匣（`src/ui/loadout.js`）里没学会的法术只写"未领悟"。

## 3. 法术池（12 门）

### 3.1 一览

| 法术 | 五行 | 定位（动词） | 手势 castKind / 施放 | 克盾 | 获取 |
|---|---|---|---|---|---|
| 剑气斩 | 金 | 破防：三道穿透剑气 + 破甲 | sweep / 直线瞄准 | 木 | 练一 玄机子传授 |
| **掌心雷** | 金 | **对空**：自动连锁，打落飞行妖物 | point / 鼠标附近索敌 | 木 | 残页 ×4 |
| **凝锋诀** | 金 | **蓄势**：立得气势，剑意更利 | raise / 自身，按下即放 | —（加强剑意，不看五行） | 残页 ×3 |
| 缠藤诀 | 木 | 群控：区域缠绕 | point / 落点圈 | 土 | 名门：山神庙地窖 |
| **藤引** | 木 | **突进**：藤索缠敌并贴身 | point / 直线瞄准 | 土 | 残页 ×4 |
| 寒冰锥 | 水 | 单体爆发 + 冻结 | point / 直线 | 火 | 名门：剑修遗府 |
| **止水诀** | 水 | **反击**：化去一击、水浪反卷 | raise / 自身，按下即放 | 火 | 残页 ×5 |
| 火符 | 火 | 群伤：符纸爆炸 + 灼烧 | point / 直线 + 爆圈 | 金 | 残卷 ×3（不变） |
| **火鸦** | 火 | **召唤**：三只火鸦自行扑击 | raise / 自身 | 金 | 残页 ×4 |
| 土遁护体 | 土 | 守御：吸收伤害 | raise / 自身 | — | 突破赠予（练三保底 / 筑基） |
| **落石诀** | 土 | **打断**：延迟巨石，眩晕、断读条 | raise / 落点圈 | 水 | 残页 ×3；练七保底 |
| **地行术** | 土 | **位移**：遁地疾行、破土震晕 | point / 直线（落点 = 鼠标） | 水 | 残页 ×4 |

- 五行覆盖：金 3、木 2、水 2、火 2、土 3；**每种护盾都至少有 2 门伤害型克制法术**（水盾第一次有了法术解：落石诀、地行术）。
- "定位"两两不同，测试断言 12 格不重复（`gongfa_v2`）。
- **淘汰的候选**：漩涡诀（水·聚怪）和枯荣诀（木·吸血），它们和紫金葫芦的"吸 + 汲取"同质（Hades 2 的做法：机制已有载体就不另做）。

### 3.2 每门：手感、与现有机制的交互、与已有法术的差异

> 机制简称：**破盾** = 五行护盾克制 ×2；**剑意** = 满势蓄势斩削盾；**狼威 / 打断** = 首领失衡条与读条打断值（`SPELLS[id].boss = { poise, chan }`，青牙控制器读）；**冻结折算** = 首领不吃冻结，改成狼威 25；**处决** = 威折处决 / 终结处决。

**掌心雷（金·对空）**：22 真气 / 9 秒，不用对准，鼠标附近 3 米或面前扇形里找首个目标，跳 3 次（跳距 5，每跳 ×0.8），每跳破甲 1 层。**飞行妖物（`tags: flying`，蝠妖 / 玄鳞蝠）伤害 ×1.5 并"打落"眩晕 0.8 秒**，飘朱字「坠」。
- 交互：破木盾；破甲 → 寒冰锥 = 冰裂；眩晕 → 金伤 = 碎甲；首领狼威 2 / 跳、打断 0.25 / 跳（单发打不断长嚎）。
- 与剑气斩的差异：剑气斩要瞄准、穿透成排、对单体三道全中；掌心雷自动索敌、在散开的群里跳，专治乱飞的蝠妖（只狼"手里剑打空中"）。

**凝锋诀（金·蓄势）**：24 / 16 秒，自身。立得 35 气势（不吃气势加成）；8 秒内剑意削盾 ×1.5（精英 35% → 52%、首领每段 20% → 30%）。
- 交互：**这是法术流和普攻流之间的桥**。凝锋 + 一套三连 ≈ 满势 → 剑意破盾；对首领"开场破绽一刀"更有分量；蓄势斩是威折窗口里的主力，凝锋让处决前那刀更早攒满。
- 差异：唯一不打伤害的金行法术，收益完全落在蓄势斩上（Hades"改变核心动作"的思路）。

**藤引（木·突进）**：18 / 7 秒，直线 11 米藤索，命中第一个敌人：14+0.4法 木伤、缠绕 1 秒，主角 0.18 秒被拉到它身前 1.4 米（全程无敌），+8 气势；落空藤自收回（不退真气）。
- 交互：破土盾；缠绕 → 火 = 爆燃；首领缠绕时长减半（青牙规则）；狼威 4、打断 0.3。拉近走地面（`tryMove`），崖壁、深水照挡，不能借它越过关卡门槛。
- 差异：缠藤诀是"定住一片"，藤引是"我过去"，给普攻流一个贴身手段（尤其对远程藤妖、站高处放箭的怪）。

**止水诀（水·反击）**：20 / 10 秒，自身，按下即放、**不锁移动**。0.6 秒架势窗口内**第一次受击被化去**，以来敌方向 100° 扇形、半径 4.5 的水浪反卷（30+2.2法、寒冷 2 层，来敌一定吃到），+25 气势，顿帧 0.08；没挨打就白放。
- 交互：破火盾；寒冷 2 层再叠一层 = 冻结（首领折算狼威 25）；**反击成立对青牙按"读招完美闪身"给狼威 20**（`player:counter`）；和完美闪身同为技巧奖励，但它不位移、站着接。
- 差异：唯一的"读招"法术（只狼弹刀的味道，但只给 0.6 秒窗口、10 秒冷却，不魂系）。冷门防御型的"进攻收益链"按 Hades 的经验给足：反击伤害 + 气势。

**火鸦（火·召唤）**：30 / 14 秒，自身。三只火鸦绕身盘旋 6 秒，每 0.9 秒放一只扑向 10 米内最近的敌人（追踪），每只扑 2 次：15+0.75法 + 灼烧 1 层（共 6 击）。新放的顶掉旧的。
- 交互：破金盾；灼烧 → 土伤 = 熔岩；追踪必中，适合打蝠妖；打图腾（火 ×2）是青牙战的"偷砍图腾"另一个解；首领狼威 2 / 击、打断 0.15 / 击。
- 差异：火符是"瞄准一发炸一片"，火鸦是"放出去不用管、我接着砍"——给普攻流的持续输出件。

**落石诀（土·打断）**：24 / 12 秒，落点圈 0.45 秒后砸下（半径 2.6，36+1.6法，眩晕 1 秒）。
- 交互：**克水盾**；灼烧 → 土 = 熔岩；眩晕 → 金 = 碎甲；**首领：打断 1.2（一发断召狼长嚎）、狼威 18**。延迟落点要求预判，是"重手段打断"里唯一的法术解（之前只有满势斩 / 寒冰锥冻结）。
- 差异：原封存版是"群控"，和缠藤诀重了；v2 改定位为"打断"，伤害不高，价值在时机。

**地行术（土·位移）**：16 / 9 秒，遁地向鼠标方向最多 9 米（0.32 秒，隐身 + 无敌，**沿地面走：崖壁、深水、碰撞体都挡**），落点破土 半径 2.2，12+0.6法，非精英眩晕 0.5 秒。不耗闪身充能、不触发完美闪身。
- 交互：克水盾（破土伤害小）；首领狼威 3、打断 0.3；**不越过关卡门槛**（断涧仍要二段跳、深水仍要御剑），首领场的御剑围栏不受影响（它不飞）。
- 差异：闪身是 2.75 秒冷却的短距无敌；地行术是长距离"换位置"，用来脱离包围、绕到首领背后（背击 ×1.35）、赶到读条中的撤离点。

**沿用的 5 门**：剑气斩、火符、寒冰锥、缠藤诀、土遁护体，数值与行为不变。首领交互仍按五行旧规则（`classify`），没有填 `boss` 字段。

### 3.3 定位即标签（给后续心法 / 词条留的挂钩）
`SPELLS[id].role` 就是标签：将来"位移类法术后 2 秒攻速 +"、"召唤物灼烧 +1 层"这类心法 / 仙品词条按 role 挂（Diablo IV 的 Mobility 标签挂装备）。本轮不做。

## 4. 获取途径

### 4.1 四类来源

| 类 | 是什么 | 本轮的法术 |
|---|---|---|
| **名门功法**（地点固定、首探必得、完本） | 遗府首通 | 缠藤诀（山神庙地窖）、寒冰锥（剑修遗府）——不变 |

- **功法残碑**（关卡设计 2026-11-17 已写入 `points.steles`，石碑景物全部建出，每局按种子启用 1–2 块为容器；只放在风险 ≥ 2 的分区、离入口 ≥ 15 秒、不靠近首领场）。每块启用的碑**必出 1 页**本分区对应的残页 + 4–8 灵石，动词「拓」。分区固定出哪门（`STELE_ZONE`），玩家能记住"山神庙那块碑出落石诀"（了不起的修仙模拟器"地点绑定功法"）。
- **刷点**（关卡实测，6 米/秒纯跑图）：石傀 4 个刷怪点，离入口 17–45 秒，有意去刷一局 2–4 只（含山神庙地窖固定 2 只）；藤妖 12 个点，一局 4–8 只，好刷；灰鬃头目在区域二 4 只精英里占几只由敌人模块的类型抽取决定（遗留问题 2）。
- 残页一律**已鉴定**掉落（宝品残页也不用鉴定，免得不能叠放）。残页是普通物品：身陨按储物袋规则丢，撤回才算得到（Dead Cells 蓝图）。
- 区域一第 3–5 局前能拿到第一门残页法术的路线：山神庙（第 3 局本来就去）石傀 + 山神庙残碑 → 落石诀；首次杀狼妖头目 25% → 掌心雷。

### 4.3 完本的"优先未学"
掉落条目 `{ pick: [...完本], unlearned: true }`：从列表里去掉已学会的（跨所有来源共享 `profile.flags.learned`，炉石的跨卡池重复保护）；全学会了照常抽，抽到重复的完本参悟时化为 4 点悟性。只用于完本，残页不做智能掉落（D3 Smart Loot："偏置而非保证"）。

### 4.4 重复残页的出路（三选一，由玩家决定）
1. **化为悟性**：已学会的那门的残页 / 完本，在仓库按「化悟性」→ 灵品残页 1、宝品 2、完本 4 点。
2. **补页**：没学会的那门，缺页时每 3 点悟性补 1 页（至少要有 1 页实物："有了线索才能参"）。
3. **化灵**：沿用仓库化灵，换灵石。
悟性的另一个用途是**升重**（§5.2）。悟性存 `profile.flags.gongfa.wux`。

## 5. 参悟与"重"

### 5.1 参悟（洞府 · 仓库 · 参悟按钮，`facilities.study` → `gongfa.studyScroll`）

| 情况 | 结果 |
|---|---|
| 有完本 | 免费，立即学会（用掉 1 本） |
| 残页 + 悟性补页 ≥ N | 付灵石（灵品残页 20 / 宝品 60）学会；先用实物残页，不够的扣悟性 |
| 残页不全 | 提示「残页不全：2/4 · 悟性 3（每 3 点补 1 页）」 |
| 灵石不够 | 提示「参悟需灵石 20」 |
| 已学会 | 按钮变「化悟性」，全部化为悟性 |

- 代价是"少量灵石"，**不做时间墙**：用户要的是"有一点代价、有一点进度"，悟性补页就是那点进度（坏运气也在往前走）。
- 完本按"整本"计页（修了原来按件数计页的问题：完本 + 残页混放时完本只算 1 页）。

### 5.2 重（用悟性给已学法术升阶）
| 重 | 悟性 | 效果 | 实现 |
|---|---|---|---|
| 一重 | — | 学会即是 | — |
| 二重 | 6 | 伤害 +12% | `strike()` 里乘进 base / scale（独立乘区，不走 Stats 的 dmg，见 坑.md 第 3 条） |
| 三重 | 10 | 冷却 −15% | `castSpell` 的冷却 |

- 这是"同一门法术的修炼"，不是新法术；`最小闭环`里的"藏经阁·三选一变体"仍是后续。升重入口（界面）属于 §8 的指引 / 功法匣草图范围，**逻辑 `zhongUp` 已落地，界面未接**。
