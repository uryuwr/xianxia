## 一、结构

"第 N 次"串起全片：每一档的入场题签是**游戏自己的** UI（"初见" / "第 4 次 · 上回削至 62%" / "第 9 次 · 上回已斩"，由 `src/dev/promo.js` 写战报 `bossLog` 驱动），不另做横幅。顺序 = 成长顺序：

练二初见被虐 → 练四学会打断 / 撞柱、打进二阶段 → 练七用构筑拆二阶段、两种处决斩首 → 筑基轻松通关 → 分屏对比"同一招四个结局"→ 落版。

## 四、配乐与音效（合成，无人声）

`tools/trailer/music.py`（B 羽五声）段落映射：开场空镜 = 低音长音 + 泛音；初见 = 古筝分解和弦 + 轻鼓；身陨后 = 古琴慢句；攻防段 = 太鼓节奏型；转阶段起 = 重鼓 + 洞箫长音；终结处决一笔横斩 = 重鼓 + 锣；分屏起 = 一声磬收尾。
音效：打断「断」= 盖印声；撞柱 = 重击；破盾 ×2 = 碎裂；蓄势斩 / 处决出刃 = 斩击；朱印「青牙伏诛」= 盖印。

## 五、拍摄工具

| 文件 | 作用 |
|---|---|
| `src/dev/promo.js` | 调试入口（只在 URL 带参数时由 main.js 加载）：`?scene=run&region=r1&slot=7&preset=T1..T4&boss=qingya&at=gate|pit|fight&tries=N&last=0.62&lastPhase=2&hud=0|boss|1&seed=7&god=1&mom=1&mp=1`；运行时 `window.__promo` |
| `tools/trailer/qingya_act.mjs` | 脚本化操作（真实键鼠）：`enter / bossHold / bossFreeze / bossDo / stage / floor / nearPillar / camPath / cast / charge / dodge / attack / approach / walkToBoss / interruptHowl / lurePillar / flankBack / standMoon / breakExec / finalExec` |
| `tools/trailer/shots_qingya.mjs` | 12 个镜头（q01–q08 + 分屏 qg1–qg4） |
| `tools/trailer/edit_qingya.mjs` | 本剪辑表（含 2×2 分屏 grid 段） |
| `tools/scenarios/promo_qingya.mjs` | 可运行测试：入口、档位、HUD、种子 + 每个脚本化操作都触发了对应游戏事件 |

档位（与数值策划 `tools/scenarios/num_qingya.mjs` 的 `preset(L)` 同步）：T1 = 练二（剑气斩，1 次闪身）/ T2 = 练四（+ 缠藤、《锋锐》）/ T3 = 练七（+ 寒冰锥、飞剑、宝品）/ T4 = 筑基。

一键：
```
node tools/trailer/build.mjs --edit=qingya                   # 重录 12 个镜头 + 出片（约 20 分钟）
node tools/trailer/build.mjs --edit=qingya --no-record       # 只重做后期
node tools/trailer/build.mjs --edit=qingya --record=q03_crash,q06_p2
node tools/run.mjs promo_qingya "scene=run&region=r1&slot=7"  # 工具自检
```
