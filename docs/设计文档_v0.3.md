## 0. 一句话

**你是一个从现代穿越进《万象山河图》的普通人，在画中世界成了无门无派的散修：一次次出行搜宝斩妖、活着撤回洞府，把收获炼成修为与丹药，一层层突破境界——为了找到穿过画卷"留白"、回到原来世界的路。**

核心钩子：**"世界是一幅画"**。地图是一卷逐渐被墨色"画出来"的长卷，美术风格（水墨）和探索玩法（揭开地图）是同一件事。

## 1. 设计支柱

| 支柱 | 含义 | 反面（避免） |
|---|---|---|
| **越修越强** | 主角操作流畅、身法灵动；靠法术、法宝、阵法的构筑叠加数值与机制，击杀越来越强的敌人 | 魂系式高惩罚、只涨数字的成长 |
| **修炼有手感** | 境界突破是看得见的成长：解锁新身法、新区域、新招式，而不只是数值变大 | 只涨攻击力的"数值修仙" |
| **探索有回报** | 每个岔路口都有东西：灵草、宝箱、捷径、妖巢、残缺丹方 | 空旷的跑图 |
| **一眼是水墨** | 任何一张截图都能认出风格：墨线、留白、宣纸、点睛的朱砂与石青 | 普通卡通渲染加个滤镜 |

## 2. 视角与操作

- **斜 45° 俯视**：3D 场景，镜头从斜上方约 45° 俯视（窄视角透视，接近等距），默认跟随主角，可以小幅旋转或拉近拉远。**可以向任意方向移动**。
- **高低差是探索的核心**：山崖、台地、溪谷、悬空栈道构成多层地形。低处被高处遮挡时，遮挡物自动变为淡墨半透明。
- 俯视角下的"跳跃"不是平台跳跃，而是**跃过沟壑、跃上矮台、跳下高崖**；身法能力（二段跳、御剑）决定能跨越多宽的沟、跳上多高的台。

操作表见 4.1（v0.3 已更新）。镜头：滚轮拉近拉远，中键拖动小幅旋转。

## 3. 核心循环

```
          ┌──────────── 洞府（家）────────────┐
          │  丹房炼丹 · 静室修炼 · 药园种植   │
          │  整理法宝符箓 · 查看画卷地图       │
          └───────┬──────────────▲───────────┘
                  │ 出行          │ 带回材料、丹方、灵石
                  ▼              │
   探索区域（采集 · 战斗 · 解谜 · 发现妖巢 / 秘境 / 捷径）
                  │
                  ▼
     妖巢深处：妖王 → 稀有掉落（妖丹、功法、法宝）
                  │
                  ▼
   修为攒满 → 回洞府突破境界 → 解锁新身法 → 打开新区域
```

- **短循环（1–3 分钟）**：清一片区域，采几株草，开一个箱子。
- **中循环（10–20 分钟）**：出行一趟，打穿一个妖巢，回洞府炼丹。
- **长循环（数小时）**：一个大境界，对应一片新地图和一套新身法。

## 4. 系统设计

### 4.1 战斗（v0.3：爽快动作 RPG，不走魂系）

**原则：主角本身就强、操作流畅、失误代价低；难度和乐趣来自"构筑"——用法术、法宝、阵法叠加数值与机制，去击杀更强的敌人。** 参考《哈迪斯》《暗黑破坏神》的爽快感，而不是《只狼》式的拼刀。

- **身法**：移动快；闪身有 2 次充能、带无敌帧、冷却短；任何攻击都能被闪身或法术取消。
- **普攻**：剑三段连斩，有轻度自动吸附（朝鼠标方向扇形内最近的敌人），一刀可以命中多个敌人，带顿帧、击退、伤害数字。
- **没有体力条**，不强制弹反；"完美闪身"（贴着敌人出手时闪身）作为奖励机制：短暂慢动作 + 下一击加伤。
- **敌人**：数量多、单体弱，有精英和首领；危险攻击都有清晰预警圈。
- **死亡**：魂归洞府、掉落储物袋（见 4.8）。

#### 构筑三大支柱

| 支柱 | 形式 | 例子 |
|---|---|---|
| **法术**（功法习得的主动技） | 3 个法术栏（Q / E / R），消耗真气、有冷却 | 剑气斩、火符、寒冰诀、雷诀、土遁护体 |
| **法宝** | 装备 1～2 件，右键发动主动效果，附带被动属性，可以"祭炼"升级 | 青冥飞剑（环身自动斩敌）、紫金葫芦（吸取）、镇山印（砸地震晕） |
| **阵法** | T 键在鼠标处布阵，持续一段时间，有数量上限 | 剑阵（持续切割）、火阵（灼烧）、聚灵阵（回复真气、加速冷却） |
| 心法（被动） | 属性加成和触发效果 | "斩敌回气""闪身留下剑影""暴击引雷" |

#### 防止"废技能"的约定（v0.3）

1. **少而精**：法术栏按境界解锁（练气初期 1 个、练气五层 2 个、筑基 3 个）；技能池精简，每个五行一个法术，定位互不重叠：剑气斩（金·破防）、火符（火·群伤）、寒冰锥（水·单体爆发）、缠藤诀（木·群控）、土遁护体（土·保命）。
2. **冷却拉长**：法术冷却 8～18 秒，是扭转局面的"决策型"技能；日常输出交给普攻与法宝。
3. **敌人逼你换手**：精英和首领带**五行护盾**，护盾存在时本体不掉血；只有相克的五行能高效破盾（×3），其他五行 ×0.25，无属性 ×0.15；破盾后眩晕并易伤。敌人种类也要求不同应对（成群要群控、硬壳要破甲、飞行要远程）。五行相克：金克木、木克土、土克水、水克火、火克金。
4. **强化代替新增**（做修炼系统时实现）：伤害随属性成长，旧技能不过时；每个法术可修炼升级，到一定等级三选一变体（如火符：连珠 / 燎原 / 爆裂）。

- **五行相生**：五行附带状态效果——金（破甲）、木（缠绕）、水（寒冷减速）、火（灼烧）、土（震晕）。相生的五行叠加会触发反应，例如**木生火**：被缠绕的敌人遇火会"爆燃"，造成范围伤害。这是构筑的核心机制深度。
- **属性**：气血、真气、攻击、法力、防御、暴击率、暴击伤害、攻速、冷却缩减、移速、五行强度与抗性。所有加成统一走"基础值 + 固定加成 → 百分比加成 → 独立乘区"的计算方式，便于叠加构筑。

| 移动 / 朝向 | WASD / 鼠标位置 |

### 4.2 修炼与境界

| 境界 | 解锁 | 突破条件 |
|---|---|---|
| 练气（1–9 层） | 基础连段、闪身；练气 5 层解锁**二段跳**（跃过更宽的沟壑、跳上更高的台地） | 修为攒满即可升层 |
| **筑基**（切片的终点） | **御剑短程飞渡**（跨越断崖、水面、瘴气区）、真气上限大增、新招式 | 修为满 + 筑基丹 + 在洞府静室打坐，进入"心魔"幻境战斗 |
| 金丹（之后） | 御剑飞行、法相 | 修为满 + 金丹类丹药 + 渡雷劫 |

- 修为来源：打坐消耗灵石（主要）、击杀妖物、服用丹药、领悟功法。
- **境界即钥匙**：新身法打开之前去不了的地方（类银河恶魔城），让回头探索有意义。
- 每次突破有一段演出：墨色漩涡、天地异象。筑基的心魔战是一个 Boss 战：对手是你自己的倒影，会用你的招式。

### 4.3 采集

- 灵草、矿石、妖兽材料散布在场景中，部分藏在需要新身法才能到达的位置。
- 每种材料有**五行属性**（金木水火土）和**药性**（温、寒、毒、灵……），是炼丹的基础。
- 采集是按住 F，同时屏幕上有一笔"运笔"的小时机：在笔锋经过高亮区时松手可得**完整品**（品质 +1）。轻量，不打断节奏。
- 洞府药园可以种植已采到的灵草，按游戏内时间生长。

### 4.4 炼丹

- **配方**：一枚丹 = 主药 + 辅药 + 药引。丹方可以从掉落获得，也可以自己摸索（试出新配方会自动记录）。
- **火候小游戏**：炼制过程中有一条温度曲线，用鼠标或按键控制炉火，使温度落在药材要求的区间，持续约 20 秒。结果分为 废丹 / 下品 / 中品 / 上品 / 极品。
- **五行相生相克**：主辅药五行相生，加成功率；相克，产生"丹毒"副作用。
- 切片内约 6 种丹药：回气丹、止血散、聚气丹（加修为）、破障丹、**筑基丹**、驱毒丹。

### 4.5 洞府

- 玩家的家和存档点，可以从画卷地图上的"传送印"快速返回。
- 功能房间：**丹房**（炼丹）、**静室**（打坐修炼、突破）、**药园**（种植）、**藏宝阁**（法宝、符箓、材料）。
- 切片里洞府是固定的；之后可以扩建、装饰。

### 4.6 妖巢 / 秘境（可重复挑战）

- 区域里有固定入口，内部由**程序化拼接**的房间组成（房间模板 + 随机组合），每次进入布局和掉落不同。俯视角很适合这种房间式迷宫，类似《哈迪斯》的一间间推进。
- 结构：3–6 个房间（战斗房、采集房、机关房、宝箱房）→ 妖王房。
- 适合刷材料和灵石，也是功法、法宝的主要来源。
- 技术上复用上一个项目的程序化生成思路：房间几何、地形轮廓、装饰物散布都在 GPU 上生成。

### 4.7 掉落与道具

| 类别 | 说明 | 稀有度 |
|---|---|---|
| 材料 | 灵草、矿石、妖丹、兽皮 | 凡 / 灵 / 宝 / 仙 |
| 丹药 | 炼制或掉落 | 品质：下 / 中 / 上 / 极 |
| 法宝 | 主武器（剑、扇、拂尘……），带一个特殊效果 | 灵 / 宝 / 仙 |
| 符箓 | 消耗品法术 | — |
| 功法 | 被动或主动技能，参悟后学会 | 灵 / 宝 / 仙 |
| 丹方 | 解锁炼丹配方 | — |
| 灵石 | 货币，也是修炼的主要消耗 | — |

### 4.8 死亡

**已确认**：魂归洞府，随身未存入的材料掉在原地成为"遗落的储物袋"，回去可以捡回（只丢材料，不丢修为和装备）。再次死亡前没捡回，旧储物袋消失。

## 5. 美术方向

### 5.1 风格关键词

**水墨为骨、设色点睛、留白为气、笔触为魂。**

- **水墨为骨**：画面主体是墨色的明暗层次（焦、浓、重、淡、清五个层次），整体低饱和。
- **设色点睛**：只在关键元素上用色：**朱砂红**（主角发带、危险、重要标记）、**石青 / 石绿**（灵气、灵草、可交互）、**藤黄 / 金**（宝物、符箓、突破）。
- **留白为气**：远景大面积云雾和空白，靠雾气层次表现纵深，而不是堆满细节。
- **笔触为魂**：物体轮廓是粗细变化的墨线；挥剑轨迹、剑气、受击溅射都是一笔笔的墨迹。

### 5.2 画面分层（斜俯视的关键）

俯视角下"纵深"主要来自**高度**，而不是前后景：

| 层 | 内容 | 处理 |
|---|---|---|
| 镜头前 | 偶尔飘过的云雾、垂下的枝叶 | 淡墨半透明，营造"从高处俯瞰画卷"的感觉 |
| **玩法层**（角色所在的地面） | 角色、敌人、可交互物、近处地形 | 对比度最高、墨线最清晰、颜色只出现在这一层 |
| 高处遮挡物 | 挡住角色的树冠、屋檐、崖壁 | 自动变为淡墨轮廓，保证角色始终可见 |
| 低处 / 崖下 | 深谷、溪流、悬崖下方 | 随深度渐隐成云雾和留白，越低越淡 |
| 画面边缘 | 视野以外的区域 | 宣纸底色和晕开的墨边，像一幅画的边缘 |

**可读性规则**：玩家任何时候都能一眼分清"能走的地面""跳不过去的悬崖""能打的敌人""能捡的东西""会伤人的东西"。
悬崖边缘用加粗的墨线勾勒，地面用淡墨皴法，崖下用留白，高低关系一眼可读。

### 5.3 角色

- **主角**：白衣散修，朱砂红发带和剑穗是全身唯一的亮色；衣摆、发带、剑穗随动作飘动。
- **敌人**：墨黑身体，妖气用紫色、眼睛用朱红点亮；体型轮廓要有辨识度（狼妖瘦长、石傀方重、蝠妖展翅）。
- 造型简练，靠剪影和动作取胜，不靠细节堆砌。

### 5.4 渲染技术要点

- 卡通着色：两到三阶明暗，暗部偏墨青。
- 墨线：角色用"外扩描边"，环境用屏幕空间的深度和法线检测；线宽随距离和角度变化，模拟笔锋。
- 宣纸纹理、边缘暗角、墨晕雾气。
- 岩石用程序化的"皴法"纹理（模仿国画画石头的笔法）。
- 特效：剑光是一笔墨迹；打击、死亡是墨点飞溅和晕开；突破时画面局部化为水墨漩涡。

### 5.5 界面

- 宣纸底、毛笔字、朱红印章；HUD 极简：左上角气血和真气是两道墨痕，右下角是快捷栏。
- **地图是一卷画轴**：没去过的地方是空白宣纸，探索过的地方自动"画上"山水。

### 5.6 参考

- 游戏：《大神》（水墨着色与笔触玩法）、《绘真·妙笔千山》（青绿山水）、《哈迪斯》（俯视角战斗手感与房间节奏）、《鬼谷八荒》（修仙系统）、《GRIS》（留白与色彩克制）
- 绘画：《千里江山图》（青绿设色）、黄宾虹（积墨层次）、吴冠中（点线面构成）

## 6. 技术方案

| 部分 | 方案 |
|---|---|
| 引擎 | 网页 Three.js（WebGL2，之后可升级 WebGPU），浏览器直接运行 |
| 角色与主要建筑 | **Blender Python 脚本**建模、绑骨、做动画 → 导出 glTF；我在后台运行 Blender 并渲染预览图供你确认 |
| 环境 | **运行时 GPU 程序化生成**：带台地和悬崖的地形高度场、岩石皴法、植被散布（竹、松、草）、崖下云海、瀑布、溪流 |
| 贴图 | GPU 着色器烘焙（沿用上个项目的思路），不依赖图片文件 |
| 妖巢 | 房间模板 + 程序化拼接，几何与装饰实时生成 |
| 物理 | 自写俯视角角色控制器：地面高度图 + 台地 / 悬崖的高度层 + 简单碰撞体；跳跃是带抛物线的跃迁 |
| 数据 | 草药、丹方、敌人、掉落都用数据表配置，方便调数值 |
| 验证 | 沿用自动化浏览器测试：启动、无报错、关键机制、截图 |
| 打包 | 开发期是多文件工程；发布时可选打包成单个 HTML |

### 6.1 美术与玩法解耦约定（保证后期换美术的改动量小）

1. **碰撞与判定不依赖模型形状**：受击半径、攻击范围、体型写在数据表；关卡的可走区域、悬崖、刷怪点、采集点是逻辑数据，模型只是外观。
2. **动作节奏写在数据里**：每个动作的出伤时间、可取消时间、位移量等"动作事件"放在数据表，换动画只改数字。
3. **资产按命名接入**：材质名（robe_white、ribbon_red……）、动画名（idle、run、slash1……）、骨骼名固定，替换 glb 即可。
4. **镜头基准（已定）**：45° 俯仰、30° 视场角，主角在 720p 下约 100 像素高。关卡尺度、战斗距离都以此为准。

## 7. 第一阶段：垂直切片（目标约 30 分钟流程）

**区域「青岚山」**：

```
洞府（起点）→ 山道 → 竹林（二段跳才能跃过的沟壑岔路）→ 溪谷瀑布（瀑布后的隐藏洞穴）
            → 黑风洞（妖巢，程序化 3–5 个房间）→ 妖王「黑风熊精」
            → 回洞府炼筑基丹 → 突破筑基（心魔战）→ 御剑飞渡断崖，到达之前去不了的孤峰，拿到结尾奖励
```

| 内容 | 数量 |
|---|---|
| 主角动作 | 跑、跃迁、二段跳、闪身、三段普攻、施法（3 种手势）、法宝发动、布阵、采集、打坐、受击、死亡、御剑飞渡 |
| 普通敌人 | 3 种：竹林狼妖（快、连扑）、山魈石傀（慢、重、危招）、蝠妖（空中俯冲） |
| Boss | 2 个：黑风熊精、心魔 |
| 材料 | 灵草 6 种、矿石 2 种、妖兽材料 3 种 |
| 丹药 | 6 种 |
| 法宝 / 符箓 / 功法 | 2 / 4 / 2 |
| 境界 | 练气 1 → 筑基 |

### 建议的开发顺序

1. **美术样张**：一块斜俯视场景（台地、悬崖、竹林、溪流、崖下云海）+ 主角模型 + 渲染管线（水墨着色、墨线、留白），先把"一眼是水墨"定下来。
2. **战斗原型**：主角全套动作 + 1 种敌人，打磨手感。
3. **区域与探索**：青岚山地形、采集、二段跳岔路、里层。
4. **洞府与成长**：炼丹、打坐、突破、心魔战。
5. **妖巢与 Boss**：程序化房间、黑风熊精、掉落。
6. 打磨与整体测试。
