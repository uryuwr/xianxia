# 墨途 · 第一版闭环开发约定 v1

> 依据：`docs/最小闭环设计_v1.md`（v1.1，两区域版本）。四个开发模块并行，**只改自己负责的文件**；跨模块只通过下面的接口和事件。

## 3. 接口约定

### 3.1 场景流程（A 实现）
`ctx.flow.go(name, data)`，场景：`title` 开始界面 → `intro` 开场 → `cave` 洞府 → `prep` 出行准备 → `run` 出行局 → `result` 结算 → `cave`。
`ctx.profile` 为当前存档（`src/core/profile.js` 格式）。事件（`ctx.world.events`）：`flow:enter {name}`、`run:start {region}`、`run:end {result: "extract" | "death" | "abandon", run}`。

### 3.2 关卡（B 实现）
```
buildLevel(def, ctx) → level = {
  root, def,
  height(x, z), canStand(x, z, fromY), colliders,
  points: { entries:[{pos}], extracts:[{id, kind: "gate"|"ruin"|"fake"|"boss", pos, channel}], chests:[{pos, tier}], gathers:[{pos, kind}],
            elites:[{pos}], glows:[{pos}], ruins:[{id, pos}], boss:{pos}, spawns:[{pos, pack}] },
  update(dt), dispose()
}
```
- 地形高度改为由当前关卡提供：`src/world/terrain.js` 的 `height(x, z)` 委托给当前关卡（`setActiveLevel(level)`），这样主角和敌人现有的 `import { height }` 不用改。
- 关卡数据：`src/data/levels/r1.js`（青岚山外 160×120）、`src/data/levels/r2.js`（竹海·溪谷 220×160）、教学局可用 r1 的一部分。每局随机：入口、宝箱 / 灵草 / 精英 / 灵光点 / 残阵位置（从候选点抽取，用种子）。
- 天时（晨午暮夜）的光照与雾气变化由 B 提供 `level.setTimeOfDay(t)`（0 晨 → 1 夜）。

### 3.3 掉落（D 实现）
- `rollLoot(sourceId, { region, level, pity }) → [物品实例]`（`src/game/loot.js`）；来源 id：`mob`、`elite`、`chest_normal`、`chest_glow`、`chest_night`、`ruin_first`、`ruin_repeat`、`boss_first`、`boss_repeat`、`gather_<kind>`。
- 敌人死亡时发出 `loot:drop {pos, items}`（items 为物品实例数组）；采集发出 `gather:done {pos, items}`。
- **A 负责**把这些变成地上的拾取物、拾取进储物袋（满了提示取舍）。原型里构筑系统把光球变成回血回气，改为只对"灵气光球"生效。

### 3.4 洞府（C 实现）
- 设施：灵泉（炼化修为）、鉴宝台（鉴定）、炼丹炉（火候小游戏）、炼器鼎（装备、储物袋 / 锦囊升级、护器符、滴血认主）、药园、仓库、出行台（→ `ctx.flow.go("prep")`）。
- 修为与突破一律调用 `src/game/progression.js`；配方读 `src/data/recipes.js`（D 提供）。

### 3.5 界面
- 先用 `src/ui/kit.js`（A 提供的薄组件层：面板、按钮、列表、物品格、提示、确认框）写界面；UI 设计师的水墨组件库（`docs/ui/v2/kit/`）完成后替换外观，不改逻辑。
- 物品格显示：品质颜色（`RARITY[i].color`）、未鉴定显示"？"、占格大小。

## 4. 第一版必须跑通的闭环

1. 开始界面 → 新卷 → 开场 → 教学局 → 走到破洞府撤离 → 洞府（练气一层，学剑气斩）
2. 洞府 → 出行台 → 出行准备 → 区域一 → 搜打撤 → 撤离结算 → 入库 → 灵泉炼化升层 / 鉴定 / 炼丹
3. 区域一身陨 → 储物袋保留一半；区域二身陨 → 遗落储物袋 + 装备风险 → 下一局取回
4. 练气五层解锁第二法术栏、二段跳等；练气九层 + 筑基丹 → 突破（心魔试炼）→ 筑基一层
5. 存档：退出后续卷能回到洞府，进度完整
