# 战斗设计 · 方法论

通用方法 + 本项目取值。出处见 参考资料.md。

## 1. 动作手感的三件套：出招时间轴、取消窗口、预输入
- **时间轴**：每招拆成 起手（startup）→ 生效（active，出伤点）→ 收招（recovery）。数据驱动：`MOVES[]` 里写 `dur / hitTime / queueFrom / cancelFrom`（攻速 1 时的秒数），运行时统一 ×1/攻速。动作播放速度跟着招式时长缩放（`play(anim, fade, once, dur)` 设 timeScale = 片段时长 / 招式时长），判定与动作永远对齐。
- **取消（cancel）**：用另一个动作提前结束当前动作。分"部分取消"（只在窗口内）和"完全取消"（任何时候）。墨途：闪身 = 完全取消（不魂系）；普攻接普攻 / 施法 / 蓄势斩 = 部分取消（出伤之后、`cancelFrom` 起）。
- **预输入（buffer）**：在窗口打开前按下的指令先存着，窗口一开立刻执行。没有缓存，玩家 20–40% 的意图会因为 3–5 帧的时机要求落空（业内常用 0.12–0.16 秒缓存）。墨途：普攻 `queueFrom` 起记一次；右键蓄势斩缓存 0.35 秒（施法 / 闪身中约 1.2 秒，落地即放）。只缓存一个指令，新指令覆盖旧的。
- **判断标准**：用户说"按了没反应" → 先查缓存；"想停停不下来" → 查是不是缓存太长 / 自动接招。

## 2. 顿帧（hit stop）与反馈分级
- 顿帧是"视觉强调"，不是硬直（hitstun 是受击方的行动限制，两回事）。越重的招顿得越久；飞行物顿帧少；击杀、破盾、Boss 关键一击要额外强调（Sakurai："重要的时刻要停"）。
- 分级（Sakurai 的升级顺序）：停 → 停 + 震 → 停 + 震 + 慢动作。墨途取值：普攻 0.045 秒、第三段 0.08 + 震 0.28、满势蓄势斩 0.14 + 震 0.55 + 慢动作 ×0.35 / 0.12 秒 + 镜头推近 10% + "斩"字；半势只有 0.07 + 震 0.3。**演出等级本身就是"攒满再放"的回报**。
- 打击感 = 顿帧 + 声音 + 镜头（学术研究的三个显著因素）；墨途没有声音，靠镜头推近和墨迹补。

## 3. 资源循环（气势 / 怒气 / 魂）
- 两种范式：Hollow Knight 的魂是"花掉的货币"（命中 +11、上限 99，回血 33 / 法术二选一）；DMC 的风格分是"打得好不好的评分"（多样、连续、不挨打）。墨途的气势是货币型：普攻命中攒、右键花掉，额外奖励技巧（完美闪身 +25、破盾 +15）。
- 设计要点：①**获取来源要绑定想鼓励的行为**（普攻命中、多目标、精英、破盾、完美闪身）；②**花费时机交给玩家**（自动释放会剥夺决策——v1 的教训）；③**流失规则决定节奏**：会流失 = 逼你立刻用；不流失 = 允许"攒着带走"（v1.3 用户拍板不流失，让"小怪攒 → 精英放"成立）；④受击扣减是 DMC 式的惩罚，力度要轻（墨途 −4，势成不扣）。
- 校验：一次资源周期多长（墨途单体约 3 套三连 ≈ 4 秒势成），每周期的爆发值多少（满势 ≈ 1.8 个法术），占总输出多少（精英 20–30%、首领 15–25% 是 v1.3 的目标，数值策划用 num_ttk 复核）。

## 4. 闪避（i-frame）
- 冲刺 + 无敌帧是动作 roguelike 的节奏核心（Hades：慷慨的无敌窗口、随时可用）。限制它的方式：冷却 / 充能数。墨途：1 次充能 2.75 秒（练六起 2 次），完美闪身返还 60% 冷却——会闪的人几乎感觉不到冷却。
- 判定陷阱：闪避无敌和受击判定不同步会让玩家觉得"闪了还挨打"（Hades 被诟病的点）→ 无敌在 `beforeDamage` 里取消伤害，时长 = 闪身 0.18 + 0.1 秒余量。

## 5. 构筑（BD）设计
- 一个构筑方向 = 一个核心资源或行为 + 3–5 个改变它的修饰（获取、花费、触发、转化）。墨途普攻流：攒（《蓄势》、词条气势获取）/ 花（蓄势斩伤害词条）/ 触发（《余波》《回锋》）/ 状态（《满势》势成加速）/ 叠层（《连环》）。
- 同名效果规则要提前定：墨途是"同名不叠加"（心法栏 + 装备特殊词条只算一次），装备词条的价值是"把心法栏空出来"。
- 新机制给"身份"：剑意破盾（不看五行）让蓄势斩成为"没带克制法术时的破盾手段"，与五行法术互补而不是替代。

## 6. 伤害对标
- 一个技能的强度先对标同境界最常用的技能（墨途：剑气斩三道全中），再定倍率。纯攻击力倍率在低境界会被法术的固定值压过 → 加 `base`（与法术同构）。
- 反推方法：各境界测出对标技能的伤害 D(L) 与攻击 A(L)，目标 T(L) = k × D(L)，对 (A, T) 做直线拟合得 base + scale × 攻击，再按命中段拆分（横扫 65% / 剑气 35%）。工具：`tools/scenarios/num_charge.mjs`。

## 7. 首领（Boss）设计
> 案例：青牙 v2（`docs/design/boss_青牙_v2.md`，2026-11-17 设计稿）。出处编号见 参考资料.md"首领设计"一节。

### 7.1 先定"这场仗考什么"，再写招式
- 一个首领 = **一个核心问题 + 3–6 招**（Hollow Knight 常见 3–6 招；首领招式最好是本区域小怪招式之和，玩家在路上已经学过）。每个阶段只加 1–2 个新机制，并且和环境 / 弱点成对出现，不做孤立的难度。
- 每个首领要有**一招标志招**定义它（青牙 = 啸月：跑进月光读条，打断即倒地）。
- 三条通关路线都要成立（"技巧 / 力量 / 解法"）：技巧 = 读招、完美闪身、打断；力量 = 境界与构筑；解法 = 环境件（石柱、图腾、月光）。任何一条都不能单独决定成败，低境界高手能过、高境界新手也能碾过。

### 7.2 失衡条（架势 / 韧性）
- 双轨：气血 + 失衡。失衡满 → 倒地 / 处决窗口。**失衡按"动作"给，不按伤害给**（Elden Ring stance）：完美闪身、打断、撞墙、破盾、重击给大头，普攻只给一点。
- 回落：一段时间不涨就回落，**回落速度 × 气血比**（Sekiro：血越少架势越难恢复）——"先削血再压失衡"成为中手解法，高手专压失衡。墨途取值：3 秒不涨开始回落，每秒 −8 × (0.4 + 0.6 × 气血比)。
- 防反复倒地：第 n 次失衡后阈值 ×1.25^n。护甲 / 护盾在时失衡获取打折（Hades 护甲：护甲在时不吃硬直），让破盾有分量（墨途 ×0.6，打断 / 撞柱 / 完美闪身不打折）。
- 显示与否：Sekiro 显示、Elden Ring 隐藏。不魂系、强调进度可见 → 显示。

### 7.3 硬控打首领
- 冻结 / 眩晕直接作用在首领上会把它变木桩（黑神话定身术的争议：首领免疫、只吃一次、时长大减）。做法：首领 `ccMode: "poise"`，硬控折算成失衡值；真眩晕只留给奖励性事件（破盾、撞柱）。蓄势斩的"打断首领预警 0.5 秒"保留但 8 秒一次。

### 7.4 读条打断
- 读条招（召唤、蓄力大招）用**打断值累计**而不是"任意一下就断"：阈值 1.0 / 1.5，普攻 0.12、单道法术 0.34、重手段（满势斩、火符、冻结）1.0–1.5。意图：打断要"用一个重手段"，并且在真气有限时成为"这发蓝用来打断还是破盾"的决策。
- 读条进度要画在地上（墨圈向内收拢），并给出对应环境件的提示（召狼时对应狼窝的图腾亮起）。

### 7.5 预警、延迟招、惩罚窗口
- 预警三重：身体动作 + 地面墨晕 + 特殊提示（尾巴竖起、眼焰）。预警结束即出手（`animHit / windup` 对齐），**全场最多一个延迟招**，并在初见时点破（Margit 是教学型延迟招；滥用延迟会显得不公平）。
- 惩罚窗口 ≥ 1 套三连（Birkhead："hold 至少容一套连招"）；大招落空再加踉跄。招式表每招写：前摇 / 判定 / 后摇（窗口）/ 预警形式 / 应对 / 环境或失衡联动。

### 7.6 专属环境
- 场地按首领招式设计（Keren《Boss Up》）：障碍物间距按冲扑长度定；**可消耗的环境件**（撞一次就碎的石柱）让场地随战斗变化，也防止同一招无限利用。
- 环境件要两面性：图腾倒了少一窝狼，也少了攒势的来源；月光让它不能潜影，但它会跑进月光读条大招。
- 入场仪式：首次完整（4 秒）、之后短版（1.2 秒）；封门要留"撤"的出口（搜打撤：读条穿雾撤出，首领回满）。

### 7.7 成长曲线（同一首领从被虐到碾压）
- 首领强度固定，曲线全由玩家成长决定，才可测、可解释。
- 归因三分：数值（境界属性 + 装备）/ 解锁与构筑（栏位、法术、法宝、阵法、第二次闪身）/ 熟练。验证：同档位跑三种机器人（只换属性 → 再放开解锁 → 再加"熟练"行为），用 TTK、胜率差值拆。墨途目标 40 / 35 / 25。
- 熟练度要做成看得见的刻度：每次挑战记录"走到哪一阶段、剩多少血"，入场题签显示"第 N 次 · 上回削至 X%"（Hades 首领"记得你"）。强者回来时给情绪落点（首领畏缩）。
- 首领战不要吃局内天时 / 难度加成，否则同一档位体验差 20–35%，测不准。
- **气血反推**（数值策划方法）：有效气血 EHP ≈ 目标时长 × 可输出时间占比（窗口，约 50–55%）× 该档 DPS；处决、失衡易伤相当于 EHP −15–20%，不要再叠加上调。青牙：DPS 练二 118 → 练七 567 → 筑基 990，目标练六 150 秒 / 练七 80 秒 → EHP ≈ 17000（气血 15000 + 2 × 1500 护盾）。
- **固定首领时各档时长受 DPS 比约束**：相邻两档的时长比 ≈ DPS 比的倒数（练六七 → 练九只差 1.5 倍），"中档 90–150 秒、高档 < 60 秒"这种目标不可能同时成立 → 高档的"轻松"要用胜率、掉血、用丹来定义，而不是秒杀。
- **资源大招对首领的占比要单独看**：蓄势斩 v1.3 打首领一分钟 12–19 刀、占 37–56%（目标 15–25%）。单刀倍率是用户拍板的，就先降对精英 / 首领的攒势速度（频率），频率到位仍超标再回到用户讨论单刀。

### 7.8 处决演出
- 两种：失衡处决（大伤害不致死，2–2.5 秒）和终结处决（首次 4 秒完整、之后 2 秒短版）。演出服务节奏（Doom Glory Kill：处决是推进战斗的工具，后作为了节奏削减了同步动画）。
- 全程双方无敌、其他敌人定格，结束后严格还原镜头 / 时间缩放 / 后期参数（写进验收测试）。墨途语汇：去饱和 / 留白、一笔、"斩"、朱印、化墨；全部在现有后期 pass 里加参数 + 复用 DOM，不加新 pass。

## 敌人 AI 与预警（敌人模块 D，2026-11-17）

### A1. 攻击令牌（attack token）
- 同时出招的敌人数量设上限，其余敌人绕圈压迫，不直接上前，这样围殴的压力不会随怪数线性增长。业内常见做法：近战 1–2 个令牌，远程单独一池，难度越高令牌越多。
- 本项目取值：ENCOUNTER.maxAttackers = 1（数值复核后定的）。有首领在战斗时小怪最多 1 只，首领不占令牌。
- 令牌在 endAttack、死亡、回巢、移除时归还。

### A2. 预警时长约定（行业惯例，未公开定数）
- 轻招约 0.4 秒，重招 0.6–0.8 秒，首领大招 ≥ 1 秒，下限约 0.3 秒。
- 本项目：小怪 0.4–0.6 秒；精英大招 0.7–0.85 秒；首领 0.7–1.7 秒（潜水突袭 1.7 秒）。

### A3. 惩罚窗口（输出窗口）
- 预警清楚，并且躲开之后有惩罚窗口，玩家才会觉得是在"打"，而不是被逼着换血。
- 本项目的 RHYTHM：
  - 大招后摇：精英 1.2 秒、首领 1.4 秒；小招后摇 0.5 秒；
  - 大招落空再踉跄 0.5 秒；
  - 精英连出 2 招后喘息 1.5 秒，首领连出 2–3 招后喘息 2.25 秒；
  - 破盾眩晕：精英 3 秒、首领每段 2.5 秒。
- 可输出时间占比目标 45–55%。数值策划用 `num_ttk` 复核。

### A4. 仇恨与脱战（拉怪、各个击破）
- 进入仇恨只有两种途径：进入视野（并且够得着），或者受到攻击。
- 被惊动时只带起最近的 1–2 只同组同伴，被带起的不再连锁。
- 脱战：离巢太远（普通 24 米、精英 30 米、首领 34 米），或太久没接触（8 / 10 / 16 秒）就回巢。回巢途中免伤、每秒回 8% 血，到巢再回 30%。这样主角没法放风筝无限消耗它。

### A5. 流场寻路 + 到不了就撤
- 一次 BFS 得到"到主角的步数"表，所有敌人共用；同一目标 0.6 秒内复用（出处：Red Blob Games，见参考资料）。
- 到不了（主角站在高台、崖顶）时：有远程招式就在射程边缘打；没有就先嚎叫，再撤到 16 米外歇着。主角还守在巢附近的高处就一直不回，**绝不站着挨打**。

## 功法体系 v2：法术池与获取（2026-11-17，`docs/design/功法体系_v2.md`）

### F1. 扩技能池不做数值变体：五行 × 定位矩阵
- 每门法术写四列：**五行 / 定位（动词）/ 手势与施放方式 / 与现有机制的交互**。定位格两两不重复（墨途 12 门：破防、对空、蓄势、群控、突进、爆发、反击、群伤、召唤、守御、打断、位移），测试里断言"五行:定位"不重复。
- 新法术先查"这个动词是不是已经有别的载体了"（法宝、阵法、心法）：紫金葫芦已经是"吸 + 汲取"，所以漩涡（聚怪）、枯荣（吸血）两个候选淘汰（Hades 2：机制迁到合适的载体，不重复做）。
- 防御 / 冷门型要给进攻收益链才有人用（Hades 复仇祝福的教训）：止水诀反击 + 25 气势 + 读招狼威。
- 针对性工具（只狼义手）：每门法术对应一类敌人特征——掌心雷打落飞行、落石诀断读条、止水诀吃重击；克制写进 desc。
- 定位就是将来心法 / 词条的挂钩标签（Diablo IV 的 Mobility 标签挂装备）；标签要有一张查重 / 查漏表。

### F2. 五行护盾覆盖检查
- 列出所有可能出现的护盾五行（包括随机护盾的巡游头目），对每一行数"伤害型克制法术"≥ 2 门。墨途 v1 的土行只有不打伤害的土遁护体，**水盾没有任何法术解**——扩池时第一件事就是补这一行。

### F3. 获取：名门固定 + 野外残页 + 稀有完本 + 境界保底
- 名门功法（地点固定、首探必得）给"主线目标"；残页（区域 / 敌人 / 容器 / 地点固定的碑）给"刷的目标"；异种 / 首领掉完本给惊喜；境界只保底（开栏没东西装才赠）。
- 地点固定的来源（功法残碑：分区固定出哪门）让"去哪打"可记忆。
- 重复保护只用在大奖（完本"优先未学"，跨来源共享已学列表），残页照常随机（D3 Smart Loot：偏置而非保证）。
- 重复物的出路：化为通用进度（悟性）→ 补缺页（坏运气保底）+ 升阶；换算率低于直接获得（炉石：分解 20 / 合成 100）。墨途：重复 1 页 = 1 悟性，补 1 页要 3 悟性。

### F4. 指引从数据推出来
- 来源文字不手写：扫掉落表（SOURCES / 遗府 / 首领 / 境界赠予 / 残碑分区）自动生成"区域 · 谁 / 什么容器 · 残页 / 完本 · 概率档"，表一改指引就跟着变（`src/game/gongfa.js` gongfaSources）。
- 指引要连到"为什么需要它"：去处护盾分布 → 缺哪一行克制 → 哪几门能补、去哪拿（shieldGap）。

### 7.9 机制要"看得见"、代价要"实打实"（青牙试玩反馈，2026-11-17）
- **数值做了不等于玩家读到了**：用户问"领悟值是什么作用？没看出来"——狼威在涨、能折、能斩，但玩家没读出来。可读性闭环：**增量看得见**（每次上涨发 `poiseGain`，大额上涨时首领身上一震、溅墨、脚下威纹，条上新墨先亮后沉 + 来源字）→ **临界看得见**（过 75% 首领喘息、滴朱、微颤，条泛朱呼吸）→ **满了醒目**（长顿帧 + 0.3 秒慢动作 + 大墨溅 + "折" + 跪地）→ **能做什么看得见**（地面朱环 = 处决距离 + "F 斩 / 近前按 F"）→ **首次点一句**（题签"折其威，可斩"，只一次）。全部叙事内。
- **"可选机制"必须有不做的代价**：打断长嚎如果打不打都差不多，玩家就无视它。代价要落在玩家当下的资源上：群狼 1.5–2 秒内跃到身边包围、分工（卡退路 / 扑咬 / 专打读条）、和首领错开节奏，且要扛打（2–3 套三连）；打断的收益也要叠（狼威、硬直、气势）。召唤物的到达**不要依赖寻路**（跃至包围位），出生点离崖壁、碰撞体留余量。
- **破绽窗口奖励"重手段"**：撞柱后的窗口如果普攻照常，攻速快时就是"普攻堆刀"。窗口内普攻降伤但加失衡、重击 / 法术加伤——窗口变成"压威 → 处决"的跳板，而不是偷血。

## 构筑与成长 v1：流派设计（2026-11-18，`docs/design/构筑与成长_v1/02_流派与机制.md`）

### B1. 用"资源放在哪"区分流派，而不是用数值
- 两个流派如果资源放在同一个地方（都是"攒在身上放大招"），玩家手上做的事就一样，只是换皮。墨途五派：剑势 = 自身气势（可携带）；五行 = 真气 + 敌身五行状态；身法 = 敌人出招的那一刻 + 闪身充能；雷暴 = 敌身雷痕（换目标就重来 → 单体流）；守御 = 吸收掉的伤害（护体破碎时反震）。
- 新流派先填这张表："资源在哪 / 玩家在做什么 / 怎么花"，三列和已有流派都不同才立项。

### B2. ★三件 = 成型的最小定义
- 每个流派成型 = 1 本心法（入门）+ 1 门核心法术 + 1 件法宝或阵法；其余是增强件。数值策划按"★三件都可用的那一层"算 p50 / p90（`tools/build_growth/pieces.mjs`），平衡按"同档位各流派首领用时与中位数差 ≤ 20%"判（守御可 +35%，但掉血要少）。
- ★件要带输出：功能型★件（续航、放缓、护体）另配伤害乘区，否则流派整体偏慢（坑 48）。
- 入门心法本身要改手感（练二只有 1 个法术栏）：例如《锋锐》加"暴击叠雷痕"、《凝神》加"克盾返还"，不能只是 +15% 某属性。

### B3. 交叉件与"数档 / 形档交替"
- 交叉件：一个部件挂两个流派标签（Dead Cells 双色武器按较高项成长、不相加；墨途靠"同名不叠加"防翻倍）。法术三重变体是第二个交叉来源：同一门法术的两个变体挂不同流派。
- 每条成长轴都交替"数档"和"形档"（Hades：Pom 只升等级，Daedalus Hammer 可以彻底改玩法；只狼义手每次升级改行为）：法术二重数 / 三重变体；法宝三、五重改行为；阵法三重改形（剑阵随身、火阵火墙、聚灵阵无前摇）。

### B4. 首领检验不被绕开的写法
- 用结构表检查：每个流派"自己的伤害件"能克哪几种护盾（`schools_check.mjs`）。目标：除五行流外没有流派能自克五种护盾；五行流受法术栏 + 真气限制，考的是"出门前选对"。
- 规则：所有新伤害件都带五行、按 `SHIELD_TUNE` 打盾；唯一的"不看五行"手段（剑意）对首领每段累计封顶 60%；反打类（拂柳斩）不带剑意。某流派打盾太慢，先加强"破盾后"的收益，不给无视护盾的手段。

### B5. 触发链防爆
- 触发效果放出来的伤害（天雷、引爆的雷、反震）不能再触发同类触发（Risk of Rain 2 的 proc 系数：道具放出的闪电系数很低，长链难成）。墨途：触发伤害打 `thunder / mark / quake / reaction / dot` 标签，触发器一律排除这些标签。

### B6. 真气不自动回复下的续航件
- 只用"有条件、有代价"的来源：克制命中返还（《凝神》）、顺序减耗（《轮转》）、主动吸取要贴怪（葫芦）、站桩且每阵封顶（聚灵阵）、丹药。被动每秒回蓝（葫芦旧被动）和不封顶的光环（聚灵阵旧版 12 秒 180 点）都等于自动回复。
- 量级目标：五行流一局 / 一场首领可放法术 ≈ 非五行流的 1.6–2 倍（数值策划初算 1.8–2.0）。
