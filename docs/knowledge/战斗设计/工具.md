## 测试写法要点（loop_momentum 里的工具函数）
- `__mk(dist, side, hp)` 沿瞄准方向放木桩（**必须带唯一 id**，否则伤害事件按 id 过滤会串）；`__clearAll()` 清木桩 + 本局敌人。
- `__realm(stage, layer, xinfa)` 切境界并套用 `ctx.applyProfileStats`。
- `__combo(until)` 从第一段按住左键直到条件成立（先把 `comboIdle` 设大、等 `state === "move"`）。
- `__rclick()` 模拟右键（`input.mouse.rightPressed = true`，走 targeting 模块的真实分支），等到 `player:charge` 事件。
- `__noCrit(true)` 关暴击（比较伤害、比较气势时必须关：暴击会额外 +4 气势）。
- 时间一律用玩法时间（`world.time` / `player.momT`），不要用真实毫秒：无头浏览器帧率低，`dt` 被夹到 0.05，真实 1 秒 ≠ 玩法 1 秒。

## 调试小技巧
- 临时场景：在 `tools/scenarios/dbg_xxx.mjs` 写一次性脚本，用完删掉。
- 复制 num_ttk 成 `dbg_ttk.mjs` 加日志（如 `momMax / fullAt / near / bh`）定位机器人问题，用完删掉；运行时改数据用 `await import("/src/data/player.js")` 拿同一个模块实例直接改字段。
- heredoc 里含反引号的 Python 补丁会让 Git Bash 报 "unexpected EOF"：补丁脚本用 Write 工具写到 `%TEMP%` 再 `python` 执行。
