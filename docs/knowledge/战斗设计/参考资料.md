## 敌人 AI（敌人模块 D，2026-11-17）
- [Red Blob Games: Flow Field Pathfinding for Tower Defense](https://www.redblobgames.com/pathfinding/tower-defense/)：一次 BFS / Dijkstra 得到距离场，所有敌人共用；nav.js 用的就是这个思路。
- [Leif Erkenbrach: Flow Field Pathfinding](https://leifnode.com/2013/12/flow-field-pathfinding/)：cost → integration → flow 三层结构，出自 Game AI Pro 中 Elijah Emerson 的流场一章。
- [Ask a Game Dev：非首领敌人 AI 的设计](https://askagamedev.tumblr.com/post/620010728353595392/when-designing-non-boss-enemy-ai-ie-ai-for)：攻击令牌的协调者模式。拿到令牌的才能出手，其余做出威胁姿态，难度越高令牌越多。
- [Optimized Enemy Pathfinding（nathanreilly.dev）](https://nathanreilly.dev/optimized-enemy-pathfinding)：所有敌人共用一张流场，寻路开销不随敌人数增长。
