## 机制
1. **"长按蓄力"和"按住左键连砍"冲突** → 按住左键已经是连续出招，再加长按蓄力只能靠"按住超过 X 秒"猜意图，误触多 → 大招放独立按键（右键），左键只管三段循环。2026-11-16
2. **满势自动接第四段：玩家没法挑时机；满了还流失 = 打满白打** → 自动释放剥夺了资源决策 → 资源型大招一律主动释放；流失规则要和关卡距离一起想（小怪离精英远，会流失就攒不到）。2026-11-17
3. **伤害加成写成 `{ stat: "dmg", type: "more" }` 不生效** → `Stats.get` = (基础 + flat) × (1 + pct) × Π(1 + more)，dmg 基础值是 0，乘多少都是 0；完美闪身 +50% 因此一直没生效 → 独立乘区直接乘进招式的 `base` 与 `scale`；自定义属性（momGain 等）基础为 0 时也只能用 `flat` 记百分比。2026-11-17
4. **蓄势斩剑意破盾的 +15 气势被吞掉** → 破盾事件在出伤时触发，而气势在出伤之后才清零 → 先清零再结算伤害。2026-11-17
5. **伤害只按攻击倍率算，低境界打不过法术** → 法术有固定值（剑气斩 base 16 × 3），练气一层时固定值占大头 → 招式加 `base`，按"对标技能"拟合（见 方法论 §6）。2026-11-17
6. **控制打首领会锁死** → 每刀都打断预警 → 同一首领 8 秒内只打断一次（`t._chargeStunT`）。2026-11-17

## 构筑与成长 v1（2026-11-18，现状复核时发现）
43. **"真气不自动回复"有两处漏网**：紫金葫芦被动 `mpRegen +1 × 祭炼`（戴着就回）、聚灵阵 `mpRegen +15/秒` + `cdr +20%`（一阵 12 秒可回 180，超过一局预算一半）→ 用户约定要逐件对照数据查，不能只看 growth / baseStats；方案：葫芦被动只留真气上限，聚灵阵改每阵封顶的"灵池"。
44. **成长档用"冷却 −15%"会越过设计红线**：剑气斩 8 秒 × 0.85 = 6.8 秒，跌破"法术冷却 8–18 秒"→ 法术成长不要乘冷却，用伤害 / 耗蓝 / 变体。
45. **性能债会被新流派放大**：`skill_fx.lightning()` 每次 new 18 个 BoxGeometry + 2 个材质；`formationMesh` 每次布阵新建材质再 dispose → 雷暴（高频天雷）、阵法升重落地前先池化。
46. **WebFetch 对多数游戏 wiki / 社区不可用**（"Unable to verify if domain … is safe"），curl 也拿到 000 或拦截页 → 先试 curl，再用 WebSearch 摘要核对并在文档里写明"未直连"，不要把没核实的说法写成定论。
47. **剑势流一家独大是"部件供给"问题，不是数值问题**：剑势有 5 本心法 + 3 条词条 + 剑意 + 凝锋 + 飞剑 + 剑阵，其他流派核心件拿不到（五行流 0 本可得心法）→ 平衡时先补其他流派的件，不削剑势。
48. **★件"带不带输出"决定流派快慢，比心法数值影响更大**（构筑与成长 v1 数值实测，2026-11-18）：练九打碧鳞，剑势 / 雷暴比中位快 41–43%，五行 / 身法 / 守御在中位附近——飞剑占剑势 / 雷暴伤害 15–26%，葫芦 / 镇山印只占 1–4%；入门心法《锋锐》《连环》是伤害乘区，《凝神》《流云》《金刚体》不是 → 设计★件时每件都要回答"它占本流派输出的几成"，功能型★件（续航、放缓、护体）要另配一个伤害乘区；先让数值跑 `num_ttk bcurve=1` 分流派对比再定稿。
