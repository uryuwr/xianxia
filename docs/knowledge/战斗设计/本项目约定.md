## 数据格式
- 招式字段：`anim dur hitTime queueFrom cancelFrom radius halfAngle base scale knock step hitStop shake arc`（秒，攻速 1 时）。
- 自定义属性：基础值为 0 的（`momGain chargeDmg dashCdr mom_*`）一律用 `type: "flat"` 记百分比 / 开关；有基础值的（`aspd dashMax dashCd`）可以用 `pct`。
- **伤害加成不要用 Stats 的 `dmg` "more"**（乘 0），直接乘进 spec 的 `base` 与 `scale`。
- 伤害标签：普攻 `melee basic stepN`；蓄势斩 `melee basic charge`，剑气加 `wave`，余波加 `aftershock`，墨痕 `dot ink charge`，附灵加 `imbue`，打破盾易伤加 `vulnBonus`。

## 事件（ctx.world.events）
`player:attack {step, hits, charge?, full?}`、`player:charge {hits, wave, full, momentum}`、`player:chargeDenied`、`player:chargeReady`、`player:dashDenied`、`player:aftershock`、`player:swordIntent {target, cut, broke}`、`player:stagger {target, dur, full, kind}`、`player:imbue / player:imbueEnd`、`player:swordFly {from, to, water}`、`player:swordFlyDenied`。

## 风格
- 特效只用墨 + 一点朱 / 泥金 / 五行色点缀，不做霓虹、不做整片着色（UI 风格指南）。
- **朱只留给"你的命"（气血）和危险**（UI 体检 v1，用户拍板，2026-11-18）：势成的气势条是墨 → 泥金渐变（金晕、朱"势成"印、按右键势不足时抖朱保留）；新的增益 / 资源表现用泥金或五行色，不用朱。
- 敌人预警外观（UI 体检 v1）：纸色外描 + 3 px 深色线 + 斜皴填充，默认色 #b8291a；数据里的 `telegraphColor` 仍生效（外缘按亮度压深），`vfx.ring` 有 `warn` 选项。
- 紫色 0x7b4fa8 不在色板里（UI 组建议换掉）：现用于狼妖头目 aura / 嚎叫圈（`enemies.js`，敌人模块）、紫金葫芦吸取圈（`skills/artifacts.js`）。新设计不要再用；葫芦落地改版（构筑与成长 v1）时顺手换成水行石青或墨。
- 新特效遵守 `docs/性能优化_v1.md` 第 7 节：池化、不每次 new 材质 / 几何体、DOM 只在值变化时写。
