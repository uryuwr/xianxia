## 1. 公式

- **伤害**（`src/core/combat.js` 的 `dealDamage`）：
  - 伤害 = (base + atk × scale.atk + spell × scale.spell) × (1 + dmg) × 暴击（critDmg）× (1 − 五行抗性，最多 0.9) × 100/(100 + def) × (1 + vuln)。
  - `dmg` 是攻击方的总伤害乘区（序章倍率用 `dmg` 降伤害）；`vuln` 是受害方易伤（负数 = 减伤，护脉丹、灵气充盈都走它）。
- **护盾**（`src/game/shields.js` 的 `SHIELD_TUNE`）：
  - 护盾量 = 气血 × frac（精英 0.3、青牙每段 0.15、碧鳞每段 0.2，用敌人的 `shieldFrac` 覆盖）；
  - 克制 ×2、其他五行 ×0.2、无属性 ×0.25；附灵按 35% 克制；
  - 蓄势斩横扫 ×2.5、剑气 ×1.5；五行符自带 `shieldMul`；
  - 破盾后眩晕 2.5 秒、易伤 30%（持续 6 秒）。
- **敌人等级缩放**（`enemies.js` 的 `ENCOUNTER.scale`）：每级气血 +15%、攻击 +12%、防御 +8%，相对数据表的 `level`。
  - **把数据表等级写高、基础值同步上调，可以让缩放的绝对斜率更陡**：狼首按 4 级写、区域二精英按 9 级写，就是这样跟上主角输出的跃升。
- **刷怪等级**（区域规划 v2）：分区 baseLevel + clamp(玩家层数 − 分区 realm[0], 0, 1)；精英 +1；首领、异种固定；刷怪点可以写 baseLevel 覆盖。
- **主角**：
  - 成长表在 `progression.js` 的 growth（练气每层：气血 +30、攻击 / 法力 +4、防御 +2）；
  - 攻速 0.80 → 1.15（战斗开发维护）；
  - 真气 120 + 12 / 层，筑基 360，**不自动回复**；
  - 小境界常驻加成 `progressBonus = 0.4`。
- **灵值**（`core/items.js` 的 `valueOf`）= 基础 × 品质倍率（1 / 3 / 10 / 40 / 200）× 数量 × (1 + 0.1 × (等级 − 1))。**只是估价，不是货币。**
- **化灵**（`recipes.js` 的 `HUALING.stones`）：
  - 关键物品为 0；
  - 有修为的物品：xp × 0.2（灵物再乘品质倍率；聚气丹 × 0.07）；
  - 其余：min(灵值 × 类别比例 × 品质系数 [1, .8, .4, .25, .1], 每件封顶 [10, 25, 60, 150, 300])。
  - 硬约束：**化灵再炼化 ≤ 直接炼化**。
- **炼化**：灵石每块 2 / 3 / 4 修为（灵泉等级）；灵物 xp × 品质倍率 [1, 1, 1.3, 1.7, 2.2]。

## 2. 品级

全游戏只有一套：`core/items.js` 的 RARITY，0 凡 / 1 灵 / 2 宝 / 3 仙 / 4 极。种子年份是别名：十年 = 凡、五十年 = 灵、百年 = 宝、三百年 = 仙、千年 = 极。**不要另起"珍 / 稀"之类的档位。**

## 4. 已定决策（原因 · 日期）

## 6. 构筑与成长 v1（2026-11-18，方案阶段，未落地；报告 docs/design/构筑与成长_v1/03_成长与数值.md）

- **局程**：一次回府约升 2 层；序章 = 第 1 局，筑基 p50 第 6 局（新手第 7 局），74–81 分钟。"练 X 层"≈ 第 (X+1)/2 + 1 局。
- **★三件三拍**（玩法 / 战斗已采纳，待用户拍板）：练二入门心法五选一 / 练四"玄机子传功"送★法术完本 / 练六法宝匣。五个流派★成型 p50 练七（第 5 局）、p90 练八。
- **成本表（建议值）**：

| 轴 | 档位 | 成本 |
|---|---|---|
| 法术重（悟性） | 二重（伤害 +15%、耗蓝 −15%）/ 三重（变体） | 6 / 10 |
| 阵法重（阵纹 + 灵石） | 二重 / 三重 | 3 + 150 / 6 + 400 |
| 法宝祭炼（本命；非本命封顶三重） | 二 / 三 / 四 / 五重 | 灵石 120 / 300 / 700 / 1500 + 区域主材 1 / 2 / 2 / 4 + 辅材；**不用精英妖丹** |
| 散功 / 改入门 / 筑基重修 | — | 返还 80% / 30 灵石 / 100% |

- **悟性新来源（建议）**：拓碑 +1、遗府首通 +4、青牙 / 碧鳞首杀 +6 / +10、传功时已学会则直接升二重。第 4 / 6 / 8 局累计约 11 / 30 / 42。
- **法宝祭炼口径**：实例新字段 `refine`（1–5），`level` 只是物品等级；掉落一律一重，极品 = 1 + bonusLevel = 三重；`lv(L) = 1 + 0.25(L − 1)` 不变。bug（`run.js` loadoutOf 把物品等级当祭炼）修复前的旧存档：建议校正到二重 + 返还 120 灵石（待用户选）。
- **续航件约束**：葫芦被动去掉 mpRegen；吸取回气 = min(伤害 × 0.3, 15 + 3 × (重 − 1))，首领先 ×0.5；灵池每阵 36（二重 47）；凝神回气丹 +25%；轮转 −25%。目标：五行★一局法术次数 = 非五行的 1.6–2 倍。
- **流派平衡目标**：同档首领用时与中位差 ≤ 20%（守御 +35%）；首领战蓄势斩类占比 剑势 ≤ 40%、其他 ≤ 20%。2026-11-18 实测：剑势 / 雷暴比中位快 41–43%，五行 / 身法 / 守御比"现状通用配装"还慢约 50%（★件不带输出）。
- **掉落偏置**：替换式 b = 0.5，叠分区道途 70% 后封顶 75%。
- **青牙实测基线（05，2026-11-18，真青牙、n = 10–12）**：现状通用配装 练四 莽 0% / 闪 67% / 熟 83%；练五 0 / 100 / 100；练六 0 / 100 / 100；练七 100 / 100 / 100（T2 标准 闪 10–30%、熟 40–60%；T3 莽 20–40%、闪 ≥ 60%、熟 ≥ 90%）。练四→练五是悬崖（+40 个百分点）。建议方案 C（处决 12%→6%、狼威阈值 100→130、攻击 40→52）待用户拍板；"练六给法宝"只在飞剑 + 莽上出界（自动清狼）。
