# 数值策划 · 参考资料

> 标题 + 链接 + 一句话结论。【未核实】= 只看到搜索摘录。检索于 2026-11-17。

## 书与系列
- **Ian Schreiber, *Game Balance Concepts***（数值关系、成本曲线、成长与节奏）：https://gamebalanceconcepts.wordpress.com/2010/07/14/level-2-numeric-relationships/ 。三角数是递增成本的好初值；用成本曲线给收益定价。
- **Schreiber & Romero, *Game Balance*（CRC Press 2021），第 4 章 Curves**。等级曲线常是对数的，XP 常是指数的，最终会趋平。
- **Adams, *Fundamentals of Game Design*（锯齿难度）**：http://what-when-how.com/Tutorial/topic-916bp3fs4/Fundamentals-of-Game-Design-366.html 。锯齿形难度带来好的节奏。

## 成长 / 防御 / 伤害
- **OSRS Wiki – Experience**：https://oldschool.runescape.wiki/w/Experience 。指数 XP，每 7 级翻倍。
- **LoL Wiki – Armor**：https://leagueoflegends.fandom.com/wiki/Armor 。`100/(100+R)` ⇒ EHP 随护甲线性增长（与墨途的防御公式相同）。
- **PoE Wiki – Armour**：https://pathofexile.fandom.com/wiki/Armour 。护甲按单次命中伤害计算，对大招弱（k 值【未核实】）。
- **D4 伤害桶**：https://diablo4.gg/diablo-4-damage-buckets-and-formula-explained/ 。同桶相加、异桶相乘，分散投入收益更高。
- **PoE 怪物等级 / 生命**：https://pathofexile.fandom.com/wiki/Monster_level ；https://poedb.tw/Monster 。高等级地图怪的生命 +43–166%，伤害只 +0–22%。

## 掉落 / 保底
- **Liquipedia – Pseudo Random Distribution**：https://liquipedia.net/dota2/Pseudo_Random_Distribution 。`P(N)=C·N`，有 C 值表；期望不变，切掉长尾。
- **炉石保底**：https://senseos.gg/guides/hearthstone/pack-odds-and-pity-timer/ 。传说 5.47%，40 包必出。
- **D3 坏运气保护**：https://us.forums.blizzard.com/en/d3/t/bad-luck-protection/10010 。软保底（数值【未核实】）。

## 经济
- **Adams, Machinations**：https://www.gamedeveloper.com/design/the-designer-s-notebook-machinations-a-new-way-to-design-game-mechanics 。用 Source / Drain / Pool / Converter 建模资源流。
- **Daniel Cook, Value chains**（Lostgarden 2021）：https://lostgarden.com/2021/12/12/value-chains/ 。每种资源要有"去处链条"，否则会贬值。
- **EVE 季度经济报告**：https://cdn1.eveonline.com/community/QEN/QEN_Q4-2010.pdf 。按类别拆分产出与回收来治理通胀。
- **WoW 金币回收史**：https://www.engadget.com/2012-07-06-wow-archivist-an-expensive-history-of-gold-sinks.html 。服务费 + 奢侈品两类回收。
- **D3 拍卖行**：https://www.pcgamesn.com/diablo/diablo-3-director-jay-wilson-auction-house-would-turn-it-if-we-could 。交易成为终局，削弱了掉落。
- **Dark and Darker Hotfix**：https://darkanddarker.com/news/175 。回收过狠会通缩。
- **塔科夫交易 / 保险**：https://escapefromtarkov.fandom.com/wiki/Trading ；https://escapefromtarkov.fandom.com/wiki/Insurance 。跳蚤市场手续费按偏离基准价指数惩罚；保险让"风险损失"可控。

## 模拟 / 画像
- **Machinations – 模拟玩家画像**：https://machinations.io/articles/balancing-f2p-economies-simulating-player-personas-and-progression-curves-with-machinations 。多画像跑分位数。
- **Holmgård 等, MCTS 画像建模（AIIDE 2015）**：http://julian.togelius.com/Holmgard2015Monte.pdf 。用 MCTS 代理模拟不同决策风格的玩家。

## 难度 / 心流
- **Cognitive Flow**（Game Developer）：https://www.gamedeveloper.com/design/cognitive-flow-the-psychology-of-great-game-design 。挑战 ≈ 技能时进入心流。
- **Hunicke, The case for DDA（ACE'05）**：https://dl.acm.org/doi/10.1145/1178477.1178573 。调补给而不是调敌人；DDA 被察觉会有反效果。
- **Hades 惩罚契约**：https://hades.fandom.com/wiki/Pact_of_Punishment 。按百分比加敌人生命 / 伤害 / 数量来叠难度。

## 构筑平衡 / 洗点（检索于 2026-11-18）
- **Riot /dev: Champion Balance Framework（2019）**：https://nexus.leagueoflegends.com/en-us/2019/05/dev-champion-balance-framework/ 。按四类玩家群定超模 / 弱势：普通玩家胜率 > 54.5%（ban 率低于均值时）算超模、≤ 49% 算弱；先修超模的。我们把它当"流派用时与中位 ±20%"的类比依据（推论，不是同一量纲）。
- **Riot 框架 2020 更新（Surrender at 20 转载）**：https://www.surrenderat20.net/2020/06/red-post-collection-dev-balance.html 。只有"四类玩家里都弱"才加强。
- **Diablo IV 洗点费用（Blizzard Watch 2023）**：https://blizzardwatch.com/2023/05/12/respec-skills-talents-paragon-diablo-4/ 。前几级免费，之后每点费用随等级递增（25 级约 110 金 / 点）【数值随版本变过】。用于"散功返还 80%、早期改选便宜"的依据。
