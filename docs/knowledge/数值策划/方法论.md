# 数值策划 · 方法论

> 通用方法 + 公式（写清变量）+ 本项目的取值 + 出处。最近更新 2026-11-17。出处的完整链接见 参考资料.md。

## 1. 成长曲线

| 形状 | 公式 | 适合 | 本项目 |
|---|---|---|---|
| 线性 | `f(n) = a + b·n` | 每层固定增量的属性 | 练气每层气血 +30、攻击 +4、防御 +2；真气 +12 |
| 三角数 | `T(n) = n(n+1)/2` | 递增成本的"第一猜"（Schreiber） | — |
| 指数 | `f(n) = a·bⁿ` | 升级所需经验（RuneScape：每 7 级翻倍） | 修为需求 100 → 1200，近似 ×1.3 / 层 |
| 对数 | `f(n) = a·ln n + b` | 收益递减的能力 | — |
| S 曲线（logistic） | `f(x) = L/(1 + e^{−k(x−x₀)})` | 有上限的属性、"毕业"进度 | — |
| 分段 | 各段分别拟合，在区域或大境界边界接上 | 区域 / 大境界跃升 | 筑基 ×1.5 跃升；敌人每个区域一档 |

**判断标准**：盯"每一级的耗时比"，即玩家能力增长 ÷ 内容成本增长，不看绝对数值。

**本项目的做法**：
- 主角能力 = 线性的境界属性 + 装备（随等级、品质）+ 构筑（法术、法宝、心法）；
- 敌人 = 数据表基础 × (1 + 0.15 × 等级差)；
- 区域内"越打越轻松"、换区域"再次吃力"，形成锯齿（见第 6 节）。

## 2. TTK / EHP / 防御

- **EHP（有效生命）**：
  - 通用式：`EHP = HP / (1 − DR)`；
  - 乘区式防御：`伤害 × 100/(100 + def)` ⇒ `EHP = HP × (1 + def/100)`。每点防御 = +1% EHP，按 EHP 算是线性的，按减伤百分比算则递减。
  - 本项目就是这种（`combat.js`）。LoL 的护甲是同一公式。
- **PoE 护甲**：`DR = A/(A + k·D)`，按单次伤害 D 计算，大伤害命中时护甲效果差（"对大招脆"）。本项目不用。
- **TTK** = `EHP_目标 / DPS_有效`。
  - 期望暴击：`E[D] = D·(1 + c·(m − 1))`，c 是暴击率、m 是暴伤；
  - 单次命中方差：`D²·c(1−c)(m−1)²`（推导）。
  - 本项目：练一暴击 10% × 1.6 → ×1.06；带《锋锐》25% × 1.9 → ×1.225。
- **伤害乘区**（D4 的"桶"）：同桶相加，异桶相乘，乘区越多，数值膨胀越快。本项目的乘区：(1 + dmg)、暴击、五行抗、防御、易伤、"more" 修正。新加加成时先想清楚它进哪个桶。
- **把 TTK 换算成"段 / 套"**：
  - 普攻三段 1.0 / 1.0 / 1.6；
  - 平均几段 = 用运行时的每段伤害和暴击率抽样（`num_ttk`）；
  - 一套 ≈ 0.74 秒（攻速 0.8 时第一段到第三段出伤，不计顿帧）。
- **TTK 的参照**（难度复核 §3）：
  - Hades：杂兵 1–2 下，Thug 约 2.3 套；
  - Dark and Darker：骷髅约 1.7 套；
  - 精英的有效血量约为普通怪的 2.5–4 倍（Hades 的护甲条、PoE 稀有怪 ×4.9）；
  - 主角能扛 5–10 下普通攻击。

## 3. 掉落与保底

- **几何分布**：期望次数 `1/p`；n 次内至少一次 `1 − (1−p)ⁿ`；中位数约 `ln2/p`。
  - 本项目：小怪装备 6% → 期望 17 只；灵品以上 1.9% → 期望 53 只，所以有"40 只保底"。
- **PRD（伪随机，Dota 2）**：`P(N) = C·N`，N 是距上次触发的次数，触发后清零。名义 25% → C ≈ 0.0847；名义 50% → C ≈ 0.302。期望不变，长时间的坏运气被切掉。
- **硬保底**（炉石：40 包必出传说）、**软保底**（D3：越久不出，概率越高）。
  - 本项目：小怪 40 只保底灵品；机缘值满 100 必出极品（软 + 硬的组合）。
- **加权表** `P_i = w_i / Σw`；要降低方差，可以"不放回抽"（bagging）。
  - 本项目的重铸"不能掷出已有的属性"，就是不放回抽。
- **原则**：期望由 p 决定，体验由尾部决定。改尾部（保底），不改期望。

## 4. 经济：产出与回收

- **Machinations 元素**：Source（产出）、Drain（回收）、Pool（池）、Converter（转换）、Trader（交易）。
- **健康度**：回收 / 产出约 95–105%（低于 90% 预警，博客观点），再看分层持有量、流通速度。
- **案例**：
  - EVE 用月度报告拆分产出与回收，通胀时增加回收、减少产出；
  - WoW 的回收分"服务费"和"奢侈品"两类；
  - D3 拍卖行让交易变成了终局，掉落失去意义；
  - Dark and Darker 曾因回收过狠导致通缩。
- **Converter 必须有不等式约束**：两条转换路径不能形成套利环。本项目的约束是"化灵再炼化 ≤ 直接炼化"（见 坑.md 第 3 条）。
- **本项目**：
  - 产出：怪物、宝箱、亭子、化灵、药园、灵田；
  - 回收（灵石）：设施升级、符箓、炼器、重铸（中后期主回收）、灵泉炼化（转修为）；
  - 灵值只是估价，不是货币，不进入流转。

## 5. 蒙特卡洛与玩家画像

- 每种画像一组策略参数（撤离率、入夜概率、击杀倍率、委托数），跑 N 次，看分位数（p50 / p90），不看平均。误差约 ∝ 1/√N，每种画像 2000 次足够。
- **本项目**：
  - 画像：谨慎、贪心、新手；
  - 目标：到筑基中位 7–8 局，p90 ≤ 120 分钟；
  - 标【假设】的参数（单局时长、击杀数、撤离率）尽快用实测回填，并做 ±25% 的敏感度分析。
- **建模理性行为**：只要存在更优的路径（例如套利），sim 里的玩家就会走那条路。否则 sim 会漏掉漏洞，见化灵 34 倍的教训。

## 6. 难度曲线与心流

- **心流通道**：挑战 ≈ 技能。太难焦虑，太易无聊（Csikszentmihalyi；Jenova Chen 2006）。
- **锯齿**：上升 → 短暂放松 → 更高的上升（Adams）。
  - 本项目：区域内敌人的气血缩放（+15% / 级）慢于主角成长 → 越打越轻松；换区域 → 再次吃力。练一 1.85 套 → 练四 1.24 套 → 练五 1.93 套 → 练八 1.67 套。
- **DDA（动态难度）**：只在看不见的地方调补给（Hunicke 2005）。会被察觉、会削弱成就感，本项目不做。
- **"不憋屈 / 不无脑"的量化**：
  - 憋屈 = "莽"机器人（不闪避）的阵亡率；
  - 无脑 = "闪"机器人几乎不掉血、且单怪能被连招锁死。
  - 两者都用 `num_ttk` 测。

## 7. 实测优先

公式只作粗算。以下因素都只能靠实测：攻速、顿帧、打断（霸体）、击退、扇形一次扫到几只、AI 的出手频率、法术实际命中几道。
- 流程：先用公式估算 → `num_ttk` 实测 → 用实测回填 sim 参数 → 再看局数和时长。

## 8. 构筑节奏与流派平衡（2026-11-18，构筑与成长 v1）

- **成型度（草图口径）** = 流派部件表里每件"到第 L 层已可用"的概率取平均；≥ 70% 成型、≥ 35% 定向。概率用蒙特卡洛（真实掉落表 × 每局接触数 × 局程）算，不要用"必 / 常 / 罕"拍权重。另配一个**个体口径**：核心 N 件全部可用的那一层，给 p50 / p90。
- **"每局 ≥ 25%"规则**：几何分布，n 局内至少一次 = 1 − (1 − p)ⁿ。墨途筑基前只有约 4 局可掉（区域一 2–3 局 + 区域二 2–3 局），p = 25% 时 68%，p = 6% 时 22%。核心件要么确定给，要么每局概率 ≥ 25%。
- **选择点 > 随机掉落**：局数很少的游戏，流派核心件用"三拍确定来源"（入门选择 / 传功 / 匣），随机掉落只给增强件（D3 Smart Loot：偏置而非保证）。
- **偏置叠加公式**（替换式）：最终同流派份额 = b + (1 − b) × 基础份额。两层偏置（身上流派 b、分区道途 z）相乘后要封顶（墨途 75%）。"权重 ×k"式的偏置在基础份额很低时几乎不起作用（0.06 → 0.11）。
- **★件功率对等**（Schreiber 成本曲线：同成本同价值）：同一栏位、同一时间到手的各流派核心件，对首领的贡献应相近（墨途：★法宝 ≈ 飞剑 +15–20%，入门心法 ≈ 锋锐 +15%）。判断流派失衡时先看"★件本身带不带输出"，再看数值。
- **流派平衡的带宽**：同档首领用时与中位数相差 ≤ 20%（守御允许 +35% 换生存）。参照 Riot 的英雄平衡框架（普通玩家胜率 > 54.5% 算超模、≤ 49% 算弱，大约是 50% 上下 ±5 个百分点；这是胜率带，我们换成用时带是推论）。
- **首领用时分解**：机器人用时 = Σ 护盾 / (破盾速度 × defAdj) + 气血 / (本体 DPS × defAdj)，defAdj = (100 + 测试对象防) / (100 + 首领防)；真人 ≈ ÷ 输出窗口（0.55）。本体和破盾分开测，比直接打首领更稳（首领 AI 流程会干扰）。
- **真气要分"首领战"和"一局预算"两层看**：首领战通常卡冷却不卡真气；真气预算只在整局里起作用。续航件按"相对非续航流派的倍数"定目标（墨途五行流 1.6–2 倍）。
- **胜负型指标（胜率）对能力是阶跃的**：同一配装多一层境界，胜率可以从 50% 跳到 100%（"活得过二阶段"的门槛）。按两层一档写的目标（T2 练四–五）要用"两层平均"判，并分别报两层；样本 10–12 次时 95% 区间约 ±25 个百分点，只把"区间也在带外"的格判出界（Wilson 区间，`qingya_report.py`）。
- **先测基线再归因**：问"X 改动是否让首领太容易"之前，先测"不做 X 的现状"——05 发现现状本身就出界，X（构筑提前）不是原因。
- **敏感度表**：首领侧每个旋钮单独开、再两两叠加，看它对哪类玩家（莽 / 闪 / 熟）起作用。狼威 / 处决只压"会闪的人"（完美闪身给狼威），攻击加成压所有人，气血加成也拖慢高层。
