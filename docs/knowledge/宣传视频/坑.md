# 宣传视频 · 坑

格式：现象 → 原因 → 规避 →（日期）

1. **画面里出现"100000"之类的伤害数字**
   - 原因：录制脚本用 `world.dealDamage(..., {base: 1e5})` 秒怪，伤害飘字照常弹出。
   - 规避：只用真实伤害。需要控制节奏时，在 `damage` 事件里把血量抬回下限（例如 Boss 按分镜 56% → 30% → 2%），让真实攻击收尾。
   - 不要用 `beforeDamage` 改伤害值，否则飘字会变成"1"这类怪数。
   - 也可以直接把怪的血量调低。（2026-11-17）
2. **结算手卷只展开了一半就被剪进片里**（左边立绘、右边账目被裁，数字缺失）
   - 原因：段落从切场景的那一刻就开始取，手卷 0.8 秒的展开动画和 0.9 秒起的逐件揭晓还没放完。
   - 规避：用 `settle(R, 根选择器, {min: 1.5})` 等进场动画结束，再打 `*Ready` 标记，剪辑表从 Ready 开始取。
   - 鼠标先挪到角落，免得弹出物品浮签。结算、天机镜、炼器结果、境界页、储物袋、地图都这样处理。（2026-11-17）
3. **慧慧（Huihui）TTS 配音被用户否决**："女配音有点难听，还不如不配音，只留字幕。"
   - 规避：默认不配音，只用字幕 + 配乐。真要旁白需要真人或更好的语音，先给用户试听。（2026-11-17）
4. **clips 被并行重录或改名失败**
   - 原因：另一位同事读 `work/video/clips/*.mp4` 做样片时，Windows 锁住了文件，`rename` 报 EPERM，镜头被判失败。
   - 规避（已实现）：录制先写 `<镜头>.part.mp4`，结束后改名；改名重试 8 次，仍失败就另存成带时间戳的文件，清单里的 `file` 指向它。
   - 读素材的一方应先拷一份快照再剪（样片用的是 `sample/src_snap/`），避免剪到一半素材变了。（2026-11-17）
5. **CDP 截图只有 1280×720**
   - 原因：`deviceScaleFactor: 1.5` 的上下文里，`Page.captureScreenshot` 默认按 CSS 尺寸截。
   - 规避：截图参数带 `clip: {x:0, y:0, width:1280, height:720, scale:1.5}`。字卡帧用 `page.screenshot({scale: "device"})`。
   - 出片前用 ffmpeg 看一下 Stream 分辨率。（2026-11-17）
6. **游戏在录制中途改了操作**（蓄势斩从三段后自动接出，改成右键主动释放；法宝从右键改成 V）
   - 现象：左键按满四秒都不出蓄势斩；右键法宝失灵；按 V 后进入了瞄准预览，左键被当成确认。
   - 规避：按键方案自动识别（`controls.json` 的 `detect`）。放法宝后如果 `__targeting.active`，补一下左键确认。
   - 录前先看一眼 `src/game/player.js` 顶部注释里的操作说明。（2026-11-17）
7. **Boss 在收尾前就被打死了**
   - 原因：筑基境界加火附灵、缠藤、飞剑，伤害太高，半血后几秒就死了。原先的血量保护只在收尾时才挂上。
   - 规避：保护从刷出 Boss 的那一刻就挂上，用 `__bossFloor` 分段放开。（2026-11-17）
8. **`await __cave.breakthrough()` 永远不返回**
   - 原因：它要等玩家点"收功"，`page.evaluate` 一直挂着。
   - 规避：不 await，后台调用后去点 `[data-act=break-done]`。
   - `record.mjs` 加了单镜头看门狗。（2026-11-17）
9. **落版"墨途"大字结束动画后跑偏**
   - 原因：`ink-bleed-in` 关键帧的终点是 `transform: none`，冲掉了居中用的 `translate(-50%, -50%)`。
   - 规避：外层容器负责定位，内层只做动画。（2026-11-17）
10. **刀光出现红色方格"马赛克"**
    - 原因：游戏着色器的飞白用的是 `floor()` 网格哈希加硬 step，跟录制无关。
    - 已由特效组在 `src/fx/player_fx.js` 改成沿笔势方向的细丝噪声。
    - 规避：发现画面问题先用原生分辨率帧判断是游戏渲染还是缩放造成的，游戏问题转给对应的组。
    - 敌人预警扇形的边缘也略有锯齿，待确认。（2026-11-17）
11. **字幕挡住技能栏和 HUD**
    - 规避：用宣纸画框，字幕只放在底部字幕带里（见 方法论.md §3）。（2026-11-17）
12. **ffmpeg 9 报 `Unrecognized option 'filter_complex_script'`**
    - 规避：改用 `-/filter_complex <文件>`。
    - drawtext 的 `%{pts\:hms}` 在 JS 模板字符串里要写成 `\\:`。（2026-11-17）
13. **地图着墨的坐标**
    - `run.explored` 是覆盖全图的 64×48 网格，换算用 `E.b`（x0 / x1 / z0 / z1），着墨后 `E.stamp++` 再 `hudUI.mm.drawBig()`。
    - 揭示的路线要落在当前视野（以主角为中心）里，否则看不出效果。（2026-11-17）
14. **妖潮刷在镜头外**
    - 原因：`run.spawnWave` 按地图夜袭点生成，可能离主角 16–30 米。
    - 规避：录制时临时替换 `r.spawnWave`，改成在主角身边 `spawnPack`。游戏自己的"妖潮来袭！"提示照常出现。（2026-11-17）
15. **背景里录进奇怪的东西**（巨大的绿色叶片、整片暗影）
    - 原因：机位没选好。
    - 规避：先用 `_explore.mjs` 截静帧挑地方。r1 东桥头 (4~8, 34~37) 一带开阔干净。（2026-11-17）
