# 宣传视频 · 范例（值得沿用）

## 1. 宣纸画框 + 底部字幕带
- **是什么**：实机画面缩到 90%，嵌在纸纹边框里，底部是墨色楷书字幕带。整体像装裱好的画卷，字幕一个 HUD 都不挡。
- **为什么好**：主管为解决"字幕挡技能栏"而定下这个做法，用户看过样片 v2 后反馈"还行"，并要求完整版沿用。
- **位置**：`tools/trailer/overlay.html`（`.paper` / `.border` / `.sub`）、`build.mjs` 合成段。
- **适用**：任何 HUD 密集的实机宣传片。

## 2. 虚拟时钟逐帧录制
- **是什么**：`vt.js` 接管游戏时间、定时器和 CSS 动画，每帧严格推进 1/30 秒再截图。
- **为什么好**：截图再慢也不掉帧、不抖动；游戏里的慢动作是真实逐帧渲染；同一脚本重录结果基本一致。
- **位置**：`tools/trailer/vt.js`、`lib.mjs`。
- **适用**：所有需要稳定帧率的录屏，包括 UI 动画展示、对比视频。

## 3. 剪辑表锚在录制标记上
- **是什么**：分镜写成"片段 + 标记 + 偏移"，例如 `{clip: "s05_loot", at: "kill", from: -0.8, toAt: "xian", toOff: 1.6}`。
- **为什么好**：重录后时间变了，剪辑、字幕、音效、配乐段落仍然自动对齐。用户说"等各组改完一条命令重录"，这次就是靠它做到的。
- **位置**：`tools/trailer/edit.mjs`、`record.mjs` 中的 `R.mark`。

## 4. 字幕规则自检
- **是什么**：构建时按规则检查每条字幕：停留时长、间隔、行宽，是否和字卡同屏，是否拖过关键镜头，违规打印 ⚠。
- **位置**：`build.mjs` 的 `planSubs`。
- **适用**：所有带字幕的视频，包括风格样片。

## 5. 字卡、字幕、落版用游戏自己的水墨 UI 套件渲染
- **是什么**：在浏览器里用 `src/ui/ink` 的印章 mask、笔触和纸纹，加完整书法字库，渲染出带透明通道的 PNG 和 mov。
- **为什么好**：风格和游戏 UI 同源，不需要另做美术；改文案只要重跑。
- **位置**：`overlay.html`。

## 6. 用户认可的字幕文案（风格样片 v2，用户评价"还行"）
- "加个班，避个雨，人就进了画里" / "手机？成了天机镜" / "活着回洞府，才算赚"
- 特点：短，一句一个意思，带一点穿越式自嘲，不解释机制。
- 完整版沿用这个路子："青牙？比周五的甲方好对付。""天机镜：我那部碎了屏的手机。"

## 7. 收尾斩首领的演出
- 分段破盾：剑气斩破木盾，半血换土盾，缠藤诀破土盾。
- 接着放 V 飞剑，再满势右键蓄势斩。游戏自带慢动作、推镜和「斩」字，录制时再放慢到 1/2，Boss 被真实伤害打倒，然后定格进落版。
- 位置：`shots.mjs` 中的 `s18_boss`。
