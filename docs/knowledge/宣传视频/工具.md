# 宣传视频 · 工具

流水线全部在 `tools/trailer/`，分镜与规则在 `tools/trailer/script.md`。

## 一键构建 build.mjs
```
node tools/trailer/build.mjs                       # 全流程：重录 18 个镜头 → 字幕/字卡 → 配乐 → 混音 → 成片 + 15s 版 + 联系表（约 15 分钟）
node tools/trailer/build.mjs --no-record           # 只重做后期（用 work/video/clips 现有片段，约 3 分钟）
node tools/trailer/build.mjs --record=s05_loot,s18_boss   # 只重录这些镜头再出片
node tools/trailer/build.mjs --only=full|short     # 只出完整版 / 短版
```
- **产物**：`work/video/墨途_宣传_v1.mp4`、`work/video/墨途_宣传_15s.mp4`、`work/video/contact_sheet.png`（每 3 秒抽一帧）。
- **中间文件**：`work/video/build/<成片名>/` 下有 `timeline.json`（实际时间线，汇报以它为准）、`cues.json`（配乐段落）、`mix.json`、`filter.txt`（ffmpeg 滤镜图）、`ov/`（字幕 PNG、字卡 mov）。
- **字幕违规会打印 `[build] ⚠`**：间隔不足、超行、和字卡同屏、拖过关键镜头。出片前确认没有 ⚠。

## 录制
- `node tools/trailer/record.mjs [镜头名 ...]` 录制镜头，输出 `work/video/clips/<镜头>.mp4` 和 `.json`（帧数 + 标记 marks）。
  - 每个镜头用独立的浏览器上下文（存档互不影响）。
  - 看门狗：默认 300 秒超时，失败重试 2 次，失败时截图 `<镜头>_fail.png`。
- 镜头表在 `tools/trailer/shots.mjs`，每个镜头是 `{ name, open, run(R) }`。常用工具函数：
  - `startRun`：进入 r1 / r2，设好境界、法术、青锋剑、飞剑、无敌，清场并关掉夜潮。
  - `place`：传送主角并切镜头。
  - `spawn`：在主角附近刷怪。
  - `walkTo`：按镜头朝向换算成 WASD 真按键走到目标点。
  - `holdAttack`：按住左键连段。
  - `comboCharge`：打满三段后接蓄势斩。
  - `castArtifact`：放法宝。
  - `trackEnemy`：鼠标每帧跟着敌人。
  - `settle`：等界面进场动画结束。
  - `R.mark(k)`：在片段里打时间标记。
- `lib.mjs` 提供 `launch()`（Vite 随机端口 + Chromium）和 `Rec` 类：
  - 帧推进：`frame()`、`frames(n)`、`sec(s)`、`skip(n)`（只推进不录）、`real(ms)`（切回实时）。
  - 片段：`clip(name)` 开始、`cut()` 结束。
  - 输入（全部是真实事件）：`key()`、`down()`、`up()`、`mouseTo()`、`click()`、`clickSel()`、`mdown()`、`mup()`。
- **按键方案**：`tools/trailer/controls.json`，默认 `detect`。游戏里有 `player.tryCharge` 就按新方案（右键蓄势斩、V 法宝）。临时覆盖用环境变量 `TRAILER_CHARGE=auto|right`、`TRAILER_ARTIFACT=right|KeyV`。
- **调试日志**：`TRAILER_DEBUG=1 node tools/trailer/record.mjs s18_boss`。
- **找机位**：`node tools/trailer/_explore.mjs "<query>" "" x,z,view ...`，按坐标截静帧到 `work/video/explore/`。
- **抽帧检查**：`node tools/trailer/peek.mjs <视频> <out.png> [间隔秒=0.5] [列=4] [宽=480]`，带时间戳拼图。

## 虚拟时钟 vt.js（稳 30fps 的关键）
- 作为 initScript 注入，先于游戏脚本执行；不改 `src/`。
- 它替换了 `performance.now`、`Date.now`、`requestAnimationFrame`、`setTimeout` / `setInterval`，并接管所有 CSS 动画、过渡、WAAPI（`document.getAnimations()` 暂停后逐帧设置 `currentTime`，到终点调用 `finish()` 触发 animationend）。
- **两种模式**：
  - `real`：实时，加载和布置场景时用。
  - `step`：时间冻结，`__vt.step(ms)` 一次推进 ms 毫秒，依次触发到期的定时器（每个之后清一次微任务）、跑一帧 rAF、对齐动画。
- **其他接口**：`__vt.busy(sel)`（选择器内还没播完的有限时长动画数，`settle()` 用它判断界面稳定）、`__vt.restartAnims()`（字卡渲染时让动画从 0 播）。
- **截图**：CDP `Page.captureScreenshot`，必须带 `clip.scale = dpr`，否则只有 CSS 尺寸（见 坑.md）。
  - 1080p JPEG 约 12–15 帧/秒，管道直接喂给 ffmpeg 编码（CRF 12 中间片）。
  - 慢动作 = 把 `R.dt` 调小。

## 浏览器与画面参数
- Playwright 自带的 Chromium：`%LOCALAPPDATA%/ms-playwright/chromium-1243/chrome-win64/chrome.exe`。
- 无头模式也能用 GPU（RTX 3070 / ANGLE D3D11）。启动参数：`--use-angle=d3d11 --enable-gpu --ignore-gpu-blocklist`。
- 用了虚拟时钟后，无头模式锁在约 31 ms 帧间隔的问题就不影响结果了；有头模式用 `HEADED=1`。
- 视口 1280×720（UI 基准尺寸）、`deviceScaleFactor` 1.5，得到原生 1920×1080。画质写死"高"：localStorage `moxian.settings.quality = "high"`。

## ffmpeg
- **来源**：`pip install --target work/video/bin/pydeps imageio-ffmpeg`，自带 gyan.dev 的 essentials 9.0.2，有 libx264、aac、libass、xfade、loudnorm。路径由 `lib.mjs` 的 `ffmpegPath()` 查找；`build.mjs` 发现缺失会自动安装。环境变量 `FFMPEG` 可以覆盖。
- Playwright 自带的 `ffmpeg-1011` 编码器不全，不要用。
- ffmpeg 9 已经去掉 `-filter_complex_script`，改成从文件读选项：`-/filter_complex <文件>`。
- 合成要点：
  - 每段 `-ss in -t dur -i clip` → `concat` → 缩放到 1728×972 → 叠到宣纸底 (96, 16) → 叠淡墨框。
  - 字幕 PNG 用 `-loop 1`，加 alpha 淡入淡出，再 `setpts=PTS-STARTPTS+T/TB` 移到时间点后 overlay（`eof_action=pass` + `enable=between`）。
  - 最后一段用 `tpad=stop_mode=clone` 做定格。
  - 音频经 `loudnorm=I=-16:TP=-1.5:LRA=11`。

## 字幕 / 字卡 / 画框渲染 overlay.html
- 由 Vite 提供 `tools/trailer/overlay.html`，引用游戏的 `src/ui/ink/strokes.css`、`ink-ui.css`、`fonts.css`（印章 mask、笔触、纸纹）和完整字库 `assets/fonts/MaShanZheng-Regular.ttf`、`ZhiMangXing-Regular.ttf`（SIL OFL）。
- 接口 `__show({kind})`：
  - `paper`：宣纸底，不透明。
  - `border`：淡墨框。
  - `sub`：字幕，"/" 换行。
  - `card`：大字卡，墨带 + 行书 + 朱印。
  - `end`：落版。
- 静态的用 `page.screenshot({omitBackground:true})`；动画的用虚拟时钟逐帧截 PNG，编成 png 编码的 mov（带 alpha）。
- **风格样片的另一种做法**（`work/video/sample/build_v2.py`）：ASS 字幕 + libass，样式是楷体 / Ma Shan Zheng，朱印用 ASS 绘图指令画，字卡用 `\t` 动画逐字盖印；转场用 xfade 自定义"墨晕"表达式（`INK_EXPR`）；每段先预渲染成 1280×720 中间文件，保证帧数精确。适合快速出样片；正式流水线用 HTML，和游戏 UI 同源。

## 配乐与混音
- `python tools/trailer/music.py <cues.json> <out.wav> [<sfx_dir>]`：约 25 秒算完 85 秒配乐，同时输出音效 `swish / slash / break / stamp / boom.wav`。
- `python tools/trailer/mix.py mix <spec.json> <out.wav>`：音乐 + 音效（+ 旁白）混音，可选按旁白包络压低音乐；母线做软削波，响度由 ffmpeg 统一。
- `python tools/trailer/mix.py trim <in.wav> <out.wav>`：裁掉首尾静音（原本给 TTS 用）。
- 依赖：Python 3.14 + numpy + scipy（系统已装）。
