# 宣传视频 · 本项目约定

| 规则 | 原因 | 决策 |
|---|---|---|
| 画面全部来自游戏实时运行，用自动化脚本驱动真实键鼠。调试接口只用来布置场景，画面里不能出现调试 UI（F8 面板、BuildPanel、调试文字）和假数字 | 实机演示的可信度 | 用户，2026-11-17 |
| 不配音，只有字幕 + 合成配乐（+ 少量合成音效），音乐不做 ducking | 用户觉得慧慧配音难听 | 用户，2026-11-17 |
| 字幕停留 ≥ max(2.5, 1.0 + 字数 × 0.25) 秒；间隔 0.3–0.5 秒；≤ 2 行，每行 ≤ 16 字；大字卡 ≥ 1.8 秒；字幕没读完不切关键镜头 | 观众要读得完 | 用户，2026-11-17 |
| 宣纸画框：实机 1728×972 放在 (96, 16)，底部 92 px 字幕带，字幕只出现在带内。墨色楷书单行 46 px，两行 40 px。字卡放在实机画面上半部的中央。标题和落版可以全屏 | 不挡任何 HUD | 主管，2026-11-17 |
| UI 段从进场动画结束、数据填好后开始取（≥ 1.5 秒 + 稳定检测） | 避免半展开的界面进片 | 用户，2026-11-17 |
| 收尾斩首领用满势右键蓄势斩；法宝用 V | 战斗组改了操作 | 主管，2026-11-17 |
| 不改 `src/` 下的游戏代码；录制需要的辅助代码放 `tools/trailer/`。需要游戏侧钩子（隐藏 HUD、镜头控制）时先报主管 | 文件归属 | 主管 |
| 不提交 git，视频不上传外部服务 | 安全 | 主管 |
| 交付：`work/video/墨途_宣传_v1.mp4`（1080p30，H.264 + AAC）、`墨途_宣传_15s.mp4`、`contact_sheet.png`；时长 60–90 秒，横版 | 需求 | 主管 |
| 画质设置"高"，成片 1920×1080 / 30 fps，响度约 −16 LUFS | 需求与网络发布 | 本岗位 |
| 下载的工具放进单独的新目录（`work/video/bin/`），只作为工具执行 | 安全规范 | 全局 |
| 字体放在 `assets/fonts/`（马善政楷书、志莽行书完整版，SIL OFL），游戏内只用子集 `src/ui/ink/*.woff2` | 清理组迁移 | 2026-11-17 |

## 文件归属
- 本岗位独占：`tools/trailer/*`、`work/video/*`（`sample/` 归风格样片的同事）、`docs/knowledge/宣传视频/*`。
- 只读：`src/**`，以及游戏数据和 UI。发现渲染问题时转给对应的组（刀光 → 特效 / 战斗组，UI → UI 组）。

## 镜头清单（shots.mjs）
`s01_title`、`s02_fight`、`s03_walk`、`s03b_bridge`、`s04_map`、`s05_loot`、`s06_chest`、`s07_bag`、`s08_night`、`s09_extract`、`s10_cave`、`s11_break`、`s12_mirror`、`s13_forge`、`s14_alchemy`、`s15_reforge`、`s16_imbue`、`s17_shield`、`s18_boss`。
- 每个镜头单独录约 15–45 秒，全部重录约 9 分钟。
