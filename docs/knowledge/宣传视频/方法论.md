# 宣传视频 · 方法论

## 1. 预告片结构：类型 → 钩子 → 锚点 → 内容 → 落版
- **前 5–10 秒交代"这是什么游戏"**，钩子最迟放在片长三分之一处（理想是前 10–15 秒）。开头不要堆慢速环境空镜，先放独特的东西。（Derek Lieu）
- **按游戏循环的时间顺序剪**，去掉无聊部分，保持核心循环完整，后面再递进加码。墨途的循环是：入画 → 搜 → 打 → 撤 → 洞府成长 → 再出行 → Boss。
- 字卡写"你通过这个玩法得到什么"，不写机制清单；避免整片像列表一样排比。
- **本项目结构**（完整版约 89 秒，15 秒版同骨架压缩）：
  | 段 | 时长 | 作用 |
  |---|---|---|
  | 开场 | 0–7 s | 标题 + 一剑（蓄势斩）= 类型 + 钩子 |
  | 搜打撤 | 7–39 s | 世界、地图、搜取（仙品出世）、开箱、储物袋、天时入夜、撤离、结算 |
  | 洞府成长 | 39–68 s | 今日可办、炼化突破、天机镜（穿越梗）、炼器 / 炼丹 / 重铸 / 附灵 |
  | 战斗高潮 | 68–84 s | 五行破盾 → Boss 多段护盾 → 满势蓄势斩慢动作「斩」 |
  | 落版 | 84–89 s | 定格 + 标题 + slogan +「实机演示」 |
- 15 秒版：每个卖点只留最高潮的 1.7–2.4 秒（开场一剑、仙品泛金、入夜、破盾、斩首领），落版 3 秒。

## 2. 字幕可读性
- **停留时长** = max(2.5 s, 1.0 s + 字数 × 0.25 s)（字数含标点，不含空格）；相邻两条间隔 0.3–0.5 s；大字卡 ≥ 1.8 s。
  - 业内参照：Netflix 简体中文字幕成人上限 9 字/秒、每行 16 字、最多两行。本项目取约 4 字/秒，远比 Netflix 宽松，因为观众同时要看实机画面，而且这条是用户定的规则。
- **版式**：每行 ≤ 16 字，最多两行，尽量单行。字幕没读完不要切到下一个关键镜头。关键镜头指字卡出现和落版。
- 字幕和大字卡不同屏，先卡后字，或者先字后卡，中间留空。
- 文案要短。用户认可过的写法："加个班，避个雨，人就进了画里""手机？成了天机镜""活着回洞府，才算赚""青牙？比周五的甲方好对付。" 正剧里带一点穿越式自嘲，一句一个意思。

## 3. 宣纸画框（字幕不挡 HUD 的通用解法）
- **问题**：游戏 HUD 四周都有信息（底部技能栏约占下方 15%、左上气血、右上天时与铜镜、左下拾取列表、右侧储物袋纸笺），所以字幕压在画面里一定会挡住 HUD。
- **做法**：把实机画面等比缩到约 90%，四周留出宣纸边（纸纹 + 一道淡墨框），底部留 90–100 px 的字幕带，字幕只出现在这条带里。
  - 本项目参数：成片 1920×1080，实机区域 1728×972，位置 (96, 16)，底部字幕带 92 px。
  - 字幕用墨色楷书，单行 46 px，两行时缩到 40 px，左右各一笔淡墨点缀。
- **例外**：开场标题、落版和大字卡可以压在画面上；大字卡放在实机画面上半部的中央，避开技能栏。

## 4. 镜头与节奏
- 动作镜头用 closeup 镜头（距离 14–21），走路和全景用 play 镜头（距离约 22）。洞府镜头距离 36 偏远，细节（例如附灵剑光颜色）放到战斗镜头里展示。
- **UI 段**从界面进场动画结束、数据填好之后才开始取（至少 1.5 秒，并检测进场动画都已结束）；动画本身就是内容的除外，例如突破的墨旋涡、搜取逐格揭示。
- 慢动作在游戏里做：每帧推进更短的游戏时间，例如 1/2，不在后期插帧。游戏自己的满势蓄势斩已经带慢动作和推镜，外加的慢放别叠太狠。
- 静帧（字卡底、结算定格）做极慢的推近，避免死帧。（风格样片做法）

## 5. 配乐与音效（程序化）
- **五声音阶**：本项目用 B 羽调式（B D E F# A）。
- **拨弦**（古琴 / 古筝）用加性合成：泛音按 1/k^b 衰减，高次泛音衰减更快，加一点非谐（1 + 0.0004k²）、12 ms 拨弦噪声，吟猱就是频率曲线上的滑音和揉弦。
  - 这样音高准确，而且 numpy 可以全向量化。Karplus-Strong 的整数延迟会跑音，补救又慢。
- **洞箫**：正弦加少量二、三次谐波，再叠带通气声噪声，慢起音，5 Hz 揉音。
- **磬**：非谐泛音（比例 1、2.76、5.40、8.93），衰减慢，适合当落版的最后一声。
- **太鼓**：正弦音高从 150 Hz 下滑到 50 Hz，叠低通噪声做鼓皮。板鼓：约 420 Hz 短促音，叠带通噪声。
- **段落**：开场（长音 + 泛音）→ 世界（古筝分解和弦 + 洞箫 + 轻鼓）→ 洞府（古琴慢句，无鼓）→ 战斗（太鼓节奏型 + 轮指）→ Boss（重鼓，最后一击前留白）→ 落版（磬）。
  - 段落起点由剪辑表算出来，重剪后自动对齐。
- **混音**：
  - 无旁白时不做 ducking。
  - 音效挂在录制标记上（挥剑、蓄势斩、破盾、盖印、重击），每张字卡盖印时加一声。
- **响度**：网络发布按约 −16 到 −14 LUFS 积分响度、真峰值 −1.5 dBTP。YouTube 只会压低超过 −14 的内容，不会提升偏小的。本片实测 −15.4 LUFS。广播用的 EBU R128 标准是 −23 LUFS，网络片不用这么低。
