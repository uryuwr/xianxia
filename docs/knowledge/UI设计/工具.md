# UI 设计 · 工具

> 写之前先读全文、在自己的分区追加，别覆盖别人的。§1 通用 · §2 采集 / 宝箱 / 搜取 / 神识 · §3 天机镜 / 洞府 · §4 图标 / 储物袋。

## 1. 通用

### 1.1 跑游戏、截图、可运行测试
- 命令：`node tools/run.mjs <场景> "<query>"`（Vite 开发服务器 + Playwright 自带 Chromium；随机端口，可并行；已屏蔽热更新）。
  - query 常用：`scene=run&region=r1&slot=3`（出行局）、`scene=title`（含序章）、`scene=cave`。
  - 场景脚本 `tools/scenarios/<名>.mjs` 导出 `default async (page, c)`；`c.shot(name)` → `work/shots/<场景>_<name>.png`；`c.ev(fn, arg)` 在页面里执行。
  - 打印以 `PASS ` / `FAIL ` 开头的行；出现 `FAIL ` 时退出码为 1。全量回归 `bash tools/regress.sh`。
- 页面里的入口：`window.__game`（`run`、`ctx`、`player`、`flow`、`scene`、`camera`）；`__game.ctx.gatherUI`（采集 / 搜取界面的状态与计数 `stats`）。
- 截图的镜头要和玩家实际视角一致：用出行视角（rig "play" 跟随主角），用 `player.spawn(x, z)` 把主角放到目标旁，不要自己挪相机。
- 鼠标先移到空地上（`page.mouse.move(980, 560)`），否则 HUD 的悬停说明会进截图。
- 稳定截图：每张前清掉敌人与通知（`run.clearEnemies()`、`run.nextWave = 1e9`、删 `.mk-toasts > *`）；夜里截图设 `run.t = R.phases[2] + 80`。

### 1.2 "改前"截图：用旧的打包版跑同一个脚本
- `release/墨途_v1_web/` 是改前打的包。`node work/run_release.mjs <场景> "<query>"` 用静态服务器打开它、跑同一个场景脚本，截图存 `work/shots/before_<name>.png`（脚本里用 `process.env.BEFORE === "1"` 跳过新功能的检查）。
- 没有旧包时：先把当前截图复制成 `v1_*.png` 再改（搜取窗口 v1 → v2 就是这么做的）。

### 1.3 对比拼图
- `node work/compare_sheet.mjs`：左改前 / 右改后、每行一个时刻、中文行标题，输出到 `docs/ui/v2/png/`。`node work/compare_sheet.mjs loot` 出搜取总览；`lootcmp` 出 v1 / v2 对比。
- 也可以用 `node tools/sheet.mjs name1 name2 …`（两列、文件名做标签，输出 `work/shots/_sheet.png`）。

### 1.4 HTML 草图（布局有明显变化时先出草图给用户选）
- 放在 `docs/ui/v2/<名>/index.html`。要用真实组件 / 图集时**经 Vite 打开**，页面里 `<script type="module">` 直接 `import "/src/ui/kit.js"`、`"/src/ui/icons.js"`、`"/src/data/items_db.js"`（JSON / webp 导入由 Vite 处理）；静态 file:// 打不开这些导入。
- 截图脚本同目录 `shoot.mjs`：`createServer({ root })` 起 Vite、`page.routeWebSocket(/./, () => {})` 屏蔽热更新、草图里暴露 `window.__xxx.step(dt)` 逐帧推进，按条件截"某一刻"，再拼成一张图。范例：`docs/ui/v2/loot_v2/shoot.mjs`。
- 不需要真实组件的草图可以纯静态（`docs/ui/v2/mock_bag_v2/shoot.mjs`，`--allow-file-access-from-files`）。

### 1.5 语法自检
- 改完 JS 先 `node_modules/.bin/esbuild <文件> --format=esm --log-level=error > /dev/null`：比跑完整场景快得多；页面 500 / `__ready` 超时多半是语法错。

用法：
```js
import { itemTag, setTagState, tagReveal, iconForMap, atlasImage } from "../ui/icons.js";
grid.appendChild(itemTag(inst, { size: 52, onClick }));             // 储物袋 / 搜取格
const t = itemTag(inst, { size: 52, sealed: true, sil: true });     // 搜取：墨封

setTagState(t, { sil: false }); tagReveal(t);                        // 显色
const ic = iconForMap("chest_glow", "empty");                        // 地图 canvas
g.drawImage(await atlasImage("map"), ic.x, ic.y, ic.w, ic.h, x, y, s, s); // ic.over 非空时右下角再叠一张
```
