# UI 设计 · 本项目约定

> 只对墨途成立的规则：规则 + 原因 + 决策日期 / 谁拍板。§1 通用 · §2 采集 / 宝箱 / 搜取 / 神识；其他分区由各自负责人追加。

## 1. 通用

| 规则 | 原因 | 决策 |
|---|---|---|
| 风格依据 `docs/UI风格指南_v1.md`："不画方框"，边界靠纸边、墨晕、一笔；形状全部来自程序化笔触（`src/ui/ink/strokes.css` 的 `--ink-enso-*`、`--ink-seal-*`、`--ink-deckle-*`、`--ink-wash-*`、`--ink-splash-*`） | 与 3D 水墨后期同一种笔性 | 风格指南 v1 |
| 品级只有一套：`src/core/items.js` 的 RARITY；颜色用 `src/fx/rarity_tint.js`（`rarityTint`、`inkReadable`），名称用 `RARITY[q].name`；不写死色值、不另起档位名 | 全局一致（用户要求） | 2026-11-17 主管 |
| 新特效 / 新 UI 遵守 `docs/性能优化_v1.md` §7：材质 / 几何池化、每帧不 new / 不 querySelector / 不读布局、DOM 只在变化时写、进度 ≥0.5% 才写、新着色器进 `src/render/prewarm.js` | 集显预算 | 2026-11-17 性能工程 |
| UI 布局有明显变化时，先出可交互 HTML 草图给用户选，确认后再落地；只是换图标 / 微调尺寸可以直接改，但要给改前改后对比 | 用户要求 | 2026-11-17 |
| 对别组文件（run.js、runhud.js、bagui.js、kit.js、pickups.js、prologue.js、enemy.js 等）只做最小接线：每次改前重新 Read，样式与组件放新文件 | 多组并行改同一批文件 | 2026-11-16 主管 |
| 不改玩法逻辑与数值（掉落、读条时长、按键判定），除非任务明确授权 | 表现与规则分离 | 2026-11-16 |
| 尺寸以 1280×720 为基准，界面按 `--mk-scale` 等比缩放；HUD 离屏幕边 ≥ 24px，画面中心 60% 只放空间型提示 | 风格指南 §7 / §13 | 风格指南 v1 |
| 物品图标统一走 `src/ui/icons.js`（`itemTag` / `iconEl` / `setTagState` / `tagReveal`，图集 `src/ui/icons/items*.webp`）；不要自己另做图标 | 储物袋 / 图标设计师维护 | 2026-11-17 |

### 4.1 突破史 `profile.stats.breakHistory`
洞府组写入（`F.recordBreak`，突破时）、旧存档补全（`F.ensureBreakHistory`，进洞府时）。按时间顺序 push，界面倒序显示（最新在上）。

| 字段 | 状态 | 含义 |
|---|---|---|
| `run` | 已有 | 当时的 `profile.stats.runs`；旧事为 null |
| `at` | 已有 | 真实时间戳 → 显示时辰；旧事为 null |
| `from` / `to` | 已有 | `{ stage, layer }`（界面转成 "1:6" 这种 key） |
| `stats` | 已有 | `heroStats(to) − heroStats(from)` 差值（全部数值键，0 也在） |
| `unlocks` | 已有 | `[{ key, value }]`，键：spellSlots / pillSlots / xinfaSlots / robeSlot / jadeSlot / artifactSlot / formationSlot / doubleJump / swordFly / region2 / bagMax / pouchMax |
| `grants` | 已有 | `[{ kind: "spells" \| "xinfa" \| "formations", id, name? }]`（旧事没有 name，界面查 SPELLS / XINFA） |
| `memory` | 已有 | 那次亮起的 MEMORIES key 或 null |
| `legacy` / `note: "旧事"` | 已有 | 旧存档补出来的条目 |
| `day` | **待写** | 入画第几日；没有日历前可先写 `runs + 1` |
| `playTime` | **待写** | 突破时的 `profile.playTime`（秒） |
| `xp` | 待写（可回退） | 这一层耗的修为；不写时界面用 `PROGRESSION.xp[from]` |
| `trial: { id, tries }` | **待写** | 心魔劫第几次才过（失败时计数） |
| `base` | 建议 | 到达境界时的属性快照；现在"前 → 后"按**当前**成长表倒推，调平衡后会和当时不一致 |

- 总览不读历史，现算：`PROGRESSION.growth[当前] − growth["1:1"]`，只算境界本身（不含装备、心法）；栏位读 `profile.unlocks`。

## 图标与储物袋（2026-11，用户拍板）
- 图标为主、单字为辅（风格指南 §11 已改）：物品、技能、地图全部用水墨图标；单字只留在名称、无障碍、设施大字、图集加载前兜底。
- 物品图标路线：程序化水墨模板 + 纸性位图（a2）；未鉴定 = 墨拓剪影。3D 离屏渲染不作主路线。
- 品级只用 RARITY（圆相色、同色晕、名称字色、仙 / 极角印）；图标本色不随品级变；名称字色用 RARITY 同色系压深：一律调用 `src/fx/rarity_tint.js` 的 `inkReadable(q)`（bagui.js 的 `QN` 也是由它推导，不再写死色值，2026-11-17 起）。
- 局内储物袋 = 方向四"侧挂纸笺"；结算 = 手卷；洞府仓库 = 博古架（落地说明 `docs/ui/v2/储物袋_v2_落地说明_局外.md`）。
- 满袋纯手动取舍：不做"可弃"建议、不做一键腾格；只提示"脚下 · ××× 放不下（需 N 格）"。
- 袋内操作：点选、双击（装备 / 拾取 / 取出）、右键丢弃、拖拽（整理 / 换装 / 入锦囊 / 拖出丢弃）；不占用 E（法术）、G（遁地符）。
- 技能图标 = 意象写意；地图图标 = 剪影意象；精英护盾环用技能栏五行色（metal #9a7d34、wood #3f9a6e、water #2f7fa8、fire #b8291a、earth #9a6a32）。
- 文件归属：`src/ui/icons.js`、`src/ui/icons/*`、`src/ui/bagui.js`、`src/fx/loot_icon_tex.js`、`tools/icons/*`、`tools/icons_gen.mjs`、`tools/scenarios/loop_bag_v2.mjs` 归 UI 设计（图标管线）；`skillbar.js`、`mirror_map.js` 的图标接入由 UI 设计改过，其余逻辑归原作者。
- 新增物品 / 技能 / 地图标记后要重跑 `node tools/icons_gen.mjs`；不重跑也不会报错（类别兜底 / 文字兜底）。
