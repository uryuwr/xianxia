# UI 设计 · 参考资料

> 标题 + 链接 + 一句话结论。按主题分组，各负责人在对应分组追加。

## 1. 水墨 / 东方风格 UI
- Ōkami 角色与笔触分析 — https://champicky.com/2019/08/30/okami-amaterasu-design-analysis/ — 水墨感来自墨色浓淡（轮廓比内部浓）与笔画粗细变化，不是贴一层宣纸。
- Real Time Sumi-E Style Rendering Techniques（TCD 2020）— https://publications.scss.tcd.ie/theses/diss/2020/TCD-SCSS-DISSERTATION-2020-056.pdf — 实时水墨渲染的轮廓、晕染做法。
- Ink & Brush Dojo（水墨格斗 UI 套件）— https://theallblu.itch.io/ink-brush-dojo-fighting-game-ui-kit/devlog/1740045/ink-brush-dojo-is-out-a-sumi-e-fighting-game-ui-kit — 品类共识：笔触血条、圆相框、朱印、手写大字。
- 网易游戏学堂《视觉设计方法》 — https://api.academy.163.com/course/careerArticle?course=303 — 从原画取色；"残缺"与留白表达限时与意境。
- 国产游戏如何洗脱"页游感" — https://www.gameres.com/689352.html — 水墨风混入拟物渐变会变脏。

## 2. HUD 与信息层级
- Fagerholt & Lorentzon, *Beyond the HUD*（2009）— https://www.researchgate.net/publication/277202228_Beyond_the_HUD_-_User_Interfaces_for_Increased_Player_Immersion_in_FPS_Games — 叙事内 / 外 × 空间 / 非空间四象限，尽量叙事内。
- 对马岛无 HUD 引导分析 — https://ludonodestudios.medium.com/%EF%B8%8F-the-invisible-hand-how-ghost-of-tsushima-guides-players-without-a-traditional-hud-70f6772fcacc — 用风等叙事内元素引导；但生死信息仍要清楚（玩家抱怨血条太小）。
- Xbox Accessibility Guidelines 101 文字显示 — https://devdocs.xbox.com/build/game-principles/accessibility/xag-deep-dives/xag-101-text-display — 关键文字对比度 ≥ 4.5:1，按最差背景量。
- Game Accessibility Guidelines：高对比 — https://gameaccessibilityguidelines.com/provide-high-contrast-between-text-ui-and-background/ — 做不到纯色底就加明显描边或阴影。

## 3. 搜打撤 / 战利品交互
- 塔科夫菜单 UX 重设计 — https://www.heiolenmarkus.com/blog/escape-from-tarkov-menu-ux-redesign — 格子背包与搜刮的信息组织；逐格搜索制造期待。
- Dark and Darker 价值 / 占格 — https://darkanddarker.wiki.spellsandguns.com/Hunting_Loot — 玩家需要"每格值多少"，官方不给就靠第三方。
- 三角洲行动、暗区突围（用户点名参考）— 击杀留尸、搜取弹格子、每格依次转圈、颜色判断稀有度；本项目改写为"神识一笔 + 墨封"。

## 4. 装裱与印章（大面板结构）
- 立轴 / 手卷 / 装裱 — https://en.wikipedia.org/wiki/Hanging_scroll ，https://en.wikipedia.org/wiki/Handscroll ，https://en.wikipedia.org/wiki/Zhuangbiao — 天头、画心、引首、拖尾等结构可借给大面板。
- 朱文 / 白文印 — https://www.comuseum.com/culture/seals/ — 白文印作状态，朱文边框作警示，印边要残缺。

## 5. 图标 / 储物袋
- Ōkami 笔触分析（见 §1）— 用于图标：笔路模型的提按、出锋、浓淡比"贴宣纸纹理"重要，图标的墨性来自笔，不来自底纹。
- Xbox Accessibility Guidelines 101（见 §2）— 用于图标：品级不能只靠色相，用"圆相色 + 角标印 + 名称字色"三重区分。
- 塔科夫菜单 UX 重设计（见 §3）— 用于储物袋：价值、占格、风险放在同一视线里（纸笺里"估价 / 占格 / 若身陨此地"一条线）。
- Dark and Darker 价值 / 占格（见 §3）— 用于储物袋：占格 + 估价是满袋取舍的两轴；本项目定稿为纯手动取舍，不替玩家选。
- 本项目方案与落地记录 — `docs/ui/v2/储物袋_v2_方案.md`（四个布局方向、三条图标路线评估、§8 落地记录）、`docs/ui/v2/储物袋_v2_落地说明_局外.md`（结算手卷、仓库博古架、技能图标待分派清单）。
- 本项目图标草图 — `docs/ui/v2/png/bag_v2_icons_compare.png`（物品图标路线对比）、`skill_icons_compare.png`（技能）、`map_icons_compare.png`（地图）。

## 炼器 / 炼丹（丹器房 v2）
- Nielsen Norman Group，10 Usability Heuristics — https://www.nngroup.com/articles/ten-usability-heuristics/ — 第 9 条"帮助用户识别、诊断并从错误中恢复"：材料不足要写缺多少、去哪得（"何处可得"）。
- Mitchell, Francke, Eng，Illustrative Rendering in Team Fortress 2（NPAR 2007）— https://www.valvesoftware.com/publications/2007/NPAR07_IllustrativeRenderingInTeamFortress2.pdf — 辨识首先靠剪影：鼎与炉先做出不同轮廓，再谈纹饰。

## UI 体检 v1（2026-11-18）
- WCAG 2.1 SC 1.4.11 Non-text Contrast — https://www.w3.org/WAI/WCAG21/Understanding/non-text-contrast.html — 血条、预警外缘这类"理解所需的图形"对相邻颜色 ≥ 3:1；HUD 体检对条形用这个门槛，对字用 XAG 101 的 4.5:1。
