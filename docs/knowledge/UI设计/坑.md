# UI 设计 · 坑

> 现象 → 原因 → 规避办法 → 日期。动手前逐条对照。§1 通用 · §2 采集 / 宝箱 / 搜取 / 神识；其他分区由各自负责人追加。

## 1. 通用

- **品级另起了一套档位名 / 色值**（2026-11-17）
  现象：采集点用了"珍 / 稀"档位名和写死的石绿、石青、泥金；设计图里出现"赤炎果（珍）"。
  原因：把"点的种类"和"品质"混成一个维度。
  规避：品级只有一套——`src/core/items.js` 的 RARITY（凡 / 灵 / 宝 / 仙 / 极 + 颜色）。颜色一律用 `src/fx/rarity_tint.js` 推导（`rarityTint` 降饱和 / 压暗 / 提亮，字色用 `inkReadable`）；种类用形制（大小、光柱、双圈）表达，不起名字。宝箱 / 灵光点的颜色按"产出物品质"。

- **高饱和点色被水墨后期原样保留，显得像塑料 / 霓虹**（2026-11-16）
  现象：自发光的荧光绿灵草、加色光柱在纸面上刺眼，夜里成了全场最亮的东西。
  原因：`src/render/ink.js` 对饱和度 > 0.32 的颜色完整保留色相。
  规避：物件本身不自发光、用低饱和本色 + 后期墨线；灵气用小而亮的低饱和点或微粒；需要信标时光柱只给高价值点。

- **字符串里写进了真换行，整个模块 500**（2026-11-17）
  现象：页面加载超时、Vite 返回 500。
  原因：用 Python 生成 JS 时 `"\n"` 被写成了字面换行，字符串没闭合；另一次是同一作用域里重名 `const q`。
  规避：改完先用 esbuild 自检（见 工具.md §1.5）。

- **新窗口没定位，贴在屏幕左上角**（2026-11-17）
  原因：位置缓存（`tx/ty`）沿用了上一个窗口的值，"值没变就不写 transform"的优化把新窗口的首次定位也跳过了。
  规避：每次新建 / 重建窗口时清掉位置与尺寸缓存。

- **测试里拿到了别的容器 / 别的物件的事件**（2026-11-17）
  原因：事件日志跨容器累计；随机种子使前一个尸体刚好也有第 2 格。
  规避：每个检查段开始前清空日志、用唯一的容器 id 过滤；挑测试对象时排除同 kind 的变体（如 `!m.altar`）。

- **书法字体缺字，悄悄回退成系统楷体**（2026-11-17，天机镜）
  现象：新界面里"亥时""舆"等字比旁边细，是系统楷体。
  原因：`src/ui/ink/MaShanZheng.woff2 / ZhiMangXing.woff2` 是按界面文案裁的子集（`tools/ui_fonts_game.mjs` 只扫 `src/**/*.js` 和 `docs/ui/v2/**/*.html`，不扫 docs 下的 .js）；草图用 `work/fonts/*.ttf` 全字库，所以草图里看不出来。
  规避：新界面写完用 fontTools 查缺字（工具.md §3），有缺就 `node tools/ui_fonts_game.mjs` 重新生成；字体是模块 A 的公共资源，重生成后体积会涨（这次 +85 KB），报告里说明。

- **`mask` 会把元素自己的文字也遮掉**（2026-11-17）
  现象：墨笔底 + 纸色字的名签只剩一团墨。原因：`-webkit-mask` 作用于整个元素（含文字）。
  规避：笔触底放 `::before` 做 mask，文字留在元素本身。另：`--ink-wash-*` 做气泡底太淡几乎看不见，气泡改用 `--ink-deckle-slip`。

- **通用类名撞车，点击被"拦截"**（2026-11-17）
  现象：Playwright 报 `<div class="body mj-scroll"> intercepts pointer events`。
  原因：装饰层 `.mv2-mirror .lit { 400×640 绝对定位 }` 套到了带 `lit` 类的相册按钮上。
  规避：装饰层用子选择器 + 专用名（`> .scrglow`），内容块类名加前缀；排查用 `elementFromPoint` + `getBoundingClientRect`。

- **径向渐变做"抹掉"色块，边缘抹不干净**：`radial-gradient(色, transparent)` 是线性衰减，写成 `色 62%, transparent`。
- **大面积元素不做 box-shadow / filter 动画**（性能规范 §7）：呼吸光单独一层径向渐变，只改 opacity。
- **`pathToFileURL` 会丢 hash**：草图截图要自己拼 `#...`（`docs/ui/v2/mirror_v2/shoot.mjs`）；file:// 下模块不能互相 import，数据用普通 `<script>` 挂 window；`history.replaceState` 包 try。
- **界面记住上次的页签，测试要显式点页签**（境界录记得上次停在"总览"）。

## 2. 采集 / 宝箱 / 搜取 / 神识

- **开完宝箱后 F 提示一直留着**（用户报，2026-11-16）
  现象：读条或打断时提示收起，同一目标再出现后，开箱 / 采完提示收不掉。
  原因：提示组件只在"目标变了"时记录当前目标；目标没变就没更新，之后"没有目标"的分支以为本来就是关着的。
  规避：每帧都记下当前目标；没有目标时只要有过 key 就收起并清 key。测试里加"开完站回原处，提示不残留"的检查（`loop_gather_ui`）。

- **宝箱改成容器后，流程测试的"开箱后屏幕上不再有'宝箱'文字"断言失败**（2026-11-17）
  原因：开箱即弹格子窗，窗口标题就是"灵光宝箱"——不是提示残留。
  规避：这类"屏幕上不应有某文字"的断言要排除 `.mk-layer-loot`（已由流程组改）。改交互流程时，先搜一遍其他组测试里依赖旧流程的断言，交付时点名告诉主管。

- **贴地圆相被坡地 / 河岸吃掉一半**（2026-11-16）
  原因：贴地平面做了深度测试，地形起伏处被遮。
  规避：圆相 `depthTest: false`、`depthWrite: false`、renderOrder 低；淡而先画，压在脚上也不碍事。

- **柳叶几何出现 NaN 包围球**（2026-11-16）
  原因：`Math.pow(sin(...), 0.75)` 遇到 -1e-17 这类浮点负零。
  规避：开幂前 `Math.max(0, …)`。

- **留尸被停止动画后姿势回到 T-pose**（2026-11-17）
  原因：`mixer.stopAllAction()` 会让绑定恢复原始状态（骨骼回绑定姿势）。
  规避：留尸时不 stop；尸身交给容器后不再更新 mixer，`skeleton.update` 只算最后一次再换空函数，节点矩阵冻结。

- **同一位置两个交互物抢 F**（2026-11-17）
  原因：`nearestMark` 只取最近一个。奇遇 NPC 给的东西如果做成容器，会和奇遇标记站在同一位置。
  规避：奇遇 / 委托给的东西仍落地自动拾取；需要并存时把容器偏移 1 米以上。

- **makeItem 把宝品以上的装备默认设为未鉴定**（2026-11-17）
  现象：草图里的"仙品剑"显示成剪影 + "？"。
  规避：演示 / 测试要已鉴定的装备时显式传 `identified: true`。

- **亭中供案和宝箱共用 kind "chest"**（2026-11-17）
  影响：按宝箱数量或"第一个宝箱"写的断言会把供案算进去；供案开箱不能换成开盖的箱子模型。
  规避：用 `m.altar` 区分；测试挑宝箱时排除 `altar`。

- **关卡与容器两边各抽一次"启用几个亭子"**（2026-11-17）
  原因：关卡已经按种子挑好 2–4 个，容器又随机挑一次，数量变少。
  规避：关卡给了 `points.pavilions` 就全部用；只在兜底（从道具找亭子）时自己挑。

- **Esc 关窗时弹出了暂停菜单**
  规避：窗口在 `keydown` **捕获阶段**处理 Esc 并 `stopImmediatePropagation`，先于暂停菜单。

## 3. 天机镜 / 洞府界面

- **加 PointLight 会让所有受光材质重新编译**（2026-11-17）
  规避：3D 物件发光用透明面片改 opacity + 已有的加法微光精灵（`cave_scene.js` 的 `glowSprite`），不加灯。透明面片用 `MeshBasicMaterial({ transparent, depthWrite: false })`，已在 `src/render/prewarm.js` 预热过。
- **`cave_scene.js` 的 `shade()` 会给所有网格开投影**：透明面片、贴花设 `userData.noShadow = true`（已支持）。
- **洞府加站点会改挂签数量**：`loop_cave` 断言挂签个数（现在 5 = 4 个设施 + 天机镜台）。加站点要同步测试，并在 `refreshHud` 的 `tag` 表、`STATIONS`（`src/game/cave/data.js`）、`_boxes()` 的 parts 里各补一项。
- **草图底图是带 HUD 的游戏截图**：会露出"今日可办"等旧界面；用纸色团块抹掉，或在说明里注明"打开时洞府 HUD 收起"。
- **旧存档数据不完整**：补出来的"旧事"条目没有亮记忆标记，序章"锁屏"记忆也不在突破史里。判定"亮过" = `flags.memories` ∪ 突破史的 `memory` ∪ 不高于当前境界的；"所学" = `flags.learned` ∪ 突破史的 `grants`。

## 图标 / 储物袋（2026-11）

- **单字图标像"文字游戏"**：现象——储物袋格子里"青 / 苗 / 牙 / 玉"，用户说像文字游戏。原因——风格指南 v1 §11 "图标首选单字"。规避——物品、技能、地图一律用水墨图标，单字只留在名称、无障碍、设施大字里（§11 已改）。
- **同字物品无法区分**：5 种妖丹都是"丹"、5 种苗都是"苗"、2 种玉都是"玉"。规避——模板按五行 / 效果 / id 散列换色或换变体（`specOf`），图标总览截图逐一核对（`loop_bag_v2_icons_overview.png`）。
- **品级色混进图标本色**：绿色灵草被误读成灵品。规避——图标只用低饱和本色，品级只由圆相色、同色晕、名称字色、仙 / 极角印表达（RARITY）。
- **小尺寸可辨识度**：细线（法剑 1–2px）、纸纹颗粒在 15–24px 下消失或糊成噪点。规避——技能图标笔画 ×1.7；地图图标用实块剪影 + 纸色反白一两笔、关掉颗粒（`renderCanvas(..., { grain: false })`），外加纸色 shadow；在 15px 实测截图确认。
- **3D 离屏渲染做图标不合笔性**：后期墨线没有起收笔，48px 以下像"描边贴纸"，软物（法衣、草叶）难建模。只适合少数硬质法宝。（样例 `docs/ui/v2/mock_bag_v2/icons_b/`）
- **`.ink-slot.q-xian > i` 选择器吃掉图标**：ink-ui.css 用 `> i` 画仙 / 极角印，图标元素若用 `<i>` 会被改成 18px 小印。规避——图标用 `<span class="mk-ico">`。
- **内联 style 里的双引号**：`style="${iconStyle()}"` 里 `url("…")` 会截断属性（图例图标不显示）。规避——外层用单引号 `style='…'`。
- **canvas 闭合笔路重复点**：笔路首尾或中间出现重复点时法线为 NaN，整笔不画（SVG 却能画，难发现）。规避——闭环笔路不要重复起点。
- **图集体积**：纸纹颗粒是噪声，webp 压不动（加 34 个地图图标让主图集 755 → 940 KB）。规避——地图图标单独 64px 小图集、无颗粒（49 KB）；降 webp 质量收益很小（0.82 → 0.74 只省 8%）。
- **世界不暂停时的全屏界面**：旧储物袋全屏薄纸，战场看不见、无敌近提示；打开时 E / G 是局内法术 / 遁地符键，不能拿来做袋内快捷键。规避——侧挂纸笺 + 敌近朱印 + 受击收浮签；袋内操作用双击 / 右键 / 拖拽。
- **满袋横幅压在袋子上**：袋子开着时 bagfull 横幅无意义。规避——袋内状态行显示"脚下 · ××× 放不下（需 N 格）"，开袋时移除该横幅；其他通知移到画面左中。
- **heredoc 里写大段 Python 偶发 "unexpected EOF"**：长 `python - <<'EOF'` 在本环境的 Bash 工具里会解析失败。规避——把脚本 Write 成文件再 `python file.py`。

## 炼器 / 炼丹（丹器房 v2）

- **鼎像锅、鼎和炉同一轮廓**（用户反馈，2026-11-17）
  现象：旧炼器鼎与丹炉都是"三足圆腹"，看不出哪个炼器哪个炼丹。原因：两张图从同一个生成器、同一套比例出来。
  规避：不同功能的器物先定**不同剪影**再谈纹饰——炼器 = 方腹 + 立耳 + 扉棱 + 铭文带（金石）；炼丹 = 圆腹带盖 + 钮上丹烟 + 炉门透火（烟火）。对比时把"现状"放第一列。
- **程序化纹饰读成字母 / 人脸**（2026-11-17）
  现象：圆勾雷纹排成一行像"bb"；炉盖上一道弧线 + 两个气孔像笑脸。
  规避：雷纹用方折回旋、左右交替镜像；盖上不要"一道横弧 + 对称两点"，气孔用一排小云形。每次出图都在纸色底上肉眼看一遍。
- **整圆轮廓穿过盖子 / 上节**：炉腹、葫芦两节用整圆笔路时轮廓线会穿过炉盖、朱绳。规避——只画可见段的椭圆弧（`arc(cx, cy, rx, ry, a0, a1)`，起止角跨过底部），左浓右淡分两笔。
- **材料位写死 4 个，配方一多就溢出**：旧版鼎周只有 4 个位，数值组随后就加了第 3 味（骨粉、妖丹碎片）。规避——`ringPos` 支持到 6 味 + 灵石，测试用一个 6 味示意配方断言不重叠。
- **测试写死配方材料，被数值组改配方打断**（2026-11-17）
  现象：重铸印一直灰（`REFORGE.items` 加了妖丹碎片）、开炉印灰（回春丹加了骨粉），`page.click` 超时，看不出原因。
  规避：测试按规则现查再补料（`F.reforgeCost(...).items`、`F.inputsOf(p, r, n)`）；朱印灰时先把 `canReforge / alchemyCanStart` 的 why 打出来再点。
- **截图被洞府"进场遮罩"挡住**（2026-11-17）：洞府组加了 `.cv-loading`（"洞府 · 墨迹未干……"），首张截图是一张纸。规避——进页后 `waitForFunction(() => !document.querySelector(".cv-loading"))` 再截。
- **自定义弹层里按 Esc 关掉了整页**：`ui/cave/index.js` 的 Esc 只认 `.cv-modal`。规避——弹层在 window **捕获阶段**监听 Esc 并 `stopPropagation`（`facModal`）。
- **Space 落印的三个坑**：①按钮被鼠标点过后有焦点，Space 原生再触发一次 click——keydown 里 `preventDefault` 并 `blur`；②洞府预热用替身 ui 渲染页面，别给替身绑键；③每次渲染都 `addEventListener` 会叠监听——模块级只装一次，改指向的 ui。火候进行中 Space 归火候（添火），落印监听要让开。
- **在 body 上盖印把整页顶上去 ~30px**：盖印层 / 带 transform 的元素超出视口，Playwright 点击或聚焦时会滚动。规避——`html, body { overflow: clip }`（hidden 仍可被程序滚动），盖印 host 用面板容器而不是 body。
- **新旧样式撞类名**：旧丹器房 CSS 有 `.rf-reveal .old/.neo`、`.mat`、`.fire`、`.detail`、`.hd` 等全局规则。规避——新模块类名一律 `ws2-` 前缀；为了测试保留的旧类名（`.rf-reveal`、`.rf-list .ink-row[data-aff]`）里，子元素别再用旧类名（揭示里改成 `.so / .sn`）。
- **规则与界面不一致**：`forgeCraft` 永远先用最好的主材（"取用中最好的一份定上限"），界面却要让玩家选主材品级。过渡做法 `craftAt()` 把更好的主材暂时挪出仓库数组再调规则函数；正式做法已请洞府组加 `forgeCraft(p, r, { mainQ })` 与 `forgePreview`。凡是界面要"预览规则结果"，先确认规则函数有没有对应参数。
- **字色写死**：新界面一开始照抄 `#2c7d57 / #245f7f …`，违反全局约定。规避——品级可读深色一律 `src/fx/rarity_tint.js` 的 `inkReadable(q)`（"足"的石绿不是品级，可以写死）。

## 首领界面（青牙 v2）

- **草图里用户选的方案，落地后还是被否掉了一块**（2026-11-17）：方向 A 草图里有"二 · 啸月"竖幅横幅和阶段字，用户选了 A，但看到落地后说"转阶段的 UI 太生硬，不需要"。原因：草图评审时用户关注的是整体布局（顶部长卷 vs 底部落款 vs 空间型），没对每个元素单独表态。规避——草图选择题里把"叙事外文字提示"（横幅、阶段字、教学字）单列一道题；默认优先叙事内表达（外观 / 护盾 / 环境），文字只做事后记录。
- **CSS 动画 fill-mode 写成 `both`，元素在延迟前就显示了**（2026-11-17）：`bxOn`（from/to opacity 1）用 `both` 时，延迟期间就套用 from 帧。规避——"到点才出现 / 到点才消失"的关键帧用 `forwards`；同一属性多个动画时列表后面的覆盖前面的。
- **`.bx-exec > * { opacity: 0 }` 把舞台容器也藏了**：处决的斩字、墨笔、朱印测出 opacity 1 却看不见——父容器 `.bx-stage` 被 `> *` 选中。规避——初始隐藏只写到具体元素；断言可见性要连父链一起查，或者直接看截图。
- **变化检测的缓存键撞名，每帧"写"两次**：`_cls(bar, "sh", …)` 和 `_var(el.sh, "sh", …)` 共用键 `sh`，互相覆盖，静止时每帧 2 次 setProperty / toggle（值没变所以 MutationObserver 是 0，只有自己的计数器看得出来）。规避——每个写入点一个唯一键；测试里同时数"自己的写入计数"和 MutationObserver，静止 2 秒应都为 0。
- **`page.evaluate` 里 return 了一个"合上才 resolve"的 Promise，测试卡死**：`__cave.openMirror()` 是 async、等界面合上。规避——`c.ev(() => void openMirror(...))`。

- **3D 预警量对比度，品红到不了满值**：水墨后期（纸纹、描线）把品红压暗，旧版外缘没有一个像素 w ≥ 0.9，固定阈值 0.7 只剩半覆盖的边缘像素，P10 ≈ 1.0 没有意义。规避：3D 元素用相对核心 w ≥ 0.85 × P98(w)（`measure_impl.py`）；要量的那层颜色单独放一个 uniform（`uRim`），A / B 只改它。
- **测试里 `spawn("wolf_elite")` 拿到的是普通狼**：精英有上限 / 间距 / 首领场地规则，被拦下会换成同族普通怪。规避：测试传 `{ forceElite: !0 }`。新存档主角是"凡人"（stage 0），境界标签只会出"凡人?"——测试先设 `profile.realm = { stage: 1, layer: 3 }`。
