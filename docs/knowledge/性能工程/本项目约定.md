# 性能工程 · 本项目约定

## 规范与报告
- **新特效 / 新 UI 的性能规范 = `docs/性能优化_v1.md` 第 7 节**（预算、材质与着色器、几何体、对象池、每帧禁止、DOM、离屏渲染、3D 对象、透明面片、寻路、自测）。全岗位遵守。2026-11-17 主管下发
- 性能报告写在 `docs/性能优化_v<n>.md`：测量方法 → 瓶颈排行 → 每项前后数据 → 画质档位 → 剩余瓶颈 → 改动清单 → 回归。

## 目标与测量口径
- 目标：普通集显 / 中端独显笔记本，出行局（r1、r2，白天 / 入夜 / 战斗）稳定 60 帧或无可感知尖峰；界面切换不卡。
- 集显基准机：本机 Intel UHD 630（`IGPU=1`），口径 `W=1536 H=864 DPR=1.25`（1080p@125%）。Iris Xe 按快 2–2.5 倍估算。
- 尖峰判定：主循环单帧 > 50ms 或 longtask；新编译着色器列表必须为空。

## 首领演出后期参数（青牙 v2，2026-11-17，boss_青牙_v2 §10.2 第 6 项）
| 接口 | 说明 |
|---|---|
| `ctx.ink.setPaperFade(v)` | 0..1 留白（焦点外淡成宣纸色、墨线减淡 60%）；调用方 `src/ui/boss/exec_fx.js`（终结处决曲线 0.3–1.2 升到 0.85，2.4–3.6 退回）|
| `ctx.ink.setPaperFocus(...objs)` | ≤ 2 个有 `pos` + `entity { radius, height }` 的对象（首领 Enemy、主角）；世界空间竖直圆柱，半径 = 碰撞半径 × 2.9（≥1 米），高 = height × 1.25，脚底 0.06–0.3 米以下不保留（地面、影子照样淡）；只在 fade > 0 时每帧按位置更新；不传 = 清空 |
| `ctx.ink.setDesat(v)` | 0..1 去饱和（按亮度褪成纸色调墨色）；调用方 `src/game/execution.js`：`spec.desat`，缺省 `kind: "break"` = 0.45，0.15 秒褪、最后 0.5 秒回，`finish()` 必归零 |
- 都在水墨后期同一个 pass 里，uniform 分支：参数为 0 时与改动前逐像素一致、GPU 无差别（perf_boss_ink）。**不要为演出效果加全屏 pass**，往这里加 uniform。
- 预热：关卡有 `points.boss` 时 prewarm 建纯外观首领 + 显示狼谷环境件 + 在狼谷按跟随 / 处决镜头真画；新首领（碧鳞等）的外观件、环境件按同样方式加进 prewarm 首领段。
- 首领战常驻 draw call 实测（二阶段，主 pass，`perf_probe STAGES=boss` 的 BOSSDRAW）：首领外观附件 5（描边壳 + 阵纹 + 眼焰 ×2）+ 狼谷环境 8（月光斑 2 × 3 层〔地面 / 光柱 / 光尘〕+ 墨雾门 + 谷沿雾带〔进谷就有〕）≈ 战斗新增 12，略超 §11.1 第 15 条的 ≤ 10；超出来自月光斑每片 3 个网格（关卡设计 lair.js `moonSpot`），可合并光柱与光尘或只在近处画光尘。后期参数 0 个。2026-11-17
