2. **翼膜从某个角度看不见** → 单层面片 + 卡通材质默认单面 → 用 `MB.sheet` 生成双层薄片（两面各一层，法线相反，厚 0.016）。2026-11-16

5. **斜坡、岸边的预警只剩一半** → 预警是一块平板，放在敌人脚下的高度，坡上的部分被地形埋住 → 网格细分、每帧把顶点贴地（只在可见时改）。2026-11-17
6. **"隙"字、喘息墨气不在头上** → 用身高或半径估算头的位置，大体型（青牙 ×2.3）偏差很大 → 直接取骨骼 `head` 的世界坐标（所有模型都有 head 骨）。2026-11-17
7. **截图里新怪"不存在"** → 测试把怪刷在主角 +x / +z 方向，刚好是崖外深渊或河里（高度 −35），飞行怪悬在深渊上看不见 → 测试刷怪位置先用 height(x, z) 检查，或刷在已知平地方向；`render_creature.py` 的预览不受影响。2026-11-17

## 青牙 v2 首领与狼谷场景件（美术管线，2026-11-17）

9. **首领第一版被主管打回："像高跷、比普通狼还瘦"** → 拿竹林狼的比例加厚一点再靠 scale 放大，长腿细腿被一起放大，体量感反而没了 → 首领要改比例而不是只改缩放：腿缩短加粗（前肢最粗）、胸厚肩宽（胸截面半高 ≥ 腿长的 0.4）、颈粗、头大前探、躯干中心降到腿长附近；待机姿势低伏（crouch 0.2+、头平视前方）。改完 scale 反而从 2.6 降到 2.2 仍然有压迫感。2026-11-17
10. **"骨甲"做成一排插在背上的尖刺，看不出是甲** → 每块只是一圈薄弧 + 大刺 → 骨板要有厚度（外层 + 内层 + 边沿一圈）、贴着躯干包到两肋（±70°）、边沿顶点随机参差、中脊隆起；刺只做点缀（每块 1 根）。做法见 方法论"有厚度的贴体骨板"。2026-11-17
11. **深色怪在游戏里压成一块黑团（主管意见，同性能工程"迎客松纯黑"）** → toon 渐变是 70/165/255，背光面只有 27% 亮度；墨色底色 × 0.27 ≈ 纯黑，水墨后期再压一档 → 首领主毛用专用材质（fur_qing）：底色提到 0x4f5f59，再加一点自发光托底（emissive 0x1a2622）；腹部、长鬃、两肋飞毛用浅一档的颜色打破大色块。数据表 tint 只改 color、不会加 emissive，所以"提亮暗面"只能在 PALETTE 里做。2026-11-17
12. **加法混合的眼焰在宣纸色地面上看不见** → 背景本来就亮，加法只会往白里洗 → 纸面上的发光特效用普通混合 + 饱和的青色（0x3fe6aa），靠颜色而不是亮度读出来；加法只在暗背景（夜、墨云遮月）才有效。2026-11-17
13. **切换子网格时墨线描边还留在原地** → enemy.js 给每个网格建的描边壳是 `m.parent.add(ol)`：多图元网格时在同一个 Group 里，单图元时是整个模型下的兄弟节点，按节点 `visible` 切不掉 → 按几何体集合切显隐（描边壳和本体共用 geometry），见 `src/fx/boss_look.js` geosOf / setVis。2026-11-17
14. **glTF 没有"默认隐藏"** → 二阶段子网格（裂缝、眼焰）出厂是可见的，一阶段和二阶段的部件会叠在一起 → 外观模块构造时必须先 `setPhase(1)`；控制器没接上时（try import 失败）会两套都显示，验收截图要用接了 boss_look 的场景。2026-11-17
15. **动画时长按 30fps 取整，关键时刻对不上** → 0.55 秒 = 16.5 帧，导出成 16 帧（0.533 秒），最后一个关键姿势没播到 → 时长和关键时刻尽量写成 1/30 的整数倍；给战斗主策报"实际帧数 / 秒数"而不是设计稿的数。2026-11-17
16. **连段招式（combo）每段都从头重播动画**，一个片段里放两次咬合不行；`strikeAnim` 从出招瞬间才开始播 → 双段咬拆成 `bite_double_a / b`（b 的起始姿势 = a 的收势），破地而出的 `emerge` 命中帧放在 0.05。动画结构要先问战斗主策用哪种出招机制。2026-11-17
17. **动作拼图里的怪只有指甲盖大，看不出姿势问题** → render_creature 按包围盒 × 2.3 取景，长尾巴 / 大体型更小 → 加了 `--zoom=1.7`；倒地类姿势（down / exec_hit）在第一版把头埋进了地里，就是放大后才发现的。2026-11-17
18. **校验场景里出现两只青牙** → 关卡进谷时按 points.boss 自动生成首领，测试先清场再自己刷，过一会儿关卡又刷了一只 → 外观测试里每帧把不是自己刷的首领清掉（`tools/scenarios/look_qingya.mjs`）。2026-11-17
19. **墨雾门一根立石整根埋进崖壁** → 按设计稿的门宽 4 米建模，北阶通道实际只有 3 米 → 门洞类场景件的宽度先向关卡要"实测通道宽"，宽度做成脚本参数（`mist_gate(W)`），出完必须看游戏内截图。2026-11-17
