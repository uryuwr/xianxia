## 笔路模板生成器（程序化水墨插画 / 器物 / 图标）

用一组"笔路"（中线控制点）生成有提按、出锋、飞白的毛笔笔触，配合没骨淡彩块，输出透明底图。立绘、丹炉插画、物品 / 技能 / 地图图标都是这一套。

| 版本 | 位置 | 输出 | 用途 |
|---|---|---|---|
| SVG 版（节点） | `tools/portrait_gen.mjs`（`stroke(pts, opts)`、`blob(pts, opts)`） | 透明底 SVG | 立绘 `portrait_linmo*.svg`、丹炉 `art_danlu.svg` 等大插画 |
| Canvas 纸性版（浏览器） | `tools/icons/inkicons.js`（`renderCanvas / renderRubbing / renderSVG`，`HELP.{circ, M}`） | Canvas → 图集 webp | 物品 / 技能 / 地图图标；也可画小器物插画 |

操作格式（inkicons）：`{ s: 笔路点[], w 笔宽, c 颜色, op 浓淡, taper 收笔出锋比例, head 起笔, press 起笔顿, both 两头尖（叶 / 牙）, dry 飞白, rough 毛边, wv 提按起伏, seed }`；`{ wash: 闭合轮廓[], hole?, c, op, soft 晕开 }`；`{ dot: [x,y], r, c, op }`。坐标按 128×128 盒子写，`HELP.M(W,H)` 映射到任意尺寸；模板函数 `(W, H, v) => ops[]` 注册到 `TEMPLATES`。

渲染要点：笔身在独立图层 → 尾段按笔毫行擦出飞白 → 纸纹颗粒擦淡 → 底下垫一层模糊淡墨（洇）；淡彩多遍叠染 + 湿边 + 颗粒。小尺寸（≤24px）关掉颗粒：`renderCanvas(spec, W, H, 1, { grain: false })`。

烘焙：参考 `tools/icons_gen.mjs` + `tools/icons/bake.html`（Vite + Playwright 打开页面，在浏览器里画、`toBlob("image/webp")` 回传写盘）。单张插画可用 `docs/ui/v2/mock_bag_v2/shoot.mjs` 截 HTML。

坑：闭合笔路不要重复起点（canvas 版法线 NaN 整笔消失）；颜色参数只接受 `#rrggbb`（不接受 rgba 字符串）；纸纹颗粒让 webp 体积大，图集类产物权衡开关。

## Blender 怪物管线（敌人模块 D，2026-11-17）

- **Blender**：便携版 4.5.16 LTS，`D:/tools/blender-4.5.16-windows-x64/blender.exe`，后台运行，不开界面：
  ```bash
  B=D:/tools/blender-4.5.16-windows-x64/blender.exe
  $B -b --factory-startup --python blender/build_rat.py                  # → assets/models/rat.glb（另存 work/rat_build.blend）
  $B -b --factory-startup --python blender/render_creature.py -- rat     # 校验 + assets/previews/rat_{side,front,topdown45,game_scale,poses}.png
  ```
- **公共库 `blender/lib_creature.py`**（脚本开头 `sys.path.insert(0, 脚本目录); from lib_creature import *`）：
  - `mb = MB(MATS)`，其中 `MATS = [(材质名, RGBA)]`。
  - `mb.loft(中心线, rx, ry, 段数, 材质, 部件, ref=, cap0/cap1, parts=)`：放样。材质可以写成函数 `mat(i, j)`，用来做腹甲 / 背纹。
  - `mb.ellipsoid(中心, 半径, 段, 环, 材质, 部件, rot=Euler)`
  - `mb.spike(底, 方向, 长, 半径, 材质, 部件, flat=)`：笔触尖刺。
  - `mb.block(中心, 尺寸, 材质, 部件, rot=, taper=, bevel=)`：切角方块。
  - `mb.sheet([中心, 边缘点…], 材质, part_of)`：双层薄片。
  - 骨骼表：`[(名, 头, 尾, 父, 是否蒙皮)]`。
  - `PART_BONES`：部件 → 骨骼列表；没写的部件按同名骨骼刚性绑定。
  - 姿势：`mkpose(base, off=(位移), 骨=(x, y, z))`、`keys_fn([(时间, 姿势)], extra)`、`add_pose`、`R(P, 骨, x, y, z)`。
  - 一站式：`build_creature(名, mb, 骨骼表, PART_BONES, 位移骨, [(动作名, fn, 时长, 是否循环)])`，会依次算权重、建对象、烘焙、导出 GLB（ACTIONS 模式、强制采样）。
- **渲染与校验 `blender/render_creature.py -- <名>`**：
  - Workbench 引擎，按包围盒自动取景；
  - 输出侧视、正视、45° 俯视（85 mm）、游戏距离（35 mm、约 14 米）和动作帧拼图（每个动作 2 帧，6 列）；
  - 打印 `[verify] tris / bbox / bones / materials / action`。
- **游戏内截图**：
  - `node tools/run.mjs new_mobs`：新怪各出一招看预警；
  - `node tools/run.mjs tele_closeup`：预警近景、首领喘息；
  - `node tools/run.mjs realm_view`：境界血条。
- **拼图**：
  - `node tools/sheet.mjs <截图名…>` → `work/shots/_sheet.png`；
  - 预览图拼图可仿照 `work/prev_sheet.mjs`（读 assets/previews）。

$B -b --factory-startup --python blender/render_props.py [-- id …]   # → props_<id>_{topdown45,side}.png、props_wolfvalley_sheet.png（旁边 1.75 米人形标尺）
python tools/glb_anim_diff.py 旧.glb 新.glb                      # 逐通道比对同名动画（追加动画后确认旧片段 max abs diff = 0）
node tools/run.mjs look_qingya "scene=run&region=r1&slot=8"      # 游戏内：与竹林狼并排的一 / 二阶段、木 / 土盾、近景、狼谷全景、墨雾门

- **render_creature.py 新可选参数**（旧用法不变）：`--scale=` 只影响 `_game_scale.png`；`--hide=a,b` 按对象名隐藏子网格；`--tag=_p2` 输出文件名后缀；`--poses=0` 不出动作拼图；`--zoom=` 动作拼图放大取景。注意 `--poses=0` 用 SystemExit 提前结束，Blender 退出码是 1，属正常。
- **lib_creature.py 多子网格**：`mb.cur = "armor"` 之后建的面都归到子网格 `qingya_armor`（`mb.cur = None` 回主网格）；`make_objects` 按组拆对象、各自只保留用到的顶点（权重按原顶点序号取，不改拓扑）；`export_glb` 导出骨架的全部子对象。单网格的怪不受影响（只是不再导出没用到的材质）。
- **build_wolfvalley.py 小工具**：`rock(mb, 中心, 半径, 种子, top=平顶高度)`（朝上的面自动用 rock_pale，侧面 rock_ink，棱面不平滑 = 皴法感）、`fang(…, cut=断开高度比)`（同一根柱子出完好 / 残桩，原点一致）、`skull()`、`banner()`（双层破幡，下沿撕口）、`make_static(名, mb)`（静态 GLB，打印面数 / 包围盒 / 材质）。
- **外观辅助** `src/fx/boss_look.js`：`bossLook(enemy)` → `update / setPhase / armorBurst / crackGlow / shield / dispose`；预热用 `bossLookPrewarm()`。

### Blender 无头构建的资源约定（防止吃满用户 CPU）
- 一律 `-t 8`；Cycles 烘焙用显卡：`lib_refine.py` 里按 OPTIX → CUDA 顺序尝试、只启用 RTX 3070，失败才退 CPU。
- 同一时间只跑一个 Blender；playwright 同一时间只开一个浏览器实例，跑完即关。
- 迭代用 `-- --quick`（粗体素）/ `-- --hi`（只出高模预览）缩短单轮；耗时分布：大部分在单线程 Python（MPFB 生成、修改器、体素融合、减面），烘焙只占一小段，所以换显卡不提速（见 坑"主管复盘"节）。
