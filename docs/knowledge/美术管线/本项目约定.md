# 美术管线 · 本项目约定

## 怪物模型（敌人模块 D）
| 规则 | 原因 | 日期 / 拍板 |
|---|---|---|
| Blender 中 Z 向上、面向 −Y、左侧 +X、单位米、原点在脚底；导出 glTF 后 +Y 向上、面向 +Z | 游戏里 `rotation.y = yaw`，`yaw = atan2(dx, dz)` 直接对准目标 | 2026-11-16 |
| 材质名是与游戏的契约：游戏按名称前缀从 `enemy.js` 的 PALETTE 取卡通水墨颜色；模型里的颜色只用于预览 | 统一调色、支持精英 / 异种 tint 换色 | 2026-11-16 |
| 已有材质名：fur_ink / fur_light / fur_brown、eye_red / eye_glow / eye_gold / eye_ice、claw、stone_dark / stone_light / rune_glow / moss、wing_membrane、feather / feather_light / beak、bark / vine_green / leaf_green / flower_red、scale_dark / scale_jade / belly、carapace / silk、snake_green / snake_belly、toad_skin / toad_belly / wart；心魔复用主角材质（robe_white 等） | 新材质名先查重、不要互为前缀 | 2026-11-17 |
| 动作名：idle、run 循环；hit、die（停在末帧）；攻击 attack_*；特殊动作 howl / dive / emerge / roar | 敌人 AI 按名播放；`animHit`（命中帧秒数）写在 `src/data/enemies.js` | 2026-11-16 |
| 所有模型都要有名为 `head` 的骨骼 | "隙"字、喘息墨气、境界提示取头位 | 2026-11-17 |
| 面数：低阶怪 ≤ 1k、标准 ≤ 2k、首领 ≤ 2.5k；骨骼 ≤ 20 根 | 同屏 30+ 只怪；动画 LOD 按视锥裁剪 | 2026-11-17 |
| 飞行怪的悬停高度做进模型（身体在 1.7 米高），实体位置仍在地面 | 主角近战判定、血条、寻路都按地面算 | 2026-11-16 |
| 新模型必须看过 `<name>_topdown45.png` 和游戏内截图（`tools/scenarios/new_mobs.mjs` 一类）才算完成 | 用户的验收标准 | 2026-11-17 用户 |
