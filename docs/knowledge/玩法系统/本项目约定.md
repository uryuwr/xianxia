## 存档字段（profile）
- `storage` / `pouch`：Bag；`equip { sword, robe, jade, artifact }`。
- `build { spells[3], xinfa[2], formation }`：装配，局内只读这里（`loadoutOf`），空栏不自动补；法宝随 `equip.artifact`。
- `unlocks`：`spellSlots`（练气 1 / 3 / 7 层 → 1 / 2 / 3）、`xinfaSlots`（4 / 8 层）、`artifactSlot` / `formationSlot`（7 层）、`pillSlots`（丹药囊种类数）。
- `flags`：`learned { spells, xinfa, formations }`、`loadoutSeen`、`buildV2`（新规则存档，旧档读档时迁移一次）、`lastRegion`、`tutorialDone`、`hint_*`（一次性提示）、`bloodDebuff`（滴血认主，下一局用掉即删）。
- `stats`：runs、kills、extracted、deaths、herbs、chests、lostBagBack、bosses、bestHaul、bestItem、firstDeath。
- `lostBag { region, pos, items }`：身陨遗落储物袋，下一局同区域可取回。
- `map[region] { extracts, inked, seen }`：天机镜跨局记忆。
- `buffs = [{ id: "lingqi", tier: 1–5, remain: 秒, mods: [{ stat, type, value }] }]`：炼化增益（洞府组写入，2026-11-17 定）。mods 缺省时按 `REFINE.buff.tiers[tier-1].mods`（`src/data/recipes.js`）。只在出行局里计时，归零移除并从存档删掉；剩余时长在结算存档时写回。`vuln` 负数 = 减伤。

## 出行局规则
- `run.carried`：带出去的丹药符箓（以及局内捡到放进快捷栏的，带 `found: 1`）。撤离时全部回库；身陨时 `found` 的按储物袋规则，其余按区域 `loseConsumables`。
- 快捷栏：1 回气丹、2 回春丹（固定映射 `skills.potions[0/1]`），3 五行符（4 换种类），G 遁地符；右键蓄势斩，Q / E / R 法术，T 阵盘，V 法宝。
- 序章守场参数在 `prologue.js` 的 `ARENA`。
- 开局刷怪组数：关卡 `points.spawnPacks`（区域规划 v2：r1 9 组、r2 11 组）优先，`regions.js` 的 `packs` 只作兜底（2026-11-17）。
- 首领关口 `points.bossGates`（r1 狼骨门、r2 碧鳞门）：走进 r 米时在天时条下方一行朱色小字提示 `g.text`，4 秒淡出；离开 r+4 米再走近会再提示。
- 关卡新加的点位字段经 `src/game/run/map.js` 的 `normPoints` 转交：数组和标量 / 单个对象都原样带出（之前只带数组，spawnPacks、bossGate 被吞掉过）。
- 首领战流程在 `src/game/run/bossflow.js`（run.boss）：狼骨门 {realm} 换境界标签 + sub；进 points.boss.trigger 圈 → `run.boss.intro(e, cause)` 发 boss:intro { boss, first, tries, best, cause }（控制器因被打 / 砍图腾开战时也调它）；墨雾门按住 F 1.5 秒穿雾撤出 → boss:retreat；首领不吃天时属性（buffEnemy 跳过 def.boss）。存档 `stats.bossLog[id]`（字段见 boss_青牙_v2 §10.2-7，best：斩杀 > 阶段更深 > 剩血更少），首次标记 `flags.bossIntro_<id>`、`flags.bossExec_<id>_<kind>`（2026-11-17）。测试 `boss_flow`（scene=run&region=r1&slot=5，控制器事件用模拟）。
- 品级颜色一律读 `src/core/items.js` 的 RARITY。
- 界面性能遵守 `docs/性能优化_v1.md` §7：不每帧 new，数值不变不写 DOM，canvas 变化时 ≤10Hz 重画。
- **地上物品不自动拾取，一律按 F 取**（用户 2026-11-17："自动拾取老是掉帧卡顿，也要按 F 自取"）：来源有奇遇 / 委托（loot:drop 无敌人实体）、采集或遗落储物袋放不下的、丢弃的、换装换下放不下的。每件挂伪标记 `p.mark = { kind: "pickup", verb: "取", pos, label, q, pickup: p }`，`run.nearestMark` 与其它交互物一起比距离（`PICK_R` = 1.6 米，`src/game/run/pickups.js`）；提示写最近那件，身边多件时 label 写成"名称（等 N 件）"（gather_ui 把括号里拆成小字）。按 F → `run.takeGround()` 一次取走 1.6 米内全部；放不下的留在原地 + 现有满袋提示（不做可弃建议、不做一键腾格）。关键物品照旧进护身格。
- **所有 F 采集点（药草、灵土、矿石、灵光点、灵田，含灵田额外的灵草苗）采完直接进储物袋**，袋满放不下的才落地（之后按 F 取）（用户 2026-11-17）。入口 `run.onGathered(e)`（gather:done 的监听），给 GatherUI 留 `e.got / e.left`：入袋的从草丛飞进储物袋计数，落地的才播抛落弧线；提示 `run.toast("采得 …")`。
- 入袋统一走 `run.collect(insts, { src: "ground" | "gather" })` → `{ got, left }`；成批拾取包在 `run.pickBatch(fn, o)` 里（搜取窗"全取" `containers.takeAll` 也是）：期间 `onPickup` 不逐件发 `"bag"`、不逐件弹"拾得"，结束时各一次（`run.bagChanged()` 代替直接 `emit("bag")`）。
- 中途关闭页面的记录 `saveMarker`：储物袋变化只标脏，下一帧写、每秒至多一次；`run.result` 有了以后不再写。
- **首领首杀必得物击杀时直接进护身格**（`run.secureFirstKill`，由 `containers.fromDrop` 在 `lootSource === "boss_first"` 时调用）：带 `key` 标签的（碧鳞内丹、筑基丹方、乾坤锦囊）、`FIRST_KILL_KEEP`（青牙之牙）、功法完本 `scroll_*_book`；其余照常进首领尸体。提示"首杀××必得：… 已收入护身格（身陨不失）"排到处决演出结束后弹（`run.lateToasts`）。原因：首杀标记 `flags.boss_<id>` 在死亡时就写，必得物一旦没带走就永久错过（2026-11-17 用户报"青牙之牙"，主管）。新加首领的首杀主材若没 `key` 标签，加进 `FIRST_KILL_KEEP`。
- **交互优先级**：撤离阵按"进阵圈"算距离（减 `EXTRACT.radius − 1`），但 1.6 米内紧挨着的尸体 / 宝箱 / 地上物品 / 采集点优先于撤离阵；Boss 出口放在离尸体 6 米、朝主角一侧的可站平地（`run.bossExitPos`）（2026-11-17）。

### 数值（数值评审 2026-11-16，用户预先批准）

### encounters.js 字段
- 通用：`name`、`title`、`glyph`（头顶印章）、`visual`（bailu / fox / remains / rain / lingtian）、`weight(P)`、`start(P)` → 起始节点、`nodes`。
- 节点：`lines [[说话人, 文本]]`（`""` 旁白、`"{me}"` 主角，心声用全角括号）；`choices [{ text, need?, effects?, reply?, next? }]`；`need` 支持 `{ item, n }` / `{ stones }` / `{ favour }`。
- 放置：`types`（适配的关卡奇遇点类型，默认 `[id]`）、`altTypes`（退而求其次的类型）。
- 单独掷：`separate`、`chance`（数字或 `{ r1, r2 }`）、`minRun`。
- 灵田专用：`field: true`、`count [min, max]`、`radius`、`kinds { 区域: [[lt_<草>_q<品级>, 权重]] }`（直接引用 `GATHER.lingtian`）、`seedBonus`、`ambush { chance, at: [min, max], n, elite }`、`thought`、`ambushText`、`done`（采尽时的效果）。

### 关卡点位与交互
- 奇遇读 `run.map.points.encounters`（每点 `types`，原位放置），遗物委托读 `run.map.points.relics`（每点 `place` 地名）；都没有时退回灵光点 / 遗府 / 宝箱等附近。
