# 玩法系统 · 工具

## 自动化场景（Playwright + Vite）
- 运行：`node tools/run.mjs <场景> [query]`。query 原样拼进页面 URL，常用：
  - `scene=title`：从标题页起（loop_flow 用；会走新游戏 → 序章 → 洞府 → 出行 → 结算全流程）
  - `scene=run&region=r1&slot=3`：直接进区域一出行局（slot = 存档位，测试互不干扰）
  - `scene=cave&slot=3`、`scene=prep`
- 环境变量：`W` / `H` 视口（默认 1280×720），`DPR` 设备像素比，`HEADED=1` 有头运行，`IGPU=1` 强制集显，`NOHMR=0` 不屏蔽热更新。
- 输出：场景里 `console.log("PASS …")` / `console.log("FAIL …")`，有 FAIL 时退出码 1；截图在 `work/shots/<场景>_<名字>.png`。
- 场景函数 `export default async (page, c)`：`c.ev(fn, arg)` 在页面里执行，`c.wait(ms)`，`c.shot(name)`，`c.log(...)`；需要切分辨率用 `page.setViewportSize`。
- 全量回归：`bash tools/regress.sh`（两两并行跑全部场景，日志在 work/regress/）。
- 连跑 N 次验稳定：`for i in 1 2 3; do node tools/run.mjs loop_flow scene=title > work/loop_flow_$i.log 2>&1; grep -c '^PASS' work/loop_flow_$i.log; grep '^FAIL' work/loop_flow_$i.log; done`
