# 墨途 · 数值评审 v1

> 评审范围：《最小闭环设计 v1.1》§8–§13，以及已实现的数据表（`src/data/progression.js / loot.js / items_db.js / recipes.js / enemies.js / skills.js`、`src/game/shields.js`、`src/game/run/regions.js`，2026-11-16 版本）。
> 默认已批准的玩法改动：第 2 / 3 法术栏练气三 / 七层、法宝栏练气七层；G3 关键物品不丢；G4 可见机缘刻度；G5 局间 ≤ 90 秒；G6 八局节奏；G9 灵潮（晨 1.0 / 午 1.2 / 暮 1.5 / 夜 2.0，区域一暮 = 第 9 分钟）；G7 出行委托；G8 四个奇遇；G10 五行符 / 附灵。

## 0. 结论先行

总时长本身没有问题：当前版本到筑基的中位时间 85–98 分钟，已经落在目标区间。**问题出在曲线形状和方差**：

1. **前快后卡**。区域一的修为收入是计划的 1.6 倍，玩家第 5 局就进区域二（G6 计划第 6 局），贪心型第 4 局。随后在练气九层圆满处卡 1.2–1.7 局，等碧鳞和随机刷出的千年何首乌，期间溢出浪费 1300–1900 修为，相当于总需求的 30–43%。p90 玩家要 116–136 分钟。
2. **五行护盾是二元的**。有克制法术时 0–3 秒破盾，没有就 12–18 秒硬磨。碧鳞三段护盾合计 96 秒，其中土盾段只能靠缠藤诀磨 42 秒。五行符的倍率叠出 ×6，一张就能破盾。
3. **大奖兑现得太晚**。机缘刻度只在 Boss 或夜明宝箱时兑现，谨慎型玩家下一次兑现就是碧鳞首杀（v1 最后一战），只有 15% 的玩家能在碧鳞之前拿到极品。
4. **灵石几乎全部被设施吃掉**。一周目带回约 1500 灵石，其中 1285 花在设施和符箓上，只有 32 块进灵泉炼化。"满载带回 → 炼化"这个核心循环在灵石这条线上名存实亡。同时，70–90% 的玩家在 v1 内买不起炼器鼎 Lv2、药园 Lv2 和 32 格储物袋。
5. **搬家后聚气丹断供**。配方只认狼妖内丹，而区域二的精英掉的是蝠妖 / 藤妖内丹。

按建议改动后：

|---|---|---|
| 到筑基局数 p50 / p90（谨慎 / 贪心 / 新手） | 7/10 · 7/10 · 9/12 | **8/9 · 7/8 · 8/10** |
| 到筑基分钟 p50 / p90 | 85/116 · 89/127 · 98/136 | **89/99 · 84/98 · 96/116** |
| 九层圆满后浪费的修为 | 1309 · 1887 · 1467 | **406 · 514 · 505**（再加"溢出存储"规则可归零） |
| 第 4 局结束时的累计修为（目标 750） | 1622 · 2258 · 1447 | **771 · 1174 · 713** |
| 碧鳞之前拿到极品的概率 | 15% | **87%** |

## 1. 发现（按严重度）

### 🔴 P0-1 九层圆满处"罚站"：何首乌靠运气，碧鳞要九层

- 筑基需要三样东西：练气九层圆满、碧鳞内丹（Boss 首杀）、千年何首乌。当前何首乌只是区域二的随机灵草，模型假设每局约 45% 的概率遇到（【假设】）。碧鳞则要求九层才能挑战（§9.2）。
- 模拟结果：玩家平均在九层圆满后还要再出 1.2–1.7 局，这期间的感悟和灵物全部溢出（c9）。新手 p90 需要 12 局、136 分钟。
- **改法**：
  - 何首乌改为剑修遗府首通的固定奖励（关键物品）。
  - 碧鳞改为练气八层即可挑战。
  - 九层圆满后溢出的修为存进 `xpBank`（上限 600），筑基后返还。
- 改后卡在圆满处的局数降到 0.1–0.3。

### 🔴 P0-2 五行护盾"要么秒破、要么硬磨"

公式：护盾 = 0.45 × 最大气血；克制五行 ×3，其他五行 ×0.25，无属性 ×0.15。精英气血按 `enemies.js` 的等级缩放计算，结果见 c6：

| 场景（精英气血按等级缩放） | 当前：只靠法术 | 建议：只靠法术 | 建议：+ 一组五行符 | 建议：附灵剑 |
|---|---|---|---|---|
| 狼妖头目 L3 木盾（剑气斩克） | 0.1 | 3.3 | 0.1 | 1.2 |
| 狼妖头目 L4 木盾 | 2.7 | 4.3 | 0.1 | 1.6 |
| 藤妖 L6 土盾（缠藤诀克） | 5.6 | 0.1 | 0.1 | 0.1 |
| 藤妖 L6 火盾（练气七层前无克制） | **18.4** | 11.4 | 1.8 | 4.4 |
| 藤妖 L8 火盾（寒冰锥克） | 0.1 | 2.0 | 0.1 | 0.7 |
| 狼妖头目 L8 水盾（无克制） | **15.0** | 10.2 | 2.7 | 4.2 |
| 藤妖 L9 土盾（缠藤诀克） | **12.2** | 5.1 | 1.0 | 1.8 |
| Boss 青牙 L4 全程 | 37 | 33 | | |
| Boss 碧鳞 L8 全程（火 / 土 / 木段） | **130**（24 / 42 / 30） | 76（12 / 14 / 16） | | |

- **现象**：克制倍率 ×3 与无属性 ×0.15 相差 20 倍，"带没带对法术"直接决定是 0 秒还是 18 秒。
- **缠藤诀太弱**：它是土盾唯一的克制法术，但总伤太低。结果是"有克制"的藤妖 L9 土盾反而要 12 秒，碧鳞土盾段要 42 秒。
- **五行符太强**：按"克制再 ×2"结算 = ×6，一张就破区域一精英盾。
- **附灵太强**：附灵剑按克制的 50% 结算，普攻破盾比专门的克制法术还快。
- 参考：《原神》的元素护盾也采用"对应元素 / 其他元素"的倍率差（同元素伤害只按 40% 结算），但不同元素之间相差约 2.5 倍，而不是 20 倍（[Shield 机制](https://genshin-impact.fandom.com/wiki/Shield)、[Shield Damage 解析](https://traveler.gg/an-extensive-look-into-shield-damage-in-genshin-impact/)）。
- **改法**：
  - `SHIELD_TUNE` 改为 frac 0.40 / counter 2 / other 0.20 / physical 0.25（克制与无属性之间缩到 8 倍）。
  - Boss 每段护盾 25%。
  - 青牙气血 1800 → 2400。
  - 缠藤诀 base 6 → 10，spell 系数 0.4 → 0.7。
  - 五行符 shieldMul 2 → 1：一组 3 张 ≈ 一面同级精英盾。
  - 附灵 50% → 35%。
- 改后的分工：没准备，约 10 秒；三种准备方式各自是 1–5 秒的快解。

### 🟠 P1-1 区域一修为过快，八局节奏被压成六到七局

| 第 n 局结束时的累计修为 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 目标（G6 八局；第 5 局青牙，第 6 局搬家） | 60 | 260 | 480 | 750 | 1150 | 1950 | 3000 | 4370 |
| 当前 · 谨慎 | 60 | 380 | 781 | **1622** | 2813 | 3844 | 4280 | 4363 |
| 建议 · 谨慎 | 60 | 240 | 418 | 771 | 1468 | 2623 | 3805 | 4297 |
| 建议 · 新手 | 60 | 226 | 393 | 713 | 1297 | 2250 | 3261 | 3955 |

- 当前区域一一局约 300–450 修为（目标约 200），主要来自三处：
  - 精英感悟 ×8，加上 1.5–2.5 只精英。
  - 狼王遗骨 150：一件就顶练气 2 → 3 的全部需求。
  - 狼妖内丹 40。
- 区域二的感悟（每只 8，灵潮另外放大）让贪心型玩家的感悟占比达到 45%。
- **改法**：
  - 精英感悟 ×8 → ×5；区域一感悟 3 → 2；区域二感悟 8 → 6。
  - 妖丹：狼妖 40 → 25，石傀 45 → 28，蝠妖 / 藤妖 90 → 60。
  - 灵物：狼王遗骨 150 → 80，灵蚌珠 70 → 35，水灵玉 300 → 240，千年竹心 360 → 300。
- 修为需求表（合计 4370）和属性成长不改。

### 🟠 P1-2 机缘刻度兑现点太少，极品大多落在最后一战

- `FORTUNE.payout` 只有 Boss 和夜明宝箱。谨慎型玩家打完青牙后基本不贪夜，所以刻度满了以后要等到碧鳞首杀才兑现，那时 v1 已经结束。
- 一周目平均 1.0 件极品，但只有 15% 的玩家能在碧鳞之前拿到（c7）。
- **改法**：
  - 兑现点加上精英和灵光宝箱。
  - 刻度兑现的极品打上 `key` 标签，身陨不丢。
  - 委托给机缘 +12，奇遇给 +5。
  - 原有增量不变。
- 改后：首个极品的中位出现在第 5–6 局，平均每周目 1.1 件，87% 的玩家在碧鳞之前拿到。
- 参考：《暗黑 3》的传奇"保底计时器"只在"可能掉传奇的事件"上累计，掉落后立即重置，目标是"不会超过约 2 小时见不到传奇"（[Diablo Wiki](https://www.diablowiki.net/Legendary_Pity_Timer)）。本作的可见刻度是同一思路，节奏换算到 1.5 小时一周目。

### 🟠 P1-3 灵石的水龙头远小于水槽：灵泉炼化灵石几乎为 0

- 一周目带回约 1500 灵石，设施和符箓花掉 1285，进灵泉炼化的只有 32 块（c4）。
- 区域一一局约 80 灵石，而必需设施要 490，每局固定还要花 25（遁地符、五行符）。区域二的护器符一局 40。
- 设施方面，炼器鼎 Lv2（300）、药园 Lv2（200）和 32 格储物袋（200）在 v1 内买不起的玩家比例分别是 91%、87% 和 69%，这部分内容等于闲置。
- 参考：经济设计的通行做法是先设计水槽，再按水槽调水龙头，并用"水槽 / 水龙头"比例来衡量（[Unity 经济设计指南](https://unity.com/resources/game-economy-design-guide)、[Heroic Labs](https://heroiclabs.com/blog/how-in-game-currencies-work-and-why-live-economies-break/index.html)）。本作单机、没有市场，不存在通胀，相反的风险是"钱永远不够，核心循环被架空"。
- **改法**：
  - 普通宝箱灵石 4–9 → 6–12。
  - 遁地符（2 张）20 → 10，五行符（3 张）15 → 10，护器符 40 → 25。
  - 炼器鼎 Lv2 300 → 180，药园 Lv2 200 → 100，32 格储物袋 200 → 150。
  - 区域二灵石倍率 2.5 保持不变。
- 改后炼化灵石 150 块，三个设施买不起的比例降到 62% / 22% / 54%：仍然要取舍，但不再是摆设。

### 🟠 P1-4 聚气丹：只认狼妖内丹，且 1 换 2.5 没有取舍

- 区域二的精英掉蝠妖 / 藤妖内丹（`CORE_OF.r2 = vine_core`），所以搬家后聚气丹断供，§10.3 第 7 局的"聚气丹 ×3"做不出来。
- 在区域一，1 枚狼妖内丹（炼化 40）能换平均约 100 修为的丹，玩家永远选炼丹。
- **改法**：
  - 聚气丹改为 2 枚内丹一炉。
  - 新增藤心方 / 蝠丹方（各 2 枚区域二内丹 + 3 寒露草）。
- 改后丹药占比约 7%。火候好的玩家（上品 / 极品）明显更赚，炼丹小游戏有了数值意义。

### 🟠 P1-5 文档的修为来源目标与自身数值矛盾

- §10.1 把首杀 / 遗府定为 5%，但 150 + 400 + 80 + 250，再加教学局 60，固定就是 940，占 4370 的 21.5%。
- 建议把目标改为：感悟 30 / 炼化 40 / 丹药 7 / 首杀遗府 18 / 委托奇遇 5。
- 建议版实测：感悟 27–32、炼化 38–41、丹药 7、首杀遗府 19–21、委托奇遇 5（c2）。

### 🟡 P2-1 区域二身陨对新手过重

- 当前储物袋清零，只能取回 60%。新手一周目平均损失 811 灵值，约为带回灵石的一半；区域二平均身陨 1.0 次。
- 参考：《逃离塔科夫》用"保险箱 + 保险"把损失切成可预期的几块，并让关键物品始终安全（[gamepressure](https://www.gamepressure.com/escape-from-tarkov/how-do-i-keep-my-items-after-death/zdcfd0)、[Wikipedia](https://en.wikipedia.org/wiki/Escape_from_Tarkov)）。G3（关键物品不丢）已经覆盖后者。
- **改法**：区域二 keepBag 0 → 0.25。装备风险不变（仍遗落 1 件未认主装备，可以取回）。新手损失降到 352。

### 🟡 P2-2 小怪装备与保底

- 当前 4% 掉率加 25 只保底，保底几乎每局都会触发，等于固定掉落。
- **改法**：掉率 6%（品质权重 70 / 25 / 5），保底放宽到 40 只。

### 🟡 P2-3 极品自然概率

- Boss 首杀 1% → 3%，重复击杀 0.5% → 1%，夜明宝箱 0.35% → 约 1%。
- 自然极品仍然稀有，94% 的极品来自刻度兑现。但"入夜开夜明宝箱"有了看得见的期待，和灵潮 ×2 的叙事一致。

### ✅ 已确认无需改动

- **普通怪 TTK**：同级 2–4 刀（一套三连之内），石傀和藤妖 4 刀属于肉盾定位（c5）。`ENCOUNTER.scale` 0.27 / 0.12 / 0.08 合适。
- **承伤**：狼妖扑咬约占气血 7–9%，首领连扑 9–14%；区域二普通妖兽约 8%，精英重击 11–16%。都在"5–6 下普通攻击 / 3 次精英重击才危险"的区间内。
- **灵潮**：倍率 1 / 1.2 / 1.5 / 2 与天时分段合适。谨慎型平均灵潮 ×1.14，贪心型 ×1.20。当前版本贪心型反而比谨慎型慢（中位 89 vs 85 分钟，p90 127 vs 116）；建议版贪心型快 5 分钟、p90 持平。"贪"是一种风格，而不是碾压式的最优解。
- **境界需求表、属性成长、灵泉 2 / 3 / 4、聚气丹每层 3 枚、灵泉 Lv2 120、炼丹炉 30 / 200**：都不改。

## 3. 模型假设与敏感度

代码和文档都没有给出、模拟又必须的量，统一在 `sim/params.py` 中标为【假设】：

| 假设 | 值 | 依据 |

| 单局时长（区域一 / 区域二 / 贪到入夜） | 8.5 / 11 / 13.5 分钟 | §10.3；天时分段 |
| 每分钟普通击杀（暮夜 +30%） | 区域一 3.3 / 区域二 3.6 | §4.2 地图大小；区域一每局约 28、区域二约 40 只 |

## 5. 如何重跑

```bash
cd docs/review/numeric
# 第一次：建虚拟环境（国内源更快）
python -m venv .venv
.venv/Scripts/python.exe -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r sim/requirements.txt
# 出全部图表与 results.json（每种画像 2000 次，约 20 秒）
PYTHONIOENCODING=utf-8 .venv/Scripts/python.exe sim/run_all.py 2000
# 只看文字版对比（累计修为、局数、来源、极品）
cd sim && PYTHONIOENCODING=utf-8 ../.venv/Scripts/python.exe tune.py
```

- `sim/params.py`：
  - `CURRENT` 对应当前文档、代码和已批准的改动，每个字段都注明了来源文件。
  - `PROPOSED` 是本评审的建议，与 `numeric_proposal.json` 一一对应。
  - 数据表改动后，同步改 `CURRENT` 再重跑即可。试玩拿到真实的单局时长和击杀数后，回填【假设】项。
- `sim/econ.py`：经济与进度模拟，包括灵潮、机缘刻度、委托 / 奇遇、关键物品、储物袋取舍、身陨与取回、洞府设施、聚气丹与炼化。
- `sim/combat.py`：TTK 与破盾模拟，公式同 `combat.js` / `shields.js` / `enemies.js scaledStats`。
