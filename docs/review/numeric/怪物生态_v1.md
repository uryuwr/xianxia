# 墨途 · 怪物生态 v1（方案：分区等级、低阶怪与日常材料、稀有异种）

> 状态：**掉落、材料、配方已落地**（2026-11-17，见 §7）。怪物 id 已与敌人模块对齐：低阶 rat / crow / spider / snake / toad，异种 chilang / xuanlin_bat。分区 baseLevel 已与关卡设计对齐。
> 下面的怪物名是占位，以敌人模块的命名为准；数值按"原型"定，换名不换数。
> 依据：难度复核 v1 的 TTK / 承伤目标；经济复核、药园与重铸、真气 v1 的灵石和材料流转。

## 0. 一句话

- **等级跟着分区走，不再跟着玩家走**：外缘、中段、深处各有基准等级，玩家境界只做 ±1 级的小修正。越往里越难，回头打外缘会觉得自己变强了。
- **低阶怪掉日常材料**：兽皮、兽牙、骨粉、羽毛、毒囊、蛇蜕、妖丹碎片。这些材料接进炼丹、画符、炼器、重铸、药园施肥，**每一局都会消耗**。精英、首领和异种基本不掉，它们掉妖丹、稀有材料和装备。
- **稀有异种**：同模型的稀有配色，等级比分区高 4–5 级，每局 0–1 只（区域一 35%、区域二 40%）。掉宝品以上的装备（10% 仙品）、专属材料（赤狼心等）和机缘值 12。

## 1. 分区基准等级（`levelFor`）

**公式**（已与关卡设计对齐，见 docs/review/level/区域规划_v2.md 的"数据约定"）：
怪物等级 = 分区 `baseLevel` + clamp(玩家层数 − 分区 `realm[0]`, 0, 1)；精英 +1；首领固定（青牙 4、碧鳞 9）；异种按数据表等级固定（赤狼 8、玄鳞蝠 10）；刷怪点可以写 `baseLevel` 覆盖分区的值。筑基按第 10 层算。

- 等级只会往上修正 1 级：深处对没练够的人照样危险。
- 练高了以后，外缘最多 +1 级："回头打外缘"能感到自己变强了。

| 区域 | 分区（关卡 v2） | realm | baseLevel |
|---|---|---|---|
| 一 | 溪畔 | [1, 2] | 1 |
| 一 | 竹林 / 狼踪 | [2, 3] | 2 |
| 一 | 山神庙、乱石岗 | [3, 4] | 3 |
| 一 | 北脊 | [4, 4] | 4 |
| 一 | 青牙狼谷（首领） | [4, 4] | 4（青牙固定 4） |
| 二 | 五个分区，[5, 6] → 碧鳞潭 [9, 9] | | 5 / 6 / 7 / 8 / 9（若分六个区：5 / 6 / 7 / 7 / 8 / 9） |

经验法则：新增分区的 `baseLevel` = `realm[0]`。

（原方案按"外缘 / 中段 / 深处"三档、修正 ±1，现已替换为上面的版本。下表保留作为风险分布参考。）

| 区域 | 分区（关卡 v2，名称以关卡为准） | 基准等级 | 风险 | 主要怪物 |
|---|---|---|---|---|
| 一 | 外缘（溪畔、入口一带） | 1 | 1–2 | 低阶为主，零星标准狼 |
| 一 | 中段（竹径、东坡、山神庙） | 2.5 → 写作 3（修正后 2–4） | 2–3 | 低阶 + 标准，精英 |
| 一 | 深处（北脊、狼谷） | 4 | 4–5 | 标准、石傀、精英；青牙 4 级固定 |

- **缩放**：沿用 `ENCOUNTER.scale`（每级气血 +15%、攻击 +12%、防御 +8%），不变。
- **对 TTK 的影响**：难度复核里"区域内越打越轻松"（练一 1.85 套 → 练四 1.24 套）现在变成"外缘轻松、深处吃力"。练四打深处的标准狼（4 级）是 1.24 套；练一去深处，修正 −1 后是 3 级的狼，约 2.4 套，而且一下 6–9% 气血。
