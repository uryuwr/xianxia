# 墨途 · 战斗：气势与身法 v1

> 范围：闪身冷却、普攻攻速随修为成长、气势（势）与蓄势斩、普攻流心法 / 词条。
> 目标：主角依旧强而流畅、不魂系；普攻本身成为一条构筑线（与法术 / 法宝 / 阵法并列），成长来自修为与构筑。

## 1. 设计要点

1. **闪身有冷却，不能无限用**。开局 1 次充能、2.75 秒冷却；第二次充能是成长点（练气六层自动获得，或心法《流云》/ 特殊词条"流云身法"）。闪身仍然随时可以取消任何动作、仍然有无敌帧——流畅不变，只是要"挑时机"。
2. **完美闪身是技巧奖励**：立即返还 60% 冷却（2.75 秒 → 约 1.1 秒后可再闪），并给 25 点气势、下一击 +50% 伤害（原有）。会闪的人几乎感觉不到冷却。
3. **攻速随修为成长**：练气一层 0.80 → 每层 +0.039 → 筑基一层 1.15。招式时间轴（出伤点、可预输入、可取消、总时长）和动作播放速度一起按攻速缩放。越修炼出剑越快，这是"变强"最直观的手感。
4. **气势（势）**：普攻命中积攒。**右键主动放蓄势斩**，时机由玩家掌握：气势 ≥ 50 就能放（伤害、范围、剑气距离按气势比例），满 100 为"势成"——锁定，不衰减、受击不扣，一直留到玩家放出；放出后清零。左键连段只在 1→2→3 之间循环，不会自动出蓄势斩。
5. **蓄势斩**要爽（满势）：金墨聚于剑身（起手）→ 朱红大弧横扫 + 一道月牙剑气向前推进 7.5 米 → 顿帧 0.14 秒 + 0.12 秒慢动作 + 镜头推近 10% + 震屏 + 朱色"斩"字。半势只有轻顿帧和较短的剑气。附灵五行照常生效（剑气换成该五行的颜色）；对护盾 ×2.5，是法术克制之外的另一条破盾手段。
6. **普攻流构筑**：5 本普攻流心法 + 1 本身法心法；法剑 / 玉佩的随机词条（攻速、气势获取、蓄势斩伤害、闪身冷却）；仙品以上特殊词条（满势疾攻、蓄势斩余波、蓄势斩回锋、流云身法）。数值克制，单体收益约 +0~10%，群战与破盾收益更明显。

### 1.1 释放方式的演变

- v1 用"满势后第三段自动接第四段"：零学习成本，但用户试玩反馈两个问题——按住左键连段时一满就自动放出，**玩家没法自己挑时机**；满了还会随时间流失，**打满等于白打**。
- v1.1（现行）：**右键主动释放**。右键原来是法宝，法宝改到 **V**（法宝是练气七层才开、冷却长的技能，挪到键盘不影响手感；右键给最常用的普攻流大招）。
  - 瞄准法术 / 法宝 / 阵盘时，右键仍然只是"取消瞄准"，不会放蓄势斩；储物袋、搜取窗口、天机镜、暂停菜单打开时，右键归界面（丢弃、插墨点等）。
  - 普攻前半段、施法、闪身中按右键会**缓存**（普攻中约 0.35 秒、施法 / 闪身中约 1.2 秒），到可以取消的那一刻立即放出——"闪身穿过去、落地右键"是最顺的用法。
  - 闪身取消蓄势斩的起手**不会**消耗气势（在出伤那一刻才清空）。
- 半势可放是为了让"边打边放"成立：小怪群里 50 就放一刀清场，打精英 / 破盾时攒到势成再放。

## 2. 按键

| 操作 | 按键 | 说明 |
|---|---|---|
| 普攻三连 | 左键（按住连续） | 只在 1→2→3 之间循环 |
| 蓄势斩 | **右键**（不在瞄准中） | 气势 ≥ 50 可放；< 50 不出招，光标旁"势未成" + HUD 气势条抖一下 |
| 法宝 | **V** | 先出预览，左键或再按 V 确认；瞄准中右键 / Esc 取消 |
| 闪身 | Space | 冷却中按下：不闪，HUD 墨点抖一下、泛朱（`player:dashDenied`） |
| 御剑（筑基） | Space（在深水 / 崖边朝对岸） | 闪身路线被深水或陡崖挡住且 12 米内有落点时自动变为御剑；筑基前提示"水深难渡，需御剑（筑基）" |
| 其他 | Q/E/R、T、F、1–4、G、Tab、M、C、Esc | 不变 |

### 3.2 攻速（`growth.aspd`，v1.4 公式 `0.65 + 0.35 × (层 − 1) / 9`）

- 招式时间轴：`MOVES` 是 aspd = 1 时的数值，`player.moveTimes()` 全部 ×1/aspd；动作用 `play(anim, …, dur)` 按招式时长调整播放速度，所以动作与判定始终对齐。

- 词条"攻速"（pct）：法剑 / 玉佩 4 / 6 / 9%；《满势》势成时 +15%。

- 50 → 100 之间收益接近线性（0.52 → 0.84），到 100 跳到 1.0 并有完整演出、完整控制和完整剑意，"攒满再放"有明确回报；半势 ≈ 一个同境界剑气斩。

- 加成：完美闪身 +50%、《连环》层数、蓄势斩伤害（chargeDmg：《蓄势》+10%、词条 10 / 16 / 25%）都是独立乘区，直接乘进招式的 base 与 scale（**不能用 Stats 的 `dmg` "more"**：dmg 基础值是 0，乘了等于没加——v1.2 复核时发现，原来的完美闪身加成一直没生效，已修）。
- **破盾易伤加成（v1.2）**：蓄势斩（横扫 / 剑气 / 余波）命中处于破盾易伤中的敌人（破盾后 6 秒）再 +15%（`CHARGE.vulnBonus`，独立乘区，伤害标签加 `"vulnBonus"`），与破盾易伤本身的 +30%、《连环》《蓄势》《回锋》等都叠加。"破盾 → +15 气势 → 右键势斩"是精英战的固定爽点。

- 消耗：出伤瞬间清空气势与连环层数；起手阶段被闪身取消则不消耗。
- 时机：右键可以打断普攻后半段（出伤之后、可取消时）；普攻前半段 / 施法 / 闪身中按下会缓存，见 §1.1。

| 闪身留剑影 | 《剑影》dash_shadow | trigger（闪身留剑影，0.6 秒后爆开） |
| 暴击引雷 | 《雷引》crit_thunder | trigger（暴击引雷） |
| 锋锐（旧名"首击必暴"） | 《锋锐》sharp | mods（暴击率 +15%、暴击伤害 +30%） |
| 金刚体 | 《金刚体》vajra | mods（防御 +20、气血 +25%） |
| 满势疾攻 | 《满势》mom_haste | mods（开关，player.js 结算） |
| 蓄势斩余波 | 《余波》mom_wave | 同上 |
| 蓄势斩回锋 | 《回锋》mom_return | 同上 |
| 流云身法 | 《流云》dash_flow | mods（充能 +1、冷却 −10%） |

- 链路：`gearStats()` 对带 `xinfa` 且该心法标了 `affix: true` 的特殊词条产出标记属性 `gx_<心法 id> = 1` → `SkillSystem.applyLoadout()` 把它并入心法集合：mods 型以 `xinfa:<id>` 来源加属性，trigger 型走 `src/game/skills/xinfa.js` 装触发器。`SkillSystem.update()` 每 0.2 秒检查一次标记，局内换 / 卸装备也会自动生效 / 撤掉。
- **同名不叠加（规定）**：心法栏、法剑、法衣、玉佩里的同名效果只算一次。典型情况：练气四层自动领悟的《锋锐》在心法栏里，法剑上再出"锋锐"词条，暴击仍然只 +15%；这件装备的价值在于"把心法栏空出来"——卸下心法栏的《锋锐》换别的心法，锋锐效果由装备继续提供。《流云》同理：心法 + 词条仍是 +1 充能（练气六层前 2 次，之后 3 次）。
- "首击必暴"与《锋锐》描述不符，新掉落的词条名改为"锋锐"；旧存档里的装备仍显示"首击必暴"，效果按《锋锐》。
- 洞府模块的兜底词条生成（`src/game/cave/facilities.js`，只在内容模块缺失时使用）产出的特殊词条没有心法 id，不生效；正常游戏走 `src/game/loot.js`，不受影响。

> 新增词条会稀释随机词条池（法剑池从 6 条变 9 条），老词条的出现率相应下降。

### 3.8 攒势加强的复核（v1.2，`num_ttk elitesOnly=1`）

**结论：原来"精英战 0–2 刀、碧鳞 3–5%"主要是测试机器人的问题，不是攒势慢。**`num_ttk` 的机器人要求 `canStartCharge()` 为真才按右键，而按住左键连段时，每到可取消那一帧主角就接了下一段——机器人永远按不出来（只有开场站定时能放）。已改为与真人一样走 `tryCharge()` 的缓存，次数按 `player:charge` 事件计（`tools/scenarios/num_ttk.mjs` fight()，已注释）。另外实测发现原来的完美闪身 +50%、《连环》、蓄势斩伤害词条在 Stats 里写成了 `dmg` "more"，乘 0 等于没加，已改成直接乘进招式倍率。

修正机器人后（每格 3 次平均，主角无敌、只普攻 + 法术 + 蓄势斩、开场 0 势；"占比" = 蓄势斩伤害 / (气血 + 各段护盾)）：

| 目标 | 旧机器人 v1.1（"现在"） | 修正机器人 v1.1 | 修正机器人 v1.2（×1.5 / +20 / +20%） | 修正机器人 v1.2b（×1.25 / +15 / +15%，现行） |
|---|---|---|---|---|
| 区域一精英（练一 / 三 / 四） | 13.2 / 12.9 / 8.6 秒，0 刀 | 10.4 / 12.2 / 10.4 秒，约 2 刀 | 10.4 / 12.5 / 8.2 秒，2–3 刀 | 13.3 / 12.6 / 8.6 秒，约 3 刀 |
| 区域二精英（练五 / 六 / 八，两种） | 14.8–18.3 秒，0–1 刀 | 9.0–13.1 秒，2–3 刀 | 9.4–13.6 秒，3–4 刀 | 10.2–11.5 秒，3 刀 |
| 青牙 | 29.2 秒，2 刀，约 5% | 26.5 秒，5–6 刀，约 22% | 22.8 秒，6–7 刀，约 32% | 28.2 秒，7 刀，约 29% |
| 碧鳞 | 64.7 秒，2–3 刀，约 3% | 61.6 秒，14 刀，约 20% | 57.9 秒，18 刀，约 28% | 54.0 秒，15 刀，约 24% |

- 精英 2–4 刀：修正机器人后 v1.1 已达到，v1.2b 约 3 刀。
- 首领占比：修正机器人后 v1.1 就已 20–22%，v1.2 的加强把它推到 24–32%，超过 10–15% 的目标；击杀时间相对修正机器人的 v1.1，精英大致持平（±噪声），青牙持平、碧鳞约 −12%。因此 v1.2 的三条按"克制"回调到 ×1.25 / +15 / +15%。3 次取平均噪声约 ±20%，数值策划复核时建议加大 trials。
- 首领占比要压到 10–15%，只能动蓄势斩本身（或攒势速度），这与 v1.3"满势一刀 ≈ 1.8 个剑气斩"的方向相反——**v1.3 之后的占比请数值策划用 num_ttk 重测**（机器人无敌、永远贴脸，是上限值）。

## 8. 蓄势斩：对标法术、剑意破盾、控制（用户拍板）

用户反馈："蓄势斩的释放门槛比法术高（要攒气势），伤害却差太多"。

| 机制 | 规则 | 数值（`CHARGE`） |
|---|---|---|
| 伤害对标法术 | 满势一刀（横扫 + 剑气打同一目标）≈ 同境界剑气斩三道全中的 1.8 倍；半势 50 ≈ 1 倍 | 横扫 `base 75 + scale 3.45`，剑气 `base 40 + scale 1.88`；`partial.dmg = [0.52, 0.32]`；标定表见 §3.4 |
| **剑意破盾**（核心身份） | 命中带护盾的敌人：**不看五行**，先直接削去护盾上限的一截，再按普通倍率结算；每刀每敌一次；破了就触发正常的破盾（眩晕 2.5 秒 + 易伤 +30%） | `shieldCut.elite 0.35`、`boss 0.2`（首领按每段护盾）；半势 × 气势 / 100（50 → 17.5% / 10%） |
