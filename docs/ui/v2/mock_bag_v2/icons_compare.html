物品图标 · 路线对比

同一组 8 件物品；每格左为 74px 大图（详情页尺寸），右为 52px 实际格子（圆相 + 品级晕，品级只为展示五档：凡 / 灵 / 宝 / 仙 / 极，颜色取自 src/core/items.js RARITY）。
(a) 程序化水墨模板：每类一个"笔路模板"（几笔中线 + 几块淡彩轮廓），按物品参数换色、换变体；同一套笔触模型已用于立绘 portrait_gen。a1 / a2 只是渲染器不同：a1 输出矢量 SVG，a2 在 Canvas 上逐笔分层，加洇墨、飞白、纸纹颗粒、湿边。
(b) 3D 离屏渲染：three.js 程序建模 + 简化水墨后期（深度 / 折角墨线、墨—纸色阶），8 件烘焙 229 ms（RTX 3070）/ 580 ms（软渲染）。和世界同一笔性，但墨线没有起收笔，小尺寸下像"描边贴纸"。
(c) 墨拓剪影：由 (a) 的同一份模板自动推出：全部形状并成一块墨，细笔反刻成白线，加拍墨斑驳，只留一点朱。零额外绘制成本，48px 以下最清楚；但没有淡彩，靠剪影区分同类物品较难（青灵草 / 寒露草）。
现状：单字在圆相里；"青 / 苗 / 牙 / 玉"需要读字才能认物，同字物品（丹、玉、苗）无法区分 —— 这是"像文字游戏"的主因。单字可保留为图标右下的辅助角标或无障碍文字。
