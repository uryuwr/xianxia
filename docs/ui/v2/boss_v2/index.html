青牙 v2 · 首领界面

三个方向并排；状态在上方切换。设计说明：docs/design/boss_青牙_v2.md §8。底图为游戏内狼谷实景（凡人测试档，青牙用的还是旧的放大狼模型）。

A 卷首横轴推荐

屏幕顶部正中的长卷（首领战时天时条收起）。名牌在左、阶段字在右；护盾 = 气血上方一笔五行色；50% 处朱色"二"刻度；"威"一行从中间向两端长，越满越浓、近朱，满了断开盖"折"。生死信息最大最清楚，不挡战场。

B 题跋落款

屏幕底部、技能栏之上（魂系惯例）。名字竖写像落款，配一方"狼谷之主"朱印；眼睛在技能冷却和首领之间的距离最短，不挡上方的月与狼王石。缺点：和技能栏挤在一起，底部信息密。

单独打开

C 空间型

气血是青牙头顶的一弯"月牙"笔（呼应啸月），狼威画在它脚下——一圈圆相，越满裂纹越多，满了碎开；屏幕右缘留一道细竖笔兜底。最"叙事内"，但青牙跑远或贴边时生死信息偏小。可以只取"脚下裂纹圆相"给 A 做补充。

请选：① 方向 A / B / C（或 A + C 的脚下裂纹圆相）；② 狼威条显示出来（推荐，只狼式）还是藏起来只靠动作提示（Elden Ring 式）。
共用元素（与方向无关）：处决提示"F 斩"锚在青牙头顶（圆相收拢 = 剩余窗口）；转阶段横幅"二 · 啸月"；入场题签"第 N 次 · 上回削至 X%"；终结处决定格（留白、一笔、斩、朱印）。
