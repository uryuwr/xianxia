甲 · 剪影意象（推荐）：最"像地图"——阵环、妖面、箱、草一眼可辨，和物品、技能图标是一套笔性；颜色就是信息（朱 = 危险、金 = 撤离 / 宝、墨 = 已知之地）。代价：剪影之间要靠形状区分，15px 下"草 / 灵土 / 矿"需要颜色帮忙。
乙 · 印框意象：保留天机镜"盖印"的手感与远处醒目度（色块大），印色分类（金 = 撤离、朱 = 凶险、墨 = 地物）；但每个点都是一块方印，标记一多画面偏"贴满印章"，15px 下印内小图只剩轮廓。
丙 · 现状文字：读字即懂、零成本；但小尺寸要读字、同色字（妖 / 斩 / 箱）在墨色底图上易混，和储物袋、技能栏图标化后风格不再统一。
