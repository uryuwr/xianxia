## 1. 三个方向（草图）

三个方向用同一份示意存档（练气五层、炼器鼎一阶、灵石 260、铁精石凡 2 / 灵 3 / 宝 1），同一套物品签（圆相 + 水墨图标 + RARITY 品质晕），背景都把洞府 3D 画面压暗、虚化。每个方向都能点：切分类（装备 / 符箓 / 扩容 / 附灵 / 重铸 / 认主）、选配方、选主材品质看品质分布和属性预览、缺料看"何处可得"、炼制盖印、重铸揭示新旧词条、设施升级弹层。左下角有"示意开关"（补齐材料 / 已搬迁溪谷 / 得器方 / 重置）。

| 方向 | 文件 | 要点 | 长处 | 短处 |
|---|---|---|---|---|
| 一 · 册页 | `forge_v2/a_cepage.html` | 和灵泉 · 静室同一套装裱册页：左页器方目录 + 页脚炼器鼎栏；右页"炼成所得 / 炼制所需"两栏 + 页底朱印 | 与已认可的灵泉册页同构；信息密度最高；改动最小 | 物件感最弱；炼制的仪式感只靠一方印 |
| **二 · 鼎为中心（定稿）** | `forge_v2/b_ding.html` | 中间一尊写意鼎，材料签围鼎排布（主材在鼎口上方），左目录、右成品卡，鼎铭在鼎下（设施阶与升阶入口） | 仪式感最强，"投料入鼎"一眼懂；缺料直接画在鼎边；盖印的舞台最好 | 鼎占去中间一大块，两侧偏挤；材料多于 4 味时环形拥挤 |
| 三 · 器谱长卷 | `forge_v2/c_changjuan.html` | 横向手卷按类分段（自右向左），每个器方一列，卷下托纸展开详情 | 六类一卷看全；"展卷"切换有仪式感 | 自右向左与阅读习惯相反；卷内留白多、托纸挤 |

我当时的推荐是方向一（改动最小、与灵泉一致）；用户选了方向二，理由是仪式感和"一眼看懂投料"。下面是定稿规格。

### 2.2 成品卡（按分类）

- **装备**：成品签 + 名称（按最可能的品级着色）+ 部位与占格 + 描述；
  - **主材品质**：凡 / 灵 / 宝 / 仙四个主材签，写各有几份；"这一档至少一份、这一档及以下凑够数"才可选；下面一行"取用：宝 ×1 + 灵 ×2 · 取用中最好的一份定上限"。默认选最好的一档（和规则函数默认一致），选次的可以省下好材料；
  - **炼成品质**：凡灵宝仙极五档一条，会出的档按 RARITY 色晕开，概率写在下面（例：灵 75% / 宝 25%），"极"注"炼器不出"；
  - **属性预览**：可能出的每一档 × 基础属性，再和身上同部位比 ▲▼；随机词条条数（仙品 + 心法）；
  - 一句规则："炼成即已鉴定。辅材与灵草不影响品质。"
- **符箓**：一炉几张、仓库现有几张、描述。
- **扩容**：16 → 24 大字 + 格子点阵（新增的格子石绿）、前置条件。
- **附灵**：目标法剑（身上优先）、旧五行划去 → 新五行、"只留一条"的提醒。
- **重铸**：鼎口放着选中的装备，花费材料围在两侧、灵石在鼎下；卡上列词条（附灵词条锁定、心法词条标"价 ×2"），选一条 → 看花费 → 落印 → 鼎前浮出"重铸所得"纸签：原词条划去、新词条墨晕浮现 → "保留原词条 / 接受新词条"（花费不退；未定夺前不能切分类、切标签）。
- **认主**：鼎口放着选中的装备；代价（灵石 100、下一局气血上限 −10%）；一阶时显示"需二阶炼器鼎"和"看升阶条件 ›"。
- **锁定的器方**：显示原因与出处（例：尚无器方 · 器方《法衣》：青岚山外 · 山神庙地窖（首探必得））。

### 2.3 动效

- 落印：朱印按下缩 12% → 器物中心溅墨 + 品级印（"灵品""宝品"…，颜色按 RARITY）+ 品质色晕开 → 结果纸签浮出（基础属性 + 词条），点"收下"收起。仙品以上沿用原来的满屏墨涌。
- 重铸：落"重铸"印，0.4 秒后旧词条划去，0.6 秒后新词条浮现，1.1 秒后两个按钮出现。
- 升阶：弹层里落"二阶"金印，0.9 秒后合上。
- 炉火 / 鼎烟：三缕淡墨烟（CSS 动画，只动 transform / opacity）；能炼时烟快一些。

### 2.4 何处可得

点任意一味材料都会弹出小纸条：名称、有 / 需、**何处可得**（最多 4 条，从掉落表反查：Boss 首杀与遗府首探必得 → 妖兽专属掉落 → 精英妖丹 → 采集点 → 区域材料池常见 / 少见 / 灵光宝箱 → 药园可种）。例：铁精石 = "青岚山外 · 山神庙石傀掉落；矿脉采集；青岚山外 · 小怪 / 宝箱（常见）"。升阶弹层里缺的材料也带一条出处。

### 2.5 炼丹（同版式）

- 中间换成写意丹炉（沿用 `art_danlu.svg`），主药在左、辅药在右、灵泉水作药引在炉口上方（标"自取"）；灵草签按"先用次的 / 先用好的"实际会取到的品级着色。
- **火候一笔放在炉下**：按住 Space 或鼠标添火，朱色区间游走，指针、余几息、入火候比例、当前丹品实时显示；炉下火光随火候变亮，炉烟加快。火候逻辑仍是 `alchemy_game.js` 的 FireGame。
- 丹方卡：一炉 1 / 2 / 3 份、灵草"先用次的 / 先用好的"（火候带宽 × herbBand，写出倍数与品级）、丹品五档的门槛、熟练进度环；熟练后右下多一个"文火自成"（跳过火候直接得中品）。
- 炉铭：丹炉阶、火候带宽、可炼几方，"升二阶 ›"弹层写明二阶能炼哪些丹方。

### 2.6 药园

这次不动版式，只换成同一条顶栏（丹器房 · 炼丹 / 炼器 / 药园 + 灵石 + 回洞府），原右下的"回洞府"收起。

### 3.1 请洞府组补的函数（规则仍在 facilities.js，UI 现在用过渡写法）

1. **`forgeCraft(p, r, { mainQ })`**：按指定主材品级取用。现在 `forge_v2.js` 的 `craftAt()` 是过渡：选的不是最好一档时，把更好的主材从仓库数组里暂时挪开、调 `forgeCraft`、再放回（同步完成，不触发事件）。有了参数就删掉。
2. **`forgePreview(p, r, mainQ)` → 品质分布 `[凡, 灵, 宝, 仙, 极]`**：现在 UI 照规则复刻了"下限 = 鼎阶 − 1、25% 再升一品、最高仙品"（`forge_v2.js` 的 `UP`、`TOP`、`dist()`）。规则一改，两边要一起改，最好由 facilities.js 提供。
3. **`sourcesOf(id)`**：现在在 `src/ui/cave/sources.js`，只读数据；可以原样挪进 facilities.js，和 `usesOf` 放在一起。
4. （可选）"挂念"：草图里有"把缺的材料挂到出行准备 / 天机镜"的开关，需要存档字段与出行准备的显示，这次没做。

## 5. 器物重画：鼎与丹炉（已选定：甲 · 青铜方鼎 + 甲 · 八卦炉，已装入游戏）

> 起因：用户同意重画——旧的炼器鼎和丹炉都像"三足圆锅"，要画成两种不同的造型。
> 对比页：`docs/ui/v2/forge_v2/vessels.html`（file:// 可直接打开；截图都是游戏里真实的丹器房页面，只换了器物）；总览图：`docs/ui/v2/png/forge_v2_vessels.png`。

| 器物 | 变体 | 造型要点 |
|---|---|---|
| 炼器鼎 | **甲 · 青铜方鼎** | 方腹、双立耳、四角扉棱、饕餮纹带 + 雷纹、一行铭文带（泥金淡彩）、四只兽足（膝上兽面，前浓后淡）、铜锈石绿斑 |
| 炼器鼎 | **乙 · 青铜圆鼎** | 深腹、外撇高立耳、饕餮纹带、乳钉一周、三只蹄形兽足 |
| 丹炉 | **甲 · 八卦炉** | 圆腹三足（云头短足）、穹顶炉盖带气孔、宝珠钮上一缕丹烟、正中炉门透火光、腹下八卦纹 |
| 丹炉 | **乙 · 葫芦炉** | 莲座、上小下大两节、腰系朱绳（画面里的一点朱）、拱形炉门透火光、葫芦口吐丹烟 |

- **笔路**：四件都写成 `tools/vessels/vessels.js` 里的笔路模板，与物品图标同一个数据格式，由 `tools/icons/inkicons.js` 的纸性位图渲染器画（洇墨垫底、尾段飞白、没骨淡彩湿边、纸纹颗粒）；笔触模型与立绘生成器 `tools/portrait_gen.mjs` 同源。512×512 透明 png，一件约 220–320 KB，渲染 30–40ms（构建期一次）。
- **锚点**：每个模板带 `META`（器口 mouth、丹烟 smoke、炉门火光 fire、器底 base）。界面据此摆材料连线终点、动态丹烟、炉门火光（随火候变亮），换图不用改坐标。对比截图里八卦炉 / 葫芦炉的门内火光、钮上丹烟都已和炉体对上。
- **材料位扩到 6 味**：第一味（主材 / 药引）在器口上方，其余依次左右上、左右下；6 味时上方并排两味；灵石另放在鼎下。对比页可切"六味材料"看。`loop_forge_v2` 新增一项：6 味 + 灵石的材料签互不重叠、不压成品卡。
- **选定后怎么换**（一条命令，不用改代码）：
