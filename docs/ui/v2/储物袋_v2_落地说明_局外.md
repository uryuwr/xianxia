## 0. 共用组件（已就绪）

| 组件 | 用法 | 说明 |
|---|---|---|
| `itemTag(inst, { size, box, gap, count, cap, sel, disabled, sealed, sil, isNew, nofit, onClick })` | `import { itemTag, setTagState, tagReveal } from "../icons.js"` | 物品签：圆相 + 图标 + 品质晕 + 数量 + 仙 / 极角印；品级色取 RARITY；未鉴定自动墨拓剪影 |
| `setTagState(el, {...})` / `tagReveal(el)` | 鉴定揭晓：`setTagState(t, { sil: false }); tagReveal(t)` | 剪影 → 彩图，0.45s 墨晕开 |
| `iconEl(x, { box, sil, h })` | 只要图标（父元素 `position: relative`） | 详情大图、账册行首、匾额小图 |
| `kit.itemCell(inst, …)` | 老接口，已换成图标 | 账册行里现在就显示图标 |
| `packBag(items, cols, rows)`（`src/ui/bagui.js` 导出） | 返回 `{ placed: [{ it, c, r }], rows }` | 按顺序首次适配；放不下退回大件优先；博古架的龛位就用它 |
| 物品签尺寸 | 40（行内 / 账册）· 52（格子）· 74（详情） | 多格：`box: "2x1"` 横签、`"2x2"` 大签 |

样式规则（与局内纸笺一致）：不画格线，格位用四角"星点"；品级只靠圆相色 + 同色晕 + 名称字色 + 仙 / 极角印；名称字色用 RARITY 同色系压深（`#3b3a36 / #2c7d57 / #245f7f / #8a6a22 / #b8291a`，见 bagui.js `QN`）。

## 1. 撤离结算 · 宣纸手卷（`result.js`）

### 1.1 布局（1280×720 基准，`.mk-stage` 等比缩放）

结算没有时间压力，手卷铺满画面中下部；**卷上方留一条题头**放行书大字与四字印（沿用现有 `big` + `seal4`）。

| 区 | 位置（约） | 内容 |
|---|---|---|
| 题头 | x 60–1220, y 30–170 | 现有行书大字（满载而归 / 全身而退 / 身陨）+ 四字印 + 区域 · 第 N 次出行 |
| 手卷 | x 54–1226, y 190–690（宽 1172 高 500） | 两端卷轴木杆（赭墨竖笔 + 轴头圆点），上下青绫边（`--silk-blue` 淡带），卷心宣纸（`.ink-paper` 纸纹） |
| 卷首（右端引首） | 卷内 x 1080–1200 | 竖排"所得"大字 + 带回估价（泥金大字）+ 灵石数；身陨时竖排"遗失"朱字 |
| 段一 · 人 | 卷内 x 20–300 | 林墨半身立绘（`portrait()`）+ 四个装备位（剑 / 衣 / 佩 / 宝，`itemTag` size 52）+ 行囊余下；修为条（现有 `xp`）放在立绘下 |
| 段二 · 所得 | 卷内 x 320–760 | 带回物品按估价排序，`itemTag` size 52 摆成 6 列（大件按占格 2×1 / 2×2，用 `packBag` 排），每签下 `cap` 写名称；超过 24 格时这一段横向滚动（手卷往左展开），不竖滚 |
| 段三 · 账 | 卷内 x 780–1060 | 账目（用时、撤离点、斩妖、灵潮）、身陨损失明细、委托结果、首次所见竹简（现有 `firsts`）、机缘刻度 |
| 卷尾 | 卷内左下 | "再出行"次要按钮 + "回府"朱印（现有） |

段与段之间只用一道淡墨竖笔（`.ink-vrule`）分隔，不画框。

### 1.2 交互与演出

1. **展卷**：进入时卷心 `clip-path` 从中间向两边展开（风格指南 §9 `fx-unroll`，0.8s）；`prefers-reduced-motion` 时直接出现。
2. **鉴定揭晓**（替换现有"整行换掉"的做法）：未鉴定物品先以 `itemTag(inst)`（自动剪影 + 呼吸晕）摆进段二；按顺序每 0.65s 揭一件：`identifyItem` 后 `setTagState(t, { sil: false })` + `tagReveal(t)`，同时签下 `cap` 换成真名；仙品以上沿用 `surge` 墨色翻涌 + `ctx.rig.shake(0.25)`。
3. **悬停签**：浮出窄纸条（`.ink-tip`）：名称（品级色）、品级 · 类别 · 占格、估价、词条（装备）、"可在灵泉炼化 / 仓库化灵"一句去向提示（`COPY.lingzhiResult`）。
4. **遗失**：身陨时段二末尾加一行"遗失 N 件"，遗失物签 `disabled: true`（整体淡 + 去色），右上压一方朱文小印"失"。
5. 键：Enter / 点朱印 = 回府；R = 再出行（与现有按钮同功能）。

### 1.3 测试建议（loop_flow 结算段）

- `.mk-result .mk-tok` 数 = `R.kept.length (+ R.lost.length)`；未鉴定签初始带 `.is-unid`，揭晓后去掉。
- 揭晓计数沿用 `S.revealCount`。
- 现有断言里按 `.ledger .ink-row` 数行的，改成按 `.mk-tok` 数。

## 2. 洞府仓库 · 博古架（`panels.js` 的 `storage()`）

### 2.1 布局

| 区 | 位置（约） | 内容 |
|---|---|---|
| 匾额 | 架顶 x 40–600, y 30–90 | 行书"仓库" + 仓中估价（泥金）+ 灵石数；右侧分类页签（全部 / 装备 / 材料 / 丹符 / 功法，沿用 `CATS`） |
| 多宝阁 | x 40–600, y 100–560 | 赭墨笔触画的木框（外框一笔赭石粗笔，隔板一笔细笔）；**龛 = `packBag` 的摆放结果**：每件物品一个龛，龛的大小 = 占格（1×1 小格 / 2×1 长龛 / 2×2 大龛）；龛内上暗下亮（一抹淡墨由上往下晕），龛底一笔淡墨投影；物品签 `itemTag` size 52 |
| 身上 | 架右上 x 620–860 | 现有"身上"四位 + 半身立绘（沿用 `equip`），签换成 `itemTag` |
| 详情浮签 | x 880–1240 | 现有 `st-detail`，顶部大图换成 `itemTag(cur, { size: 74, box: "1x1" })` |
| 底部 | 架下 | 批量化灵条（现有 `cap`）+ 键位 |

仓库容量无限（`capacity = Infinity`）：阁子列数固定 8，**行数按 `packBag` 结果增长**，超出可视高度时整阁在框内竖向滚动（滚动的是阁内，不是页面）；每 4 行画一道横隔板（更粗的赭笔），像多宝阁的层。

### 2.2 交互

1. **不自动重排**（方案里"重排抖动"的风险）：入库、化灵、装备后只在原位置空出或补入，顺序 = `p.storage.items` 顺序；**R 键 / "归置"按钮**才按"类别 → 品级 → 估价"重排一次（改 `items` 顺序后重绘），重排时龛形用 0.25s 透明度过渡。
2. **拖拽**：拖一件到另一件前 = 调整顺序（与局内纸笺同一套：`.drop-before` 朱色竖笔提示）；拖到"身上"某位 = 装备（`F.equip`）；拖到化灵区 = 加入批量化灵。
3. **批量化灵**：多选时被选签 `setTagState(t, { sel: true })`（朱圆相），未选且不可化灵（关键物品、灵石）的签 `disabled`。
4. **鉴定**：仓库里鉴定（现有"鉴定"按钮）后对该签 `setTagState(t, { sil: false }); tagReveal(t)`，再盖"鉴"印（现有 `lastIdent` 演出保留）。
5. **分类页签**：切页签时只是过滤 `items` 后重新 `packBag`；空页签显示"空空如也"。
