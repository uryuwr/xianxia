一园，两种读法

药园从丹器房独立。只比较打开后的操作界面，不改变场景中的 3D 方块田格和围栏。
所有操作都在内存演示，不读写真实存档；本阶段不落地游戏正式 UI。建议打开单页体验。

预览内也能点击；选中方案仅在本页记录，不提交游戏。

A · 园圃总览 推荐

左边看全园，右边只办选中这一畦的事。空地选苗，生长看出行次数，成熟手动收。五畦状态始终可见，照看小园最直接。

取舍　种子区较紧凑，每年份每页两种；通过翻页而非内部滚动容纳多种草苗。

B · 药圃册页 大区分页

巡园、移栽、采收、扩建各占一整页。移栽页给种子更大的阅读区，每年份每页四种；不把内容塞进小浮窗里滚动。

取舍　一次只看一个任务，字与图更舒展；移栽时不同时看到全园，任务切换多一步。

这轮请选什么

一、偏好全园常见的 A，还是任务分开的 B？
二、种子每页两种，还是四种，哪种密度更舒服？
三、保留「全部采收」在右下角，还是更倾向只进采收页操作？

默认建议：A 总览 + 年份分页 + 右下全部采收。种子选择、扩建条件与采收去向在两案中完全一致。

不变的边界

  • 等级基础地块 1 / 2 / 3 / 4；搬迁且 Lv＞0 加 1，最多 5 块，不把 8 个模型插槽当作可开地。
  • 按出行次数成长；成熟留地，手动采收进入仓库。
  • F 统一打开药园，不在场景直接采收；无自动播种、新肥料或真实存档访问。
  • 年份分页，禁止小面板内滚动；园务说明的砚台翻页支持键盘。
