## 1. 问题（改前截图里看到的）

| # | 现象 | 为什么丑 / 为什么不好用 |
|---|---|---|
| P1 | 灵草是一小撮**自发光的荧光绿**平面叶，头顶一根绿色光柱 | 水墨后期会把高饱和色原样保留，结果整幅淡彩画里只有它是"塑料绿"；夜里它是全场最亮的东西，像霓虹灯。叶片是等宽长条，没有笔意，也没有墨线。 |
| P2 | 灵草、矿脉、灵光点、何首乌这类高价值灵草都是"一个模型 + 一根同样的光柱" | 品阶看不出来。千年何首乌（380 灵值）和青灵草（4 灵值）远看一样；灵光点的光柱是白 / 青色，反而像普通灵草。 |
| P3 | 交互提示是屏幕底部中间的一条通知笔"F · 青灵草" | 离物件很远，眼睛要在草和屏幕底部之间来回跳；它压在技能栏上方，读起来像系统通知；只有字母"F"，没有动作；所有交互物都一样。 |
| P4 | 采下 / 开箱是"一帧消失" + 几个绿点 | 没有"手"的感觉；物件直接没了。宝箱打开后**整只消失**（关卡 consume 只是把模型藏起来），地上留下一个看不见的碰撞体。 |
| P5 | 掉落字牌是一枚纸白圆片 + 1 像素圆圈 | 像贴在世界里的按钮；夜里纸白圆片反而刺眼。 |
| P6 | 拾取只在左下拾取流里多一行半透明小字 | 普通灵草不弹提示，物品"去哪了"没有交代；拾取流在复杂背景上对比度不够。 |
| P7 | 储物袋里灵草格就是一个灰字（凡品 = 灰），数量在右上角 10px 淡墨 | 灵草 / 矿石 / 妖兽材料长得一模一样；数量位置和指南 §5.6（右下、纸色描边）不一致。 |
| P8 | 宝箱：普通箱是一个褐色方块，夜明宝箱是兜底的 Lambert 方盒（夜里几乎看不见），灵光箱只是多一根金柱 | 三档分不清；和关卡里的写意石、木、屋不是一套。 |

## 2. 方案总览：一套"交互物"表现组件

所有交互物（灵草、矿脉、灵光点、宝箱、撤离点、遗落储物袋、奇遇）走同一套四段式：

```
远看：物件本身 + 脚下一笔圆相（产出物的品质色）+ 灵气微粒 / 光柱（只有块根、灵光点、灵光 / 夜明宝箱）
靠近：圆相"聚焦"（墨变浓、圈收紧）+ 物件上方的「F 印 · 动词 · 名称」
读条：一笔圆相按进度画出（运笔时机 = 一段泥金弧）；被打断 = 转朱、抖两下、钤"断"
完成：圆相一笔收拢 + 钤一方小印（采 / 启）→ 掉落字牌从物件里抛出 → 拾取时飞入储物袋 + 原处浮起"名称 ×数量"
```

### 2.1 世界里的造型（`src/world/markers.js`）

三层，各层独立：

1. **写意物件**：toon 着色 + 后期墨线，**不再自发光**。叶片改成两头尖、向外弯、中脉微折的柳叶形（toon 下有明暗两面），轻微随风（`wind`）。叶色比周围的墨色草丛浅一档（石绿偏淡），所以不靠发光也能从草里跳出来。每种灵草保留一个小而亮的"灵点"（青灵草的玉色灵芽、凝露花花心的露、赤炎果的红果、寒露草叶尖的霜），低饱和、带一点自发光，夜里仍看得见。
2. **脚下一笔圆相**（指南 §6.1"可交互物脚下的淡墨圈"）：着色器画的一笔——起笔顿、绕约 320°、收笔飞白、留缺口；白天是"品阶色压暗的墨线 + 纸色外晕"（纸白地面和焦墨地面都清楚，指南 §8.2 的双层结构），**入夜**（关卡把 `uK` 放大到约 1.7）自动转成"灯色线 + 品阶色晕"，笔也更粗；带 2.4s 呼吸。贴地平面关掉深度测试，坡地、河岸不会把圈吃掉。
3. **灵气微粒 / 光柱**：加色小点缓缓上升、绕根部轻转（全在顶点着色器里算，CPU 不更新）；入夜更大更亮。**光柱只留给何首乌（块根）、灵光点、灵光箱、夜明箱**——远处的信标只给值得绕路的东西。

### 2.2 品质与形制（v1.1：颜色统一用 RARITY）

> 全游戏只有一套品级：`src/core/items.js` 的 `RARITY`（凡品 / 灵品 / 宝品 / 仙品 / 极品）及其颜色。采集点、宝箱的圈色、光柱色、微粒色、F 提示名称色**一律按该点产出物的品质**从 RARITY 推导（`src/fx/rarity_tint.js`：降饱和 25%、压暗作墨线 / 文字、提亮作夜里的灯色）；不另起档位名，不写死色值。
> 形制（大小、微粒多少、有无光柱、双圈）按"点的种类"区分，只在代码里用，不显示名字。去饱和也分得出：圈的数量 + 光柱有无 + 微粒多少。

| 形制 | 用于 | 品质（取产出物） | 圆相半径 | 微粒 | 光柱 |
|---|---|---|---|---|---|
| `herb` 灵草丛 | 青灵草、凝露花、寒露草 | 凡品 | 0.95 | 7 | — |
| `bush` 灌木 / 藤 | 赤炎果、紫藤 | 凡品 | 1.05 | 10 | — |
| `root` 块根 | 千年何首乌 | 宝品 | 1.3 | 16 | 3.2 m |
| `ore` 矿脉 | 铁精石、灵土 | 凡品 | 1.25 | 4 | — |
| `glow` 灵光点 | 狼王遗骨（灵品）、灵蚌珠 / 水灵玉（宝品）… | 按宝物 | 1.7，**双圈**（内圈缓转） | 24 | 5.5 m |
| `chest` 普通宝箱 | — | 凡品 | 1.05 | — | — |
| 灵光宝箱（`glow` 形制） | — | 宝品 | 1.7 双圈 | 24 | 5.5 m |
| `night` 夜明宝箱 | — | 仙品 | 1.3 | 12 | 3.2 m |

宝箱的颜色按"该档宝箱常见的最高品质"，开箱前不剧透具体内容。F 提示：灵光点带一方"灵光"两字印（地点类型），产出宝品及以上的采集点带一方品质名印（如"宝品"），印色都取 RARITY；其余不写档位。

### 2.3 宝箱（`chestMarker(tier, {opened, bare, dim})`）

- 三档：**普通**（赭墨木箱 + 铁箍）、**灵光**（焦墨漆箱 + 泥金包角 + 泥金箍）、**夜明**（黛青漆箱 + 月白箍，箍带一点自发光，入夜仍亮）。箱身 + 底座 + 半圆拱盖，箱盖挂在后沿的转轴上（`userData.lid`）。
- 关卡里的箱子和兜底箱子（夜明箱、样张地图）用同一个函数，不再有 Lambert 方盒。
- **开箱**：`level.consume` 把关卡模型藏起来的同一帧，在原位放一只"已开启"的箱子（木色压暗、箍不再发光），箱盖 0.5s 回弹着掀开（−1.95 rad），箱身轻跳一下；一团焦墨从箱口慢慢涌出、上浮；光柱和圆相按 RARITY 着色；钤一方"启"印。**v1.1（搜取）**：宝箱改成容器，开箱即打开格子窗、东西不再抛到地上，所以开箱时还不知道品质，光柱 / 圆相 / 印都用凡品色（不剧透）；品质在格子揭示时才出现，见 `docs/ui/v2/搜取_v1.md`。
- **已开启**：箱子留在原地，盖开着、无光无圈（原来的碰撞体仍在，现在看得见是什么挡路）。

### 2.4 交互提示（`src/ui/gather_ui.js` + `gather.css`）

```
 (F) 采  青灵草  [灵光]
           ‾‾‾‾‾‾‾ ← 一笔同色短划（0.36s 扫入）
           ╵       ← 指向物件的一笔短竖（上浓下淡）
```

- 贴在物件上方（灵草 1.25 m、宝箱 1.15 m、灵光 1.9 m、撤离阵 2.4 m），跟着物件走，不再放在屏幕底部。
- **F 键是一方焦墨圆印**（30px，−5°，纸色黑体"F"），不是方框键帽；灵光物换泥金印。
- 动词一个楷书大字（25px 焦墨）：采（灵草 / 矿脉）· 开（宝箱）· 撤（撤离点）· 取（遗落储物袋）· 探（奇遇）；外部标记可以给 `m.verb` 自定义。
- 名称楷书 20px（灵光 22px），采集点 / 宝箱按品质（RARITY）着色，其他交互物按种类；文案里的括注（"开始撤离""灵光"）拆成小字或印。
- 底衬是一团墨晕（`.ink-wash`，α .84），没有框。整个提示按 `--mk-scale` 等比缩放。
- **所有交互物共用**：撤离点、遗落储物袋、奇遇也用这个提示；屏幕底部的旧提示只留给"非交互物"的文字（例如灵雨读条、储物袋已满）。文字仍取 `run.hint`（流程模块的文案），表现层不改文案。
- 靠近时物件脚下的圆相同步"聚焦"（`setFocus` 0→1，0.17s）：墨变浓、圈收紧、微粒加快。
- 读条中或刚被打断时，提示先收起，让圆相读条说话。

### 2.5 读条：运笔圆相

- 一笔圆相（指南 `.ink-ring`，104px）按进度画出，石绿；**运笔时机**（设计文档 §4.3"笔锋过高亮区松手得完整品"）是外圈一段泥金弧。
- 上方"采集 / 开箱 + 剩余息数"（行书数字），下方一行小字说明（"笔锋过金处松手 · 得完整品"/"受击或走开即断"）。
- **被打断**：圆相转朱、抖两下（0.32s × 2），中间钤一方朱色圆印"断"，下方朱字"采集被打断 · 再按 F 重来"，0.95s 后淡出。
- ⚠ **玩法上采集和开箱目前是即时的**（玩法评审 G12：常见灵草免小游戏；本次按要求不改逻辑与数值）。读条组件已做好，按下面的约定接上即可显示：
  - `run.gathering = { mark, t, need, sweet?: [a, b] }`（开箱可用 `run.opening`，或 `run.channel.kind === "gather" | "chest"` 且带 `mark`），`t / need` 是进度，`sweet` 是运笔金弧的起止（0~1）。
  - 读条中途 `run.gathering` 消失而 `mark` 仍在 → 自动按"打断"表现；也可以 `run.emit("gather:cancel", { reason })` 指定原因。
  - 注意：若复用 `run.channel`，`runhud` 里撤离读条的"撤离中"圆相也会出现，需要流程模块按 `kind` 排除。

### 2.6 完成反馈

| 时刻 | 表现 |
|---|---|
| 采下 | 脚下圆相 0.32s 一笔收拢（从缺口处画满）→ 外扩 18% 淡出；浅色灵气微粒向上散、几点焦墨落下；原处钤一方 40px 圆印"采"（印色 = 产出物品质色），盖印动效同指南 §9。 |
| 开箱 | 见 §2.3。 |
| 掉落抛出 | 地上字牌从草丛 / 箱口（高 0.6–0.75 m）沿抛物线落到落点，0.42–0.54s，多件依次错开 0.06s。只改贴图位置，**拾取判定仍按落点**。 |
| 拾取 | 物品圆相格（`kit.itemCell`，50px，品质晕）沿弧线 0.72s 飞向右上"储物袋"计数，身后 6 个同品质色墨点依次出现、淡去；到达时灵值与占格数字一跳（1→1.12→1）。原处浮起"名称 ×数量"（楷书 21px，按品质着色，凡 = 浓墨，仙 / 极加一方小角印），1.6s 上浮 30px 淡出；同时拾取多件时逐行错开。只对采集 / 开箱掉出的物品飞（战斗掉落仍只进拾取流，不打扰战斗）。 |
| 地上字牌 | 改成"一笔圆相（先纸色外描、再墨或品质色）+ 同色淡晕 + 楷书字（纸色描边）"，128px 贴图；书法字体载入后原地重画。 |

### 2.7 储物袋格（指南 §5.6 / §5.7 / §11）

- 字仍是图标（物品定义的 `glyph`），字后面压一个 **2–4 笔的写意小图**，按品类着色：灵草 = 一枝三叶（石绿 α .34）、矿石 = 三棱晶 + 一道地（黛 α .3）、灵物 = 一笔圆光 + 三点（泥金 α .38）。图是 SVG 填色路径（带起收笔的叶形），不是线性图标。
- 品质：字色 + 淡晕（凡 浓墨、灵 石绿、宝 石青、仙 泥金 + 角印、极 朱）。
- 数量：右下角黑体 11px 粗、纸色描边（原来是右上 10px 淡墨）。
- 未鉴定：字换"？"，轻模糊 0.8px，淡晕 2.4s 呼吸，不显示品类小图。
- 同一套也用在 `kit.itemCell`（拾取流、锦囊、脚下、飞行中的格子）：格子带 `g-<cat>` 类名。

### 2.8 配色与尺寸速查

| 项 | 值 |
|---|---|
| 圆相线（白天） | 品质色压暗与品质色各半；α .62，聚焦 1.0 |
| 圆相外晕（白天） | 纸色 (0.965, 0.945, 0.90)，α .34，聚焦 .64 |
| 圆相（夜里） | 线 = 品质色提亮 62%（灯色），外晕 = 品质色、α 降 55%，笔粗 +40% |
| 圆相笔宽 | 起笔 0.10 r → 收笔 0.032 r，起笔顿 +70%，缺口 11%（灵光内圈缺口 38%） |
| 微粒 | 屏幕约 5–8px（随距离），寿命 3–8s，上升高度 1.0–2.6 m |
| F 印 | 30px 焦墨圆印，−5° |
| 动词 / 名称 | 楷书 25px / 20px（灵光 22px） |
| 读条圆相 | 104px；石绿；运笔弧泥金；打断朱 + 44px"断"印 |
| 采 / 启 印 | 40px 圆印 |
| 飞行格 | 50px → 0.55 倍 |
| 拾取字 | 楷书 21px + 黑体 13px 数量 |

性能：圆相与微粒都是一张平面 / 一组点，全部在着色器里动；DOM 只有一个提示、一个读条（常驻，改 transform / CSS 变量）和短命的印、飞行格、墨点、拾取字（≤ 1.7s 自删）。不用全屏 filter，不用 mix-blend-mode。
