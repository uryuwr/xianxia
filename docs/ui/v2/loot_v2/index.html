搜取 v2 · 物品签格子与"先露形、后显色"

格子改用储物袋同一种物品签（52px，一笔圆相 + 图标 + 品质晕 + 数量 + 仙 / 极角印），最多 4 列、多行。每格的探查时长不变（凡 0.35 / 灵 0.5 / 宝 0.8 / 仙 1.2 / 极 1.8 秒 × 100/(100+神识)）， 只把过程分成两段：神识一笔走到 62% 时墨封化开、露出墨拓剪影（"探得其形"）；走满一圈换成本色、外圈晕开品质色（"辨得其色"），名称在宣纸底部浮出 1.2 秒。仙品最后顿一下泛金，极品朱金迸开。 神识 ≥ 40：墨封下隐约浮现剪影轮廓（预感）。未鉴定：揭示后保持剪影 + "？"。悬停 / 选中显示"名称 · 品质 · ×数量"。取物时飞向储物袋的就是这张物品签。
