# 墨途 · UI 风格指南 v1（淡彩水墨）

> 适用范围：所有界面（标题、洞府、出行准备、局内 HUD、储物袋、结算、炼丹、境界、天机镜）、光标与地面技能预览。
> 配套实现：`docs/ui/v2/kit/`（CSS 套件、程序化笔触、字体子集、立绘、光标）；示意图：`docs/ui/v2/*.html` → `docs/ui/v2/png/`；组件总览：`docs/ui/v2/kit/gallery.html` → `docs/ui/v2/png/gallery.png`。
> 生成脚本：`tools/ui_kit_gen.mjs`（笔触形状）、`tools/ui_fonts.mjs`（书法字子集）、`tools/portrait_gen.mjs`（立绘 / 丹炉）、`tools/cursor_gen.mjs`（光标）、`tools/mockshot_v2.mjs`（截图与总览拼图）。

---

## 0. 一句话

**不画方框。** 界面是"画在纸上的东西"：边界靠纸边、墨晕和一笔，层次靠墨色浓淡与留白，强调只用一点朱砂（或石青、石绿、泥金）。

v1 示意图的问题：所有信息都装在圆角矩形里，矩形套矩形；颜色是"米色 + 深灰"的网页后台配色，和 3D 画面的水墨后处理是两套语言；按钮、格子、进度条都是几何图形，看不到"笔"。

## 1. 调研要点（结论先行，出处见文末）

| # | 观察 | 对我们的结论 |
|---|---|---|
| R1 | 《大神》（Ōkami）的水墨感来自两点：**墨色浓淡**（轮廓比内部更浓）和**笔画粗细变化**；它不是"加一层宣纸贴图"。 | 每个 UI 形状都要有浓淡与提按：进度条是一笔（起笔顿、收笔出锋、飞白），物品格是一笔圆相，不是均匀描边的几何图形。 |
| R2 | 现成的水墨 UI 套件（Ink & Brush Dojo）收敛到同几种形状：**笔触血条（带掉血余迹）、圆相头像框、朱红印章、手写大字**。 | 这几种形状说明品类里已经形成共识，我们照这个方向做，但全部程序化生成（见 §4），不靠贴图。 |
| R3 | 《对马岛之魂》：用"风"代替航点，HUD 按情境出现；但玩家也抱怨血条太小、看不清。 | 氛围信息走**叙事内**（天机镜 = 一面铜镜、洞府设施 = 挂在画里的签），**生死信息**（气血、真气、冷却、撤离读条）必须走叙事外 HUD，并且够大、够清楚。 |
| R4 | Fagerholt & Lorentzon 的四象限（叙事内 / 叙事外 × 空间 / 非空间），建议"在不伤害一致性的前提下尽量用叙事内"。 | 分类见 §6.1：撤离读条 = 空间型（画在主角脚下的一笔圆相），地面技能预览 = 空间型，小地图 = 叙事内（铜镜），其余为 HUD。 |
| R5 | 网易《一梦江湖》：从水墨原画里**取色**定主色与辅助色；有意用"残缺"（半烧的纸表示限时将尽）和留白激发想象。另一篇文章提醒：水墨风混入拟物渐变，整体风格会变脏。 | 色板从游戏画面取（§3）；状态可以用"纸被烧 / 墨被晕开"表达；**禁止**拟物高光、金属渐变、玻璃质感、斜面浮雕。 |
| R6 | 留白在国画里是意境，在界面上是信息层级：功能界面少留白，氛围界面多留白。 | 标题、结算、境界多留白；储物袋、炼丹这类操作界面留白要克制，信息密度优先。 |
| R7 | 装裱与卷轴有固定结构：立轴（天头、画心、地头、惊燕、轴头）、手卷（引首在右、画心、拖尾/跋在左，从右向左读）。 | 大面板借这些结构：境界 = 册页、天机镜 = 手卷（卷名在右侧引首，图例在左侧跋）、出行去处 = 扇面、丹方 = 竹简。 |
| R8 | 印章分朱文（红字白底）和白文（白字红底）；落款处钤印。 | 朱印 = "下决心"的动作（启程、开炉、突破、回府）；白文印 = 状态或标签（二境、风险、天机）；朱文印（只有边框）= 强敌、警示。印的边缘必须残缺不齐，不能是干净方块。 |
| R9 | Xbox 无障碍规范 XAG 101：关键信息文字对比度 ≥ 4.5:1，按背景里**对比最差的那一块**来量；半透明底衬要按最坏情况验证。Game Accessibility Guidelines：尽量放在纯色高对比底上，做不到就加明显的描边或阴影。 | 45° 俯视画面纸白与焦墨交错，是"最坏背景"。HUD 文字一律放在**墨晕底衬**（不规则的淡纸色晕团，α≈0.85–0.9）上，数字加纸色外描（§7）。 |
| R10 | 撤离类游戏（塔科夫、Dark and Darker）：格子背包、按占格算价值；玩家需要"每格值多少"，官方 UI 往往没给，只能靠第三方工具算。 | 储物袋与 HUD 一直显示**袋中灵值**和占格；结算按价值排序；未鉴定物用"？"加呼吸晕，不剧透价值。 |

## 2. 设计原则

1. **留白**：先决定哪里不放东西。HUD 只贴四边和四角，画面中心 60% 区域只留给"空间型"提示（撤离圆相、技能预览）。全屏界面至少三分之一是纸面。
2. **以墨分层**（焦、浓、重、淡、清五色）：标题、数字用焦或浓墨，标签用重墨，说明用淡墨，分隔线和空格用清墨。**不靠描边框分层。**
3. **克制的点色**：朱砂只给"你"和"下决心的动作"（主角标记、确认印、危险）；石青、石绿、泥金分别对应灵气/宝品、草木/灵品/回复、仙品/灵值。同一屏里大面积的彩色不超过两处。
4. **动静**：静止时像一幅画；变化时像墨在纸上走：出现 = 墨晕开，进度 = 笔锋扫过，确认 = 盖印，地图 = 展卷（§9）。
5. **一套形状走天下**：所有笔触、圆相、印章、纸边都是同一组程序化形状（mask），只换颜色和尺寸。新界面不允许另起一套边框。
6. **不出现低模 3D 人偶**：界面里的人物一律用 2D 写意立绘或剪影（§5.12）。

## 3. 设计令牌（`kit/ink-ui.css` 第 1 节）

### 3.1 颜色

| 令牌 | 值 | 用途 |
|---|---|---|
| `--paper` / `--paper-hi` / `--paper-lo` | #ece6d6 / #f5f0e3 / #e1d8c2 | 纸面、浮签、旧纸 |
| `--ink-jiao` 焦 | rgba(21,24,27,.92) | 大标题、主按钮底、鼎足 |
| `--ink-nong` 浓 | .78 | 标题、数值、物品字 |
| `--ink-zhong` 重 | .58 | 标签、次要文字 |
| `--ink-dan` 淡 | .36 | 说明、禁用、次按钮下划 |
| `--ink-qing` 清 | .16 | 分隔、空槽、进度底 |
| `--zhu` 朱砂 | #b8291a | 确认印、主角、危险、HP |
| `--shiqing` 石青 | #2f7fa8 | 真气、宝品、水 |
| `--shilv` 石绿 | #3f9a6e | 灵品、草木、回复、"足" |
| `--nijin` 泥金 | #b8923a | 仙品、灵值、修为 |
| `--zhe` 赭石 / `--dai` 黛 | #9a6a32 / #3a4a52 | 土、木器 / 冷暗部 |

**品质（凡 / 灵 / 宝 / 仙 / 极）** = 淡墨 / 石绿 / 石青 / 泥金 / 泥金 + 朱印角标。品质只体现在**圆相颜色 + 一团同色淡晕 + 字色**上，不做彩色边框，也不做发光描边。

### 3.2 字体

| 层级 | 字体 | 字号（1280×720 基准） | 用于 |
|---|---|---|---|
| 大字 | 志莽行书 Zhi Mang Xing（行书） | 64–150 | 游戏名、结算大字、区域名、竖排大标题 |
| 标题 / 按钮 / 物品字 | 马善政楷书 Ma Shan Zheng | 17–44 | 面板标题、按钮、标签页、格子里的单字、大数字 |
| 标签 | 系统楷体（KaiTi / STKaiti） | 13–18 | 键值对的"键"、题跋、对白 |
| 小字 / 数字 | 微软雅黑 / 苹方 / Noto Sans CJK | 10–13 | 说明、倒计时、数量、热键 |

- 两种书法字都是 SIL OFL 开源字体，**按界面实际用到的字子集化**成 woff2 并 base64 内嵌（`tools/ui_fonts.mjs`；当前 588 字，两套共约 480 KB base64，转成独立 woff2 文件约 360 KB）。游戏里也照此处理：构建时从 UI 文案收集字表，只打包用到的字。
- 书法字只用在 ≥17px 的地方；12px 以下一律用黑体（书法字小了糊）。
- 数字：大数字（灵值、结算总额）用楷书显得有手写感；表格里的小数字用黑体 `tabular-nums` 对齐。
- 竖排（`writing-mode: vertical-rl`）只用于短标题、题跋、印文、竹简、挂签。**正文、列表、数值不竖排。**

### 3.3 尺寸与间距

`--t-xxl 72 / --t-xl 44 / --t-l 28 / --t-m 20 / --t-s 15 / --t-xs 12`。间距不设格栅系统，用"一个字宽"作单位（16–20px）：同组元素间隔半字到一字，组与组之间至少两字。

## 4. 形状语言（`tools/ui_kit_gen.mjs` → `kit/strokes.css`）

所有形状都由脚本用固定随机种子生成 SVG，再以 data URI 写进 CSS 变量，统一当作 `mask-image` 用。**形状只决定透明度，颜色由 `background` 决定**，所以一套形状可以染任何颜色，也不需要图片文件。

| 形状 | 变量 | 用途 |
|---|---|---|
| 横笔（起笔顿、收笔出锋、尾段飞白、露锋毫毛） | `--ink-stroke-1/2/3`、`-thin`、`-bar`、`-band`、`-v` | 下划、分隔、进度条、主按钮底、通知条、竖向书签 |
| 圆相（一笔画圆，起笔重，绕约 320°，留缺口） | `--ink-enso-1/2/3`、`-full` | 物品格、技能格、圆形读条、选中圈、地图上的"你" |
| 印章（圆角方印 / 圆印 / 椭圆印 / 朱文边框，边缘残缺） | `--ink-seal-sq/sq2/round/oval/frame/frame-round` | 确认按钮、状态印、品质角标、地图标记 |
| 墨点 | `--ink-splash-1/2` | 冲刺点数、指针头、装饰 |
| 宣纸毛边 | `--ink-deckle-1/2/slip` | 所有面板、浮签、挂签 |
| 墨晕（位移 + 模糊的淡墨团） | `--ink-wash-1/2/round` | HUD 底衬、立绘背后的灵气 |
| 扇面 / 卷云 / 米字格 / 田字格 | `--ink-fan`、`--ink-cloud`、`--ink-grid-mi/tian` | 去处选择、角饰、储物袋底纹 |
| 纸纹 / 纤维 / 云气（有色纹理） | `--ink-tex-paper/fiber/cloud` | 舞台、纸面底色 |

规则：

- **不允许**：圆角矩形边框、1px 实线描边框、内阴影立体按钮、渐变高光、玻璃模糊。
- 同一屏里同一形状重复出现时轮换变体（`nth-child` 选 `enso-1/2/3`），避免"复制粘贴感"。
- 纸张阴影必须跟着毛边走：阴影加在 `.ink-sheet` 外层（CSS 的执行顺序是 filter → clip → mask，所以 filter 必须放在被 mask 元素的父级上）。

## 5. 组件规格（`kit/ink-ui.css`，效果见 gallery.png）

### 5.1 面板 `.ink-paper`
一张毛边宣纸（`<section class="ink-paper">`，`ink-ui.js` 自动补 `.ink-sheet` 纸张层）。变体：`.alt`（另一种纸边）、`.slip`（窄纸条）、`.sajin`（洒金笺，只给稀有物 / 首次发现）、`.tilt-l/.tilt-r`（±1° 倾斜，一屏最多一张）。内边距 26/30。纸上不再套框。
大面板按场合选：**装裱** `.ink-mount`（境界、鉴宝）、**手卷** `.ink-scroll.h`（天机镜）、**扇面** `.ink-fan`（去处）、**竹简** `.ink-slips`（丹方、首次所见）、**挂签** `.ink-tag`（洞府设施、地图标注）。

### 5.2 标题
`.ink-title`（楷书 28/44）＋右侧一道 `.ink-rule` 淡墨横笔；需要强调时加一方白文小印（如"二阶"）。全屏界面的主标题可用竖排行书大字（`.ink-splash` + `writing-mode`），配一列题跋 `.ink-tiba`。

### 5.3 按钮（三级）
| 级别 | 样式 | 用于 |
|---|---|---|
| 次要 `.ink-btn` | 只有字，下面一道淡墨笔，悬停时笔变浓、拉满 | 返回、取消、切换 |
| 主要 `.ink-btn.primary` | 一道焦墨宽笔作底，纸色字；悬停时笔变朱 | 一屏最多一个：放入锦囊、确认 |
| 决断 `.ink-seal-btn` | 一方朱印（92px，−4°），竖排两字 | 启程、开炉、突破、回府、出行 |

状态：悬停（墨变浓 / 印放大 4%、转正 2°）、按下（印缩 6%，像落印）、禁用（字退成清墨；印退成淡墨灰）。热键用小号黑体加底线（`.key`），跟在按钮后面。

### 5.4 标签页
横向 `.ink-tabs`：字 + 中点分隔，选中项字转焦墨、下面一道朱笔；未解锁项清墨。竖向 `.ink-vtabs`：书签式竖排，选中项右侧一道朱色竖笔。

### 5.5 列表 `.ink-list / .ink-row`
不画格子。行与行之间是一道很淡的短笔（只到行宽的 70%）；键（楷体重墨）在左，值（楷书浓墨）右对齐；当前行左侧一个朱点。

### 5.6 物品格 `.ink-slot`
一笔圆相 + 单字（物品的代表字，楷书）+ 右下角数量（黑体，加纸色描边）+ 同品质色的一团淡晕。
- 品质：`q-fan / q-ling / q-bao / q-xian / q-ji`（仙、极在右上角加一方小印：仙 = 泥金、极 = 朱砂）。
- 状态：`is-unid` 未鉴定（字模糊 2px、淡晕呼吸 2.4s）、`is-new`（左上一个朱点）、`is-sel`（圆相换朱色）、`is-empty`（圆相 22% 透明）、`is-locked`（圆相 18% + 清墨"锁"字）、悬停（圆相 100%、放大 5%）。
- 尺寸：`.sm` 46、默认 64、`.lg` 88。

### 5.7 储物袋 `.ink-grid`（v2 已换为侧挂纸笺 + 物品签，见 docs/ui/v2/储物袋_v2_方案.md）
玩法需要格子，所以保留格子，但画成习字用的**米字格淡朱线**（α .32），物品是墨字，不是卡片。占多格的物品用 `.w2 / .h2`，字号放大；选中物品套一笔朱色圆相。格子下方显示占格进度（一笔细条）。

### 5.8 浮签 `.ink-tip` 与详情
一张窄纸条，轻微倾斜（−0.8°），阴影跟毛边走。结构：名称（楷书）+ 品质印 + 一行品级说明 + 两三句描述（楷体）+ 键值列表 + 操作按钮。稀有物用洒金笺。

### 5.9 进度条 `.ink-bar`
满值 = 一整笔；`--v` 控制露出多少（`clip-path`，只改裁切，不重绘形状）。颜色：默认墨、`.hp` 朱、`.qi` 石青、`.xp` 泥金、`.ok` 石绿。掉血余迹 `<b>`（`--lag`）用纸色表示"被擦掉的墨"，0.4s 后追上。尺寸 `.thin` 8 / 默认 16 / `.thick` 26。
圆形读条 `.ink-ring`：一笔圆相按 `--v` 画出（conic 渐变 × 圆相 mask），用于撤离、采集、突破成功率。

### 5.10 资源计数
一方小圆印（石 / 材 / 丹 / 修）+ 楷书大数字 + 黑体小单位。灵值一律用泥金色数字。

### 5.11 印章徽记 `.ink-seal`
`.two`（两字竖排）、`.four`（四字，每字一个 `<span>`，右起竖读）、`.round`、`.oval`、`.frame`（朱文边框），颜色 `.gold/.ink/.blue/.green`。旋转 −3° 左右；同一屏的印不要全部同角度。

### 5.12 立绘 `kit/portrait_linmo.svg`
- **规则：界面里永远不出现低模 3D 人偶。** 需要人物在场时（出行准备、结算、境界），用 2D 写意立绘或剪影。
- 当前立绘由 `tools/portrait_gen.mjs` 生成：手工编排每一笔的笔路（中线控制点），程序把笔路画成有顿挫、出锋、飞白的毛笔笔触；淡墨宽笔铺体积、浓墨线收形（浓淡相破），脸只留眉眼几笔，**唯一的彩色是朱砂发带与剑穗**。透明底，直接叠在纸面上。
- 规格：全身 `portrait_linmo.svg` 600×1000（脚底约 y=900，人物朝左、风从左向右）；半身 `portrait_linmo_bust.svg` 380×460。**以后可由画师或 AI 立绘按同路径、同尺寸、同朝向直接替换**，界面不用改。
- 同一套笔法也画了丹炉 `kit/art_danlu.svg`；以后的器物插画（鉴宝台、蒲团、传送阵）沿用这套生成器，保持笔性一致。

### 5.13 通知 `.ink-toast`
一道宽笔（stroke-band）作底，纸色楷书字；默认墨色（拾取）、`.gold`（首次发现、高价值）、`.zhu`（危险：妖潮、被包围）。从左侧 0.3s 笔扫入，停 2.4s，墨淡出 0.6s。

### 5.14 对话 `.ink-say`
人名竖排 + 一方小印，台词写在一张浮签上（楷体 18）。不做头像框。

### 5.15 模态确认
屏幕整体压一层 35% 的墨色，中间一张 `.ink-paper.alt`；标题一行，正文两三句，底部"次要按钮 + 朱印"。危险操作（丢弃宝品、强行突破）把朱印换成朱文边框印，并加一句后果说明。

### 5.16 HUD（`hud.png`）
| 元素 | 位置 | 形式 |
|---|---|---|
| 气血 / 真气 | 左上 | 楷书标签 + 一笔进度条（朱 / 石青）+ 黑体数值；冲刺次数是两个墨点 |
| 天时（晨午暮夜） | 上中 | 四字刻度 + 一笔细条 + 朱砂水滴指针；剩余时间与"妖潮将起"小字 |
| 灵值 | 右上 | 竖排"灵值" + 泥金楷书大数 + 占格 / 未鉴定数 |
| 天机镜（小地图） | 右上角 | 铜镜：铜色外环 + 回纹 + 镜钮；镜内是该区域画面，未探处是纸色雾；撤离点为朱印，残阵为墨印；下面一行"古传送阵 · 东北 38 丈" |
| 撤离读条 | 主角脚下 | 一笔朱色圆相按进度画出；旁边竖排"撤离中"+ 倒计时 + 规则提示 |
| 技能栏 | 下中 | 圆相技能格（五行着色）+ 单字；冷却是扫过的淡墨扇形 + 秒数；法宝、阵法、丹药囊分组，组间留一字宽 |
| 拾取流 | 左下 | 小圆相 + 名称 + 灵值增量，越旧越淡（1 → .65 → .4） |
| 境界修为 | 右下 | 楷书境界 + 一笔泥金细条 + "本局感悟 +162" |

所有 HUD 组都放在 `.ink-wash` 墨晕底衬上（不规则淡纸色晕团，α .85–.9），**没有任何矩形底板**。

## 6. 叙事位置与信息层级

### 6.1 四象限归类
| 类型 | 元素 |
|---|---|
| 叙事内（画中之物） | 天机镜铜镜、洞府挂签、地图手卷、丹炉插画、首次所见竹简 |
| 空间型（画在世界里） | 撤离圆相、地面技能预览、可交互物脚下的淡墨圈 |
| 叙事外 HUD | 气血真气、技能栏、灵值、天时、拾取流、修为 |
| 元信息 | 受伤时屏幕边缘晕开的淡朱墨（不用红色闪屏）、入夜时纸面四角变暗 |

### 6.2 层级
生死（气血、撤离、危险） > 决策（技能冷却、灵值、天时） > 收获（拾取、修为） > 氛围（区域名、题跋）。层级越高：位置越靠近视线（左上、主角周围），墨越浓，越允许用朱色。

## 7. 45° 俯视下的可读性

1. **最坏背景**：画面同时有纸白地面和焦墨崖壁 / 竹林。所有 HUD 文字按对比最差的位置计算，关键数值目标 ≥ 4.5:1（XAG 101）。
2. **墨晕底衬**代替矩形底板：`--wash-color` 默认 rgba(240,234,220,.86)；压在大片焦墨上时调到 .9；压在纯纸白上可降到 .7。
3. **数字外描**：12px 以下的数字一律加两层 3px 纸色 `text-shadow`；不要用黑色描边（会和水墨后处理的轮廓线混在一起）。
4. **贴边**：HUD 离屏幕边至少 24px，画面中心 60% 不放常驻 HUD；主角周围只允许出现撤离圆相和技能预览。
5. **色相不是唯一区分**：去饱和截图检查，品质靠"圆相颜色 + 角标印 + 名称字色"三重区分，危险靠"朱色 + 位置 + 文字"三重区分。
6. **字号下限**：HUD 正文 ≥ 13px，数值 ≥ 12px（1280×720 基准，随分辨率等比缩放），书法字 ≥ 17px。

## 8. 光标与地面技能预览（给模块 F）

### 8.1 光标（`kit/cursors/`，`node tools/cursor_gen.mjs` 生成；热点表见 `kit/cursors/README.md`）
统一做法：**墨色主体 + 一圈纸色外描（约 1.5px，α .92）+ 很淡的投影**。纸白地面上靠墨色，焦墨上靠纸色外描，两种背景都清楚。

| 状态 | 形 | 色 | 热点 |
|---|---|---|---|
| 默认 | 毛笔笔尖（左上为锋） | 焦墨 | 笔尖 (3,3) |
| 界面悬停 | 笔尖 + 尾部一点 | 墨 + 泥金点 | (3,3) |
| 可交互 | 笔尖 + 泥金小圆相 | 墨 + 泥金 | (3,3) |
| 敌人 | 开口圆相 + 四道短笔 + 中心点 | 朱砂 | 中心 (16,16) |
| 瞄准 | 细圆相 + 内小圆相 + 中心点 | 当前技能的五行色（低饱和） | 中心 |
| 不可用 | 淡墨圆相 + 一道斜笔 | 淡墨（不用红） | 中心 |

- 尺寸：32×32（1×）与 64×64（2×，坐标 ×2）。状态切换 0.12s 淡入淡出，敌人状态的圆相可以 0.6s 缓慢自转半圈，其余静止。
- 光标层放在最上面、`pointer-events: none`，**不经过水墨后处理**。
- 现有 `src/ui/cursor.js` 的六种状态与本表一一对应（它的"可交互"用泥金小印，本套件用泥金小圆相，两者都符合规范），视觉打磨时对照本表与 SVG 即可。

### 8.2 地面技能预览（见 gallery.png 末节）
| 预览 | 填充 | 边 | 说明 |
|---|---|---|---|
| 施法范围（可施放的最远处） | 不填 | 淡墨虚圆 α .45，外面一圈纸色描边 α .7 | 只提示边界，不抢画面 |
| 落点 AoE | 五行色墨晕，由内 α .08 到边缘 α .32 | 一笔圆相（有起笔收笔、留缺口）α .85 | 中心一点；落点吸附时圆相轻微收紧（0.12s） |
| 扇形（剑气斩）/ 锥形 | 同色由根部 α .3 到外缘 .06 | 2px 毛边描线 α .75 + 纸色外描 | 扇根贴在主角脚下 |
| 直线（冲刺 / 飞剑） | 同色宽带 α .28 | 终点一笔箭头 α .9 | 宽带两端圆头 |
| 弹道 | — | 点状虚笔（3 / 6），颜色同五行 | 从施法者到落点 |
| 不可施放（超距、冷却、真气不足） | 淡墨 α .08 | 淡墨虚线 + 一道斜笔 | **不用红色**（红色留给敌人和危险） |

五行色（低饱和，比 UI 点色再淡一档）：金 #a8862f、木 #3f9a6e、水 #2f7fa8、火 #c0392b、土 #9a6a32。

渲染要点：
- 边缘"毛"：用噪声纹理扰动圆环 / 扇形的 alpha 边（或在 shader 里对 UV 做 1–2px 噪声位移），不要用完美几何线。
- 画在水墨后处理**之后**（或者在后处理里用遮罩把预览排除在描边 / 抖动之外），否则预览会被描黑边、被纸纹吃掉。
- 地面是"纸白"时靠深色边 + 纸色外描，地面是"焦墨"时靠纸色外描，所以每条边都是"深色线 + 外侧一圈纸色"的双层结构。
- 透视：预览贴地，按 45° 俯视压扁（示意图里是 y 方向 ×0.62）；线宽在屏幕空间保持 2–3px，不随距离变细。

## 9. 动效

| 名称 | 用于 | 做法 | 时长 / 缓动 |
|---|---|---|---|
| 墨晕开 `fx-bleed` | 面板、浮签出现 | 透明度 0→1 + 模糊 6→0px + 缩放 .985→1 | 0.6s，`--ease-ink` |
| 笔锋扫 `fx-wipe` | 进度、分隔线、通知、标题下划 | `clip-path` 从左向右露出 | 0.3–0.6s |
| 盖印 `fx-stamp` | 确认、鉴定结果、结算印 | 1.6 倍 → 0.94 → 1，旋转 −8° → −4° | 0.42s；落印瞬间可配轻微屏幕震动 2px 与印泥声 |
| 展卷 `fx-unroll` | 天机镜、手卷、册页 | `clip-path` 从中间向两边展开 | 0.8s |
| 呼吸 | 未鉴定物、可升级设施的朱点 | 透明度 .55↔1、缩放 .94↔1.06 | 2.4s 循环 |
| 墨散 | 关闭面板、物品丢弃 | 反向墨晕开 + 下移 4px | 0.25s |

- 动画只改 `opacity / transform / clip-path`；**不要动画 mask 或 SVG 滤镜**（贵）。
- `prefers-reduced-motion` 时关闭所有循环动画与展卷，改为直接出现。

## 11. 图标（v2 定稿：图标为主，单字为辅）

- **物品一律用水墨图标**，不再在格子里写单字（单字像"文字游戏"，同字物品也分不开：5 种妖丹都是"丹"）。图标由程序化笔路模板画成"纸性位图"（洇墨、飞白、颗粒、湿边），与立绘同一套笔触模型，构建期烘焙成图集：`tools/icons/inkicons.js` → `node tools/icons_gen.mjs` → `src/ui/icons/`；运行时接口 `src/ui/icons.js`（`iconFor / iconEl / itemTag`）。详见 `docs/ui/v2/储物袋_v2_方案.md` §8。
- **未鉴定 = 墨拓剪影**（同一模板自动推出：并墨、反刻白线、拍墨斑驳）：只见其形、不见其色。
- **品级不进图标**：图标是物品本色、低饱和淡彩；品级只由圆相色、同色晕、名称字色、仙 / 极角印表达，颜色严格取 `src/core/items.js` RARITY。
- 构图：主体占画面约 80%，斜放物左下到右上；2×1 物品（剑 / 衣 / 佩）用横构图；一点朱（剑穗、绳结、符文）每图至多一处。
- **单字为辅**：保留在悬停名称、详情标题、无障碍朗读、设施大字（"鼎""血"）与地图印章（撤 / 阵 / 府 / 妖 / 袋）里。
- 技能图标同理画"意象"（月牙剑气、符火、冰棱、盘藤……，已落地，`iconForSkill`）；地图图标用剪影式简笔意象（已落地，`iconForMap`，单字印章只作图集加载前的兜底）。
- 需要图形的界面元素仍用"笔画式"图形，不用等宽线性图标库。

## 13. 集成到 `src/ui`

`src/ui/kit.js` 已经是"薄组件层"（注释写明等待本套件替换），各界面的逻辑不用改，只替换样式与少量结构：

1. **拷贝套件**：`docs/ui/v2/kit/{ink-ui.css, ink-ui.js}` → `src/ui/ink/`；`strokes.css` 由 `tools/ui_kit_gen.mjs` 在构建 / 开发启动时生成到 `src/ui/ink/strokes.css`（改输出路径参数即可）。
2. **字体**：构建时运行 `tools/ui_fonts.mjs` 的同一逻辑，从 `src/ui/**` 与 `src/data/**` 的界面文案收集字表，输出两套 woff2（不 base64，独立文件可缓存）。玩家改名等动态文字回退到系统楷体。
3. **映射**：
   | kit.js 现有接口 | 换成 |
   |---|---|
   | `kit.button(label, fn, {primary})` | `.ink-btn` / `.ink-btn.primary`；新增 `{seal:true}` → `.ink-seal-btn`（启程、开炉、突破、回府） |
   | `kit.panel(title)` | `<section class="ink-paper">` + `.ink-title` + `.ink-rule`；调用后执行 `inkui.decorate(root)` |
   | `kit.itemCell(inst)` | `.ink-slot.q-*`（单字取物品定义的 `glyph` 字段，没有就取名称首字） |
   | 储物袋格子（bagui.js） | `.ink-grid`，占格用 `.w2/.h2` |
   | `kit.toast(text,{kind})` | `.ink-toast`（kind: loot / gold / danger） |
   | `kit.confirm / prompt` | §5.15 模态 |
   | hud.js / runhud.js / skillbar.js | §5.16 的 `.hud-vital / .hud-skill / .hud-mirror / .ink-ring` |
   | cursor.js | 视觉对照 §8.1 与 `kit/cursors/*.svg` |
4. **性能**：mask 形状是静态 data URI，浏览器只解码一次；数值变化只改 CSS 变量（`--v`、`--cd`），对应的是 `clip-path` / conic 渐变，不触发重新解码。HUD 不要用 SVG 滤镜（`#ink-rough` 只用在静态插画和全屏界面上）；HUD 层的 DOM 节点保持在 150 个以内；进度类数值每帧最多更新一次，且值不变时不写 DOM。
5. **分辨率**：所有尺寸以 1280×720 为基准，界面根节点按 `min(innerWidth/1280, innerHeight/720)` 设置 `font-size` 或 `zoom` 等比缩放；mask 形状是矢量，任何缩放都清晰。
6. **替换美术**：立绘、器物插画、光标都是独立文件，路径与尺寸固定，画师交稿后直接覆盖。
